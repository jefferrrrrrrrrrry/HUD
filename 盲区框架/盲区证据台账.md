## 二、A 类：遮挡为核心条件（6 篇，本框架的证据主干）

### #54 Merenda 等（2018）—— 本库唯一的实车「遮挡后横穿」范式

| 项 | 内容 |
|---|---|
| 范式 | 户外测试床 100 m × 110 m，事件区左右各停 **3 辆同色货车（共 6 辆）**；研究 2 **在每辆货车尾部悬挂黑布，以阻止被试在行人步出之前看到其双脚**；行人演员自货车后走出 |
| 运动学 | 车速 **10 mph**（偏差 ±2 mph 持续 5 s 即口头提醒）；紧迫度三级 **TTC 2 / 3 / 4 s = 9 / 13.5 / 18 m** |
| 触发 | GPS 触发图形，同步无线电通知演员，**演员信号预留约 0.5 s 提前量**（Wizard-of-Oz） |
| 核心结果 | **屏幕固定线索「捕获快、引导慢」；世界固定共形线索「捕获慢、引导快」**（FG：共形被注视更慢 *t*(53) = 3.022, *p* = 0.019；GT：共形→目标转移最快 *t*(176) = 3.904, *p* < .001）；两者总定位时间无显著差异 |
| 关键副作用 | **与车辆自身运动耦合的动画（compass）在 2 s TTC 高紧迫度下产生负的停车间隙**（即理论碰撞）——危险线索的动画必须独立于本车运动 |
| 关键约束 | **17° 圆形 FOV 下，近距侧方行人的共形图形会移出 HUD 视场而彻底失效** |
| 证据等级 | **A（全文，实车）** |

> 本篇同时给出「刺激驱动任务」的定义，其例证即「应对盲区中的车辆」——即遮挡场景在注意机制上属**刺激驱动**而非目标导向，这是研究二与研究一在机制层面的第一处分野。

### #12 Zhang（边扬）等（2024）—— 遮挡场景收益幅度的唯一强量化来源

| 项 | 内容 |
|---|---|
| 遮挡设置 | 行人位于机动车道右边线 **2.5 m**，**被路边公交车遮挡**（斑马线外隐藏行人横穿） |
| 场景 | 4 km 城市路、双向四车道、车道宽 3.5 m、限速 60 km/h |
| 触发 | 主车距 **100 m** 时路侧 V2I 触发 HUD／HDD 视觉 + 语音（语音仅播一次）；距行人 **60 m** 时行人以 **1 m/s** 起步横穿 |
| 设计 | N = 34，3（Baseline／HDD／HUD）× 2（晴／雾 240 m） |
| 核心量化 | HUD 使**油门松开位置提前 36.29 m**（*p* < 0.001）、**首次制动提前 39.10 m**、**\|最大减速度\| 降低约 3.45 m/s²**、**最小冲突距离 +9.41 m**、最小速度位置前移约 29.2 m；预警类型对 6/7 指标 *p* < 0.001 |
| 逐档数值 | \|a\|max：Baseline −8.30 ± 1.94 → HDD −6.94 ± 2.34 → HUD −5.03 ± 1.23 m/s²；最小冲突距离 10.75 ± 6.97 → 15.02 ± 5.25 → 20.96 ± 6.58 m |
| 雾天交互 | HUD 雾 vs 晴：油门提前多 27.7 m（*p* = 0.032）、制动提前多 27.8 m（*p* = 0.035）——**能见度下降放大遮挡预警的收益** |
| 证据等级 | **A（全文）** |

> **引用规则：凡需「被遮挡行人预警的距离／减速度增益」数值，一律引本篇。** 主库其余盲区文献均无可引用数值。

### #65 You 等（2023）—— 「不可见危险」预警的理论路径，且是本框架最重要的边界揭示者

| 项 | 内容 |
|---|---|
| 构念 | **invisible danger**：危险目标当前不在驾驶员直接视野内或被遮挡；作者明确称该问题「仍未被充分探索」 |
| 设计路径 | **团队协同感知模型**——人类驾驶员感知循环 + 计算智能体感知循环；AR-HUD 被定位为「**承载智能体认知信息的载体**」 |
| 结果 | SA 与**反应时**在**手动与自动两模式下均显著改善**，并提升对 auto-pilot 的信任 |
| 致命局限 | 仅摘要级；**零个数值**（无被试量、无毫秒数、无 SA 得分、无统计量）；**反应时计时起止点未定义** |
| 证据等级 | **B（仅摘要）——不得引用任何数值** |

**本篇对双框架的三处决定性贡献：**

1. **揭示 #08（Wu 等 2024）「目标锁定 BW 优于 BD／BR」的适用边界**：目标被完全遮挡时，BW 图形要么绘制在遮挡物表面（此时锚定的是遮挡物而非行人），要么以穿透方式绘制（引入 X-ray 深度歧义）——**严格 BW 在物理上不可实现**。故 #08 的右转场景 TTFF 2730 ms → 617 ms 这一结论**不可外推到盲区情境**。
2. **指出遮挡场景下预警的时间上界性质改变**：不可见危险的预警只能在传感器探测到目标之后发出，**其最早可能时刻是探测时刻而非某个人因最优值**。
3. **指出遮挡场景下信任的建立机制改变**：驾驶员无法用自身视觉核验预警真伪，故信任无法通过「与自身判断吻合」建立。这与 #74（Abe 与 Richardson 2006：报警晚于驾驶员自身首次响应基线 0.72 s 时，信任由 **7.3 降至 4.3**，报警时刻与信任 *R* = **−0.46**）构成直接张力——**#65 的信任提升很可能取自近 100% 可靠条件，不可外推至含误报系统。**

### #86 Chang 等（2009）—— 交叉口遮挡（公交遮挡行人）的预警时序需求

| 项 | 内容 |
|---|---|
| 场景 | 交叉口公交—行人碰撞，公交车体构成对行人的相互遮挡 |
| 运动学 | 公交 50 km/h，紧急减速率约 3 m/s²，有预警时感知—反应时 **2.1–2.3 s** |
| 时序需求 | 预警必须在**碰撞点前 6.07 s（视觉）／6.28 s（语音）** 发出 |
| 空间需求 | 行人检测须覆盖**距路缘 7.1 m**；危险感知距离 **≥ 61 m** |
| 收益形式 | 紧急减速率由 3.10–3.56 降至 **2.77–3.18 m/s²**——**收益体现为制动平顺化而非反应时缩短** |
| 证据等级 | **A（全文，仿真参数分析）** |

### #38 Kim 等（2022）—— 非视距（NLOS）行人预警的工程时间预算

### #84 Char（2022）—— 遮挡在事故重建中的量化地位与硬下界

| 项 | 内容 |
|---|---|
| 样本 | 3700 余例事故重建；「遮挡」在本篇出现 13 次，为主库中遮挡关键词密度最高的事故学来源 |
| 硬下界 | **tLTTB = 碰撞前 1.5 s**（行人；骑行者 1 s，左转 0.8 s） |

## 四、D 类：认知性盲区（4 篇）——**构念不同，必须与几何遮挡严格区分**

几何遮挡与认知性盲区都会导致「驾驶员未察觉行人」，但**成因、可干预点与预警作用机制完全不同**：几何遮挡下驾驶员**无信号可采样**（Scanning 阶段在物理上无法启动）；认知性盲区下**信号已入视网膜而未被注意选中**（Scanning 已启动但 Identification 失败）。本框架的研究二处理前者，后者仅作为代价指标进入因变量集。

| # | 文献 | 关键数值 | 在本框架中的角色 |
|---|---|---|---|
| **#60** | Wang 等（2021） | AR-HUD 边界框把行人 IB 频次由 **46 → 11**，反应时快约 **112 ms**；**但系统一旦漏检行人，IB 反而高于不用 AR-HUD**；高负荷再叠加约 **141 ms** 延迟 | **研究二的第一约束**：盲区预警高度依赖系统探测，故「漏检代价」而非「反应速度」是首要终点 |
| **#43** | Chen 等（2023） | N = 30，2 × 2；**外周视野下危险叠加在 AR 图形上（on-HUD）时漏检率最高且反应时最长**；中央视野下反而 off-HUD 危险漏检最多（**交叉交互**） | AR 图形除吸引注意外还**掩蔽被叠加目标**；盲区预警图形若绘制在遮挡物表面，恰是「on-遮挡物」构型，须检验掩蔽风险 |
| **#48** | Hou 等（2025） | 3 动效 × 4 透明度；**T0.75 的 IB 最低，T0.5 的无盲视反应时最短且满意度最高**（安全最优与体验最优分离）；三种动效对 IB 均无显著影响，**仅闪烁缩短反应时** | 不透明度动态范围 0.6–0.75；**「闪烁可缓解无意视盲」为转述失真，原文为「动效对 IB 无显著影响」** |

## 六、盲区情境对研究一结论的六处边界推翻

这一节是双框架切分的**充分性论证**：以下六条说明研究一（非盲区）的结论在盲区情境下**并非"效应量变小"，而是"前提不成立"**，因此必须另立研究二而不能作为研究一的一个附加水平。

| 编号 | 研究一的成立前提 | 盲区情境下的失效方式 | 出处 |
|---|---|---|---|
| **BD-1** | 存在自发察觉时刻 t₀，可实测、可作为 Δt 的零点 | 行人在 t_reveal 前不可见，**Scanning 无信号可采样，t₀ 在物理上不存在**；Δt = t₀ − t_warn 无定义 | #65、#58 |
| **BD-2** | 目标可见，故目标锁定 BW 可实现且最优（TTFF 2730 → 617 ms） | **严格 BW 物理不可实现**：或锚定遮挡物表面，或穿透绘制而引入深度歧义；锁定策略候选集本身改变 | #65 揭示 #08 的边界 |
| **BD-3** | 提前量的上界由人因（虚警代价、认知窗口）决定 | **上界由探测时刻与探测可靠性决定**：最低时间预算 1.66 s；意图预测缓冲仅 0.5–2.0 s，远小于 6.07–6.28 s 的制动需求 | #65、#38、#87、#86 |
| **BD-4** | 驾驶员可用自身视觉核验预警真伪，信任由「报警与自身判断是否吻合」建立 | **无从核验**：信任只能依赖长期可靠性经验；#74 的「晚报警 → 信任 7.3→4.3、*R* = −0.46」机制在此不适用 | #65、#74 |
| **BD-5** | 共形图形可稳定贴合于目标 | **17° FOV 下近距侧方行人的共形图形移出视场彻底失效**；遮挡后横穿恰是「近距侧方」构型 | #54 |
| **BD-6** | τ 理论可由光学膨胀率 $\dot{\theta}$ 越过知觉阈值反推 t₀ 下界（60 km/h 无遮挡约 3.2 s） | **$\dot{\theta}$ 的时间原点被遮挡截断**：$\dot{\theta}$ 序列自 t_reveal 起才存在，下界推导须以 t_reveal 为起点重做 | 本框架推导，据 #54／#12 场景几何 |

### 6.1 由 BD-1 导出的零点替换

研究一以 t₀（**心理量，须实测**）为零点；研究二无法沿用，故改以**几何量**为零点，并保留「以驾驶员为参照」这一核心思想：

- **t_reveal**：行人前缘越过遮挡体边缘、首次进入驾驶员视线锥的时刻。**可由场景几何（遮挡体位置与尺寸、行人步速、本车轨迹与眼点位置）解析求出**，无须实测，且在被试间恒定。
- **t_detect**：系统首次以给定置信度探测到被遮挡行人的时刻。**由传感／V2X 架构决定，构成预警提前量的物理上界**。
- **研究二自变量**：**Δt′ = t_reveal − t_warn**，即预警相对「自然显露时刻」的提前量，且必受 t_warn ≥ t_detect 约束。

**由此得到一条可否证的跨研究预测：研究二的最优 Δt′ 应显著大于研究一的最优 Δt。** 机制解释有二：其一，遮挡条件下驾驶员的预期性注视（SPIDER 的 Predicting，代理量为预期性注视）无从建立，故理解与决策所需窗口更长；其二，遮挡场景在注意机制上属**刺激驱动**而非目标导向（#54），而刺激驱动的定向本身有额外耗时。
