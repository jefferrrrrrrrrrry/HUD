# AR-HUD 行人碰撞预警：非盲区与盲区双情境研究框架

> **本框架与主线框架的关系**：主线框架（`../AR-HUD行人碰撞预警_毕业论文研究框架.md`）按**参数类型**切分（研究一＝时间参数、研究二＝空间参数）。本框架按**视线可见性情境**重新切分（研究一＝非盲区、研究二＝盲区），每个研究内部同时覆盖时间与空间参数。
> **切分依据**：并非"另一种归类方式"，而是因为盲区情境使研究一的六项成立前提**不成立**（非"效应量变小"）。逐条论证见 `盲区证据台账.md` 第六节。
> **盲区口径**：盲区 = **驾驶员视线的几何遮挡**。不含传感器盲区、不含后视盲区、不含认知性盲区（无意视盲）——后者作为代价指标进入因变量集，不作为情境自变量。

## 零、论证契约

### 0.1 中心论点

AR-HUD 行人碰撞预警的时空参数**不存在一套跨情境通用的取值**：在非盲区情境下参数应以驾驶员的**自发察觉时刻 $t_0$**（心理量、须实测）为零点、以目标锁定为空间载体；而在盲区情境下 $t_0$ 在物理上不存在，参数必须改以**行人自然显露时刻 $t_{reveal}$**（几何量、可解析）为零点，且目标锁定退化为不可实现——本研究分别标定两套参数，并直接实测两者之间的**迁移损失**。

### 0.2 核心贡献与边界

| 贡献 | 证据形式 | 边界 |
|---|---|---|
| 提出情境依赖的双零点参数化：非盲区用 $t_0$、盲区用 $t_{reveal}$ | 实验 1 同场同批标定两个零点，使两套参数可比 | $t_{reveal}$ 的解析解依赖遮挡体几何与眼点位置，跨车型须重算 |
| 首次实测盲区情境的"预告区段"价值 | 实验 4 以 $\Delta t' = t_{reveal} - t_{warn}$ 为自变量，含跨越与不跨越 $t_{reveal}$ 两类水平 | 限于单一遮挡体、单一行人步速 |
| 首次比较盲区情境下的四类锚定策略（目标锁定不可实现时的替代方案） | 实验 5 四水平 × 遮挡几何两水平 | 限于视觉 AR-HUD；穿透显影条件受模拟器渲染保真度限制 |
| 直接实测跨情境迁移损失，为"是否需要情境自适应参数"提供判据 | 双向交叉迁移区块 | 迁移损失的估计精度受样本量限制 |
| 揭示盲区情境下预警时间上界的性质由"软"变"硬" | 实验 4 的可靠性操纵 + 探测置信门限 | 探测门限在模拟器中为程序设定，非真实传感器性能 |

### 0.3 术语表

| 符号 | 定义 | 性质 | 取得方式 |
|---|---|---|---|
| $t_0$ | **自发察觉时刻**：无预警条件下驾驶员首次注视行人（或首次松油）的时刻，以距冲突点的剩余时间表示 | 心理量，随被试与场景变化 | 实验 1 实测（非盲区情境） |
| $t_{reveal}$ | **自然显露时刻**：行人前缘越过遮挡体边缘、首次进入驾驶员视线锥的时刻 | **几何量，被试间恒定** | 由遮挡体位置尺寸、行人步速、本车轨迹与眼点位置解析求出，实验 1 验证 |
| $t_{detect}$ | **系统探测时刻**：系统首次以给定置信度探测到被遮挡行人的时刻 | 工程量，由传感／V2X 架构决定 | 场景设定，构成 $t_{warn}$ 的硬上界 |
| $t_{warn}$ | 预警呈现时刻 | 自变量 | — |
| $\Delta t$ | **非盲区提前量** $= t_0 - t_{warn}$ | 研究一自变量 | — |
| $\Delta t'$ | **盲区提前量** $= t_{reveal} - t_{warn}$ | 研究二自变量 | — |
| **预告区段** | $[t_{warn},\ t_{reveal}]$：预警已呈现而行人尚不可见的区段 | 盲区情境**独有** | — |
| **显露区段** | $[t_{reveal},\ t_{conflict}]$：行人已可见的区段 | 两情境共有 | — |
| BTN | 制动威胁数 $=$ 避险所需减速度 / 最大可用减速度 | 触发准则的归一化物理量 | 实验 1 标定分母 |
| BD / BR / BW | 屏幕（视线）固定 / 道路（冲突点）锁定 / 跟随目标锁定，记法沿用 Wu 等（2024） | 非盲区空间参照系 | — |
| **BO** | **遮挡体锚定**（occluder-locked）：图形贴于遮挡体表面 | 盲区情境专有 | — |
| **BR-p** | **推测地面锚定**（projected-ground）：图形贴于行人推测的地面位置 | 盲区情境专有 | — |
| **DR** | **穿透显影**（diminished reality）：将遮挡体半透明化以显示其后行人 | 盲区情境专有 | — |
| **BD-dir** | **屏幕方位指示器**：屏幕固定的方向箭头，不做空间配准 | 盲区情境专有（FOV 受限时的退化方案） | — |

## 一、研究目标与研究问题

### 1.1 总目标

以驾驶员**情境意识模型**与**注意加工阶段理论**为理论基础，围绕**视线可见性**这一情境变量，探索 AR-HUD 行人碰撞预警**时空参数**与驾驶员**安全绩效、认知负荷、情境意识及用户体验**四类构念之间的关系，**输出两套可检验、可复现的时空参数设计标准**，并直接实测两套参数之间的**迁移损失**，据此判定参数是否须情境自适应。

### 1.2 四项分目标

| 编号 | 分目标 | 探索的关系 | 输出的成果 | 对应 |
|---|---|---|---|---|
| **O1′** | 双情境零点的同批标定 | 无预警条件下非盲区自发察觉时刻的分布特征，与盲区显露时刻解析解的效度 | 两个情境共用刻度的参数化基准、反应时分位数、舒适减速度、方差成分 | 实验 1 |
| **O2′** | 非盲区情境的时空参数标定 | 相对提前量、触发准则类型、空间参照系、背景视觉复杂度与次任务负荷对四类构念的影响 | 非盲区时间参数区间、锁定策略推荐序，且**位置增益与共形增益分离** | RQ1′；实验 2–3 |
| **O3′** | 盲区情境的零点重建与参数标定 | 显露时刻零点下的相对提前量、预告区段价值、系统可靠性与四类锚定策略对四类构念的影响 | 显露时刻**解析式**、盲区时间参数区间、分层语义分化规则、「遮挡几何 × 可用视场 → 推荐锚定」查表式规范 | RQ2′；实验 4–5 |
| **O4′** | 迁移损失估计与切换判据 | 一情境入选方案施用于另一情境时的双向绩效损失 | 迁移损失的点估计与 95% 置信区间、以可见性判别为输入的切换条件；**或**「切分不成立」的否证结论 | RQ3′；交叉迁移区块 |

O3′ 输出物中的「解析式」为一项刻意的形式约束：显露时刻不取固定秒数，而由遮挡体位置尺寸、行人步速、本车轨迹与眼点位置解析求出，故可跨车型换算。O4′ 不引入新的实验操纵。

四项目标间的依赖关系：O1′ 的产出构成 O2′ 与 O3′ 的自变量换算基准与样本量估计输入；O2′ 与 O3′ 的入选时间参数组合分别构成实验 3 与实验 5 的固定条件；O4′ 以 O2′ 与 O3′ 的入选方案为输入。

### 1.3 三个研究问题

- **RQ1′　非盲区情境的时空参数。** 行人自始可见时，预警相对驾驶员**自发察觉时刻 $t_0$** 的适宜提前量为何？触发准则应依据固定时间阈值抑或减速度归一化量？预警应锁定于屏幕、道路冲突点、行人目标抑或复合，该优劣序是否随**背景视觉复杂度**与**次任务负荷**变化？各水平如何影响四类因变量构念？
- **RQ2′　盲区情境的时空参数。** $t_0$ 在物理上不存在时，零点应替换为何？预警相对**自然显露时刻 $t_{reveal}$** 的适宜提前量为何？「行人尚不可见而预警已呈现」的**预告区段**是否具有独立价值？**系统可靠性**如何调节该效应？目标锁定在物理上不可实现时，图形应锚定于何处，最优解是否随**遮挡几何**反转？
- **RQ3′　跨情境迁移损失。** 两套参数能否互换？双向迁移损失的量级为何？若须情境自适应，切换判据为何？**该问题的答案可否证本研究的情境切分本身**——若迁移损失不显著，则应退回单情境处理（见 P6′）。

三个问题的递进次序由变量依赖关系强制：RQ1′ 与 RQ2′ 的自变量分别以 O1′ 标定的两个零点为基准，RQ3′ 以前两者的入选方案为输入。

### 1.4 四类因变量构念

两个情境共用同一因变量结构，归入四类构念；其中**情境意识单列**而不并入认知负荷，因二者可解离——存在主观负荷下降而危险漏检率上升的条件（注意隧道与无意视盲）。故**漏检率升格为并列主要终点**（见 H4′），且眼动指标一律按**区间判定**而非单调假设解释。

| 构念 | 测量指标 |
|---|---|
| **安全绩效**（safety performance） | 最小 TTMD、碰撞率、最小冲突距离、峰值减速度、jerk、制动启动时刻 |
| **认知负荷**（cognitive workload） | DALI 或 NASA-TLX、瞳孔直径变化率、注视熵、次任务绩效衰减 |
| **情境意识**（situation awareness） | 按**感知／理解／预测**三阶段分别计分；**危险漏检率**（并列主要终点）、TTFF（警告／行人）、目标验证时间、**预告区段内向遮挡体边缘的预期性注视比例**、路径侵入预测正确率、冲突点空间误差 |
| **用户体验**（user experience） | 信任量表、依从率、接受度、扰烦度；**盲区情境另加晕动与不适**（穿透显影条件） |

盲区情境相对非盲区情境的指标变更详见 §7.1。

## 二、核心理论模型

### 2.1 三重约束模型的情境分化

主线框架的三重约束模型（运动学下界／可靠性上界／认知加工窗口，以 $t_0$ 为零点）在盲区情境下三条约束**全部改变性质**：

| 约束 | 非盲区情境（研究一） | 盲区情境（研究二） | 性质变化 |
|---|---|---|---|
| **下界**<br>运动学必要性 | $t_{warn} \ge PRT_{p95} + v/a_{comf} + \delta_{brake}$ | 同式，但 $PRT$ 须以 $t_{reveal}$ 为起点重测 | 形式不变，**参数须重标定** |
| **上界**<br>可靠性 | $t_{warn} \le t_{pred}(PPV \ge \pi^*)$，由**虚警代价**决定 | $t_{warn} \le t_{detect}$，由**传感器能否看见**决定 | **软约束 → 硬约束**：前者可通过界面设计缓解，后者不可 |
| **窗口**<br>认知加工 | $\Delta t \ge \sum \text{SPIDER}$，五阶段在同一区段内连续完成 | **五阶段被 $t_{reveal}$ 强制拆成两段**（见 2.2） | **连续 → 分段** |
| **零点** | $t_0$（心理量，实测） | $t_{reveal}$（几何量，解析） | **可变 → 恒定** |

零点性质的变化带来一项**方法学收益**：$t_{reveal}$ 在被试间恒定，故研究二的自变量不需要按被试个体校准，$\Delta t'$ 可直接作为被试内因子操纵；而研究一的 $\Delta t$ 依赖每位被试自身的 $t_0$，须先复用同批被试完成实验 1。

### 2.2 盲区情境把 SPIDER 五阶段拆成两段

这是研究二区别于研究一的核心机制，也是"预告区段"这一构念的来源。

```
盲区情境的时间轴（右侧更紧急）

  t_detect        t_warn              t_reveal                t_conflict
     │              │                     │                        │
     │◀── 硬上界 ──▶│                     │                        │
     │  传感器可见性  │                     │                        │
     │              │◀──── Δt′ ─────────▶│                        │
     │              │                     │                        │
     │              │◀─ 预告区段 ────────▶│◀─── 显露区段 ────────▶│
     │              │  可做：P、部分 D      │  可做：S、I、D、E        │
     │              │  不能做：S、I         │                        │
     │              │  （无目标可扫视/确认） │                        │
```

- 在**预告区段**内，驾驶员已知"存在一个看不见的危险"，可以完成 **Predicting**（预测行人可能自何处进入本车路径）与部分 **Deciding**（预置减速），但**无法完成 Scanning 与 Identification**——没有目标可扫视、没有目标可确认。
- 在**显露区段**内，S 与 I 才成为可能，而此时若已借预告区段完成 P 与部分 D，则 I → E 的链条被显著缩短。

**由此得到三条可否证预测：**

- **P1′（预告区段价值）**：若预警仅在 $t_{reveal}$ 之后发出（$\Delta t' \le 0$），则等于放弃预告区段，绩效应显著劣于跨越 $t_{reveal}$ 的预警（$\Delta t' > 0$）。
- **P2′（最优提前量的情境差）**：盲区情境的最优 $\Delta t'$ 显著**大于**非盲区情境的最优 $\Delta t$。机制有二：其一，遮挡使预期性注视（Predicting 的代理量）无从建立，故 P 阶段耗时更长；其二，遮挡场景在注意机制上属**刺激驱动**而非目标导向（Merenda 等，2018），刺激驱动定向本身有额外耗时。
- **P3′（收益上限）**：预告区段的收益应随 $\Delta t'$ 单调递增但**存在饱和**，饱和点对应 P 与预置 D 完成所需时间；超过饱和点后继续提前只增加虚警暴露而不再改善绩效——此即盲区情境下"过早预警收益递减"的机制性解释。

### 2.3 由不可核验性导出的信任机制分化

非盲区情境下，驾驶员可用自身视觉核验预警真伪，故信任由"报警是否与自身判断吻合"建立——Abe 与 Richardson（2006）实测：报警晚于驾驶员自主响应基线 0.72 s 时，信任由 **7.3 降至 4.3**（10 点量表），报警时刻与信任相关 $R = -0.46$。

盲区情境下**该机制在物理上不适用**：预警发出时行人不可见，驾驶员无从核验。You 等（2023）报告不可见危险预警提升信任，但其摘要未涉及误报条件，因而很可能取自近 100% 可靠条件。

- **P4′（可靠性损伤的情境差）**：同一虚警率下，盲区预警的信任损伤与依从率下降显著**大于**非盲区预警。理由：非盲区情境中驾驶员可将一次虚警归因于"系统略早"而保留信任；盲区情境中虚警无法被归因，只能计入系统错误。

### 2.4 由显示视场约束导出的锚定策略反转

Merenda 等（2018）在实车条件下报告：**17° 圆形 FOV 下，近距侧方行人的共形图形会移出 HUD 视场而彻底失效**。而"遮挡后横穿"恰是近距侧方构型——行人自停放车辆后走出时，其方位角随接近而迅速增大。

- **P5′（锚定策略随遮挡几何反转）**：在近距侧方遮挡几何下，共形类锚定（BO、BR-p、DR）的绩效显著低于屏幕方位指示器（BD-dir）；而在远距前方遮挡几何下方向相反。即**盲区情境不存在单一最优锚定策略，最优解是遮挡几何的函数**。

### 2.5 迁移损失

- **P6′（双向迁移损失）**：把研究一入选的时空方案直接施用于盲区情境，以及把研究二入选方案施用于非盲区情境，均产生显著绩效损失（迁移损失 $> 0$）。**这是双情境框架必要性的直接实证检验**：若迁移损失不显著，则本框架的切分不成立，应退回主线框架的单情境处理。此项为**预注册的可否证检验**，零结果照实报告。

## 三、总体研究结构

| 研究 | 实验 | 核心问题 | 核心变量及水平 | 主要机制指标 |
|---|---|---|---|---|
| 共用基础<br>双情境标定 | **实验 1**<br>双情境无预警基线 | 两个零点各在何处？运动学可行域多大？ | 情境（非盲区／盲区）× 车速（40／60 km/h），**无 AR 预警** | 非盲区：$t_0$ 分布；盲区：$t_{reveal}$ 几何验证与显露后 PRT；两情境的 $PRT$ 分位数、$a_{comf}$、$t$ 时刻 BTN、渲染延迟、方差成分 |

### 3.1 为什么可靠性操纵放在研究二而非研究一

主线框架把系统可靠性放在时间参数研究（实验 3）内。本框架改置于研究二，理由有三：

1. **理论意义最大处**：可靠性的核心争议是"虚警代价"，而虚警代价的机制在盲区情境下才发生质变——不可核验（§2.3）。在非盲区情境操纵可靠性，只能复现 Schall 等（2013）的 15%／15% 零效应或 Abe 与 Richardson（2006）的强效应，而无法解释两者为何冲突。
2. **可否证预测最强处**：P4′ 给出明确的方向性预测（盲区损伤 > 非盲区损伤），且该预测可由本框架的双情境设计**直接检验**，而单情境设计只能间接推断。
3. **上界性质一致**：盲区情境的时间上界本就是探测可靠性（§2.1），把可靠性与 $\Delta t'$ 置于同一实验，使自变量与上界约束在同一物理量上闭合。

**80% 这一水平的依据**：Schall 等（2013）已在 15% 错误率上得到全零效应，故 15% 大概率复现零结果而不提供信息；Large 等（2019）的最低操纵档为 20%；工程可达骚扰水平约 13.74%（A-TTC 正式版，3,519 条视频核验事件）。故 20% 略高于当前最佳工程水平，属**保守压力测试**，用于检验方案稳健性而非模拟典型系统。

### 3.2 硬约束：实验 1 与实验 2、4 必须共用场景族

自变量 $\Delta t = t_0 - t_{warn}$ 与 $\Delta t' = t_{reveal} - t_{warn}$ 都以实验 1 的标定为基准，而两个零点**均随车速与遮挡系统性变化**（遮挡直接改变光学膨胀率 $\dot{\theta}$ 越过知觉阈值的时刻）。故：

- 实验 1 按「情境（非盲区／盲区）× 车速（40／60）」**四个单元分别标定**；
- 实验 2 只能在已标定的非盲区单元内换算 $\Delta t$；实验 4 只能在已标定的盲区单元内换算 $\Delta t'$；
- 实验 3 与实验 5 已固定全部时间参数，可另设场景操纵（背景复杂度／遮挡几何／次任务负荷），不受此约束；但**实验 3 的次任务负荷区块须补一项声明**：负荷会把 $t_0$ 推后，故高负荷条件的名义提前量与实际提前量不等，两套并列报告；
- **被试安排**：实验 1 与实验 2 复用同一批被试（$\Delta t$ 需被试自身的 $t_0$）；实验 4 因 $t_{reveal}$ 被试间恒定，**无须复用被试**——这是零点由心理量改为几何量带来的第二项方法学收益。

## 四、研究一：非盲区情境

### 4.1 实验 2：单层预警的时间参数

**研究问题**：行人自始可见时，预警相对驾驶员自发察觉时刻应提前多少？触发准则应依据固定时间阈值还是减速度归一化量（BTN）？

**设计**：2（触发准则：固定时间阈值／BTN）× 3（$\Delta t$：0／+1.0／+2.5 s）被试内。区块 B 另比较持续与撤销三水平。

**水平依据**：
- $\Delta t = 0$ 为"与自发察觉同时"的对照；+1.0 s 对应 Scanning + Identification 的工程估计（Daimler 级联第二级间隔 1.0 s、Suzuki 等 1.0 s 档距双源支持）；+2.5 s 用于检验收益递减与代价递增。
- 触发准则的对照依据：同一 TTC = 2 s 在 40 km/h 下所需减速度 2.78 m/s²（BTN 0.35，温和制动），在 80 km/h 下 5.56 m/s²（BTN 0.69，接近全力制动）——固定秒数在物理上不可跨车速迁移，而人因侧从未做过准则类型的对照。
- 撤销侧沿用 Takada 等（2014）的 **2 : 1 滞环**（进入 4.0、解除 2.0 m/s²），原文目的即"避免极短促的报警"；这是本库中唯一以运动学量定义级间关系的先例。

**主要终点**：最小 TTMD（安全非劣）；次要终点为峰值减速度、jerk、TTFF、漏检率。

### 4.2 实验 3：空间参照系与锁定策略

**研究问题**：行人可见时，预警应锁定于屏幕、道路冲突点、行人目标，还是复合？该优劣序是否随背景视觉复杂度与次任务负荷变化？

**设计**：**主设计**为 5（Baseline／BD／BR／BW／BW+BR）× 2（背景视觉复杂度）被试内，共 10 单元；时间参数固定为实验 2 入选组合。

**次任务负荷区块**（对应主框架实验 4 的区块 F）：2（BD／BW）× 2（次任务负荷：纯音乐／意图诱导型听觉问答）被试内，共 4 单元，背景复杂度固定为高拥挤。采用「主设计 + 独立区块」而非 5 × 2 × 2 全因子，是为避免 20 条件设计使危险事件总数与疲劳不可控。

**证据基础与效应量预期**：
- Wu 等（2024，N = 36）三方对照：BW 首次注视 **617 ms**、BD **2563 ms**、BR **2730 ms**（60 km/h、TTC < 3 s、行人 1.5 m/s）。
- 但 Lind（2007）的四方对照显示：碰撞预警平视显示（本身即屏幕固定式前视野显示）制动反应时最快（快约 200 ms），漏报 **1 次** vs 方向盘 6 次、仪表 12 次、高位下视 17 次。
- **故 AR 的收益必须拆成位置增益与共形增益两项**。BD 条件已包含平视显示位置的大部分收益，BW／BR 相对 BD 的增量必然更小，**样本量估计须按更小的效应量做**。
- 背景复杂度以场景中同时可见的行人与车辆数量、路侧广告密度分两水平，并以图像统计量（边缘密度、颜色熵）报告操纵检查。
- **次任务负荷区块的三条判据**：① 采用**听觉—认知**次任务而非视觉—手动次任务，因本实验的主要终点是注视类指标，视觉类次任务会使「负荷升高导致 TTFF 延长」与「视线离开前方导致 TTFF 延长」不可分离（Lubbe 2017 的数字记忆任务须注视副驾屏幕，该研究因"二次任务期间视线回到前方"排除 5 名被试）；② 低负荷水平取**纯音乐**而非无任务，使听觉通道占用一致，避免把"有无声音"混入负荷操纵（两项定义均取自 Shen 等 2026 的沉浸度操纵）；③ 负荷类指标兼作**操纵检查量**，须先确认负荷主效应显著再解释交互，主分析报"锁定策略在各负荷水平下的增量"。
- **背景复杂度与次任务负荷是两类不同干扰源**：前者为外源性视觉竞争，后者为内源性中枢资源占用；前者主要延长视觉搜索，后者主要延长搜索之后的确认与决策，故分列检验而不合并。
- **假设与零结果的预先声明**：预期 BD 与 BW 的定位效率差在高负荷下更大。但 Shen 等（2026）是本库唯一交叉了显示参数与副任务沉浸度的研究，其「闪烁模式 × 沉浸度」交互 $F = 2.699$、$p = .126$ **不显著**，而沉浸度主效应 $\eta^2 = 0.886$ 极大。故负荷主效应几乎必然显著而交互可能为零；若如此，则结论为"负荷整体推高各条件的代价而不改变优劣序"，即**锁定策略推荐序可跨负荷水平迁移**——该结论对设计同样有用。

**并列主要终点**：漏检率与注视时长是否越过 2000 ms 分心上界（依据：贴地共形箭头曾把 HUD 图形注视时长推到 3.33 s）。

### 4.3 交叉迁移区块（嵌入实验 3）

## 五、研究二：盲区情境

### 5.1 场景族定义

沿用本库中两处已发表的遮挡范式，并统一到同一场景族：

| 要素 | 设定 | 依据 |
|---|---|---|
| 遮挡体 | 路侧停放的同色厢式货车（近距侧方）／路侧公交车（远距前方） | Merenda 等（2018）事件区左右各停 3 辆同色货车；Zhang 等（2024）路边公交车遮挡 |
| 行人位置 | 机动车道右边线外 2.5 m，斑马线外 | Zhang 等（2024） |
| 行人步速 | 1.0 m/s（主）；1.5 m/s（稳健性检查） | Zhang 等（2024）1 m/s；Wu 等（2024）1.5 m/s |
| 车速 | 40／60 km/h | 与实验 1 标定单元一致 |
| $t_{detect}$ | 距行人 100 m（≈ 6 s @60 km/h）设为 V2I／路侧探测可达时刻 | Zhang 等（2024）路侧 V2I 于 100 m 触发 |
| 显露几何 | $t_{reveal}$ 由遮挡体几何解析求出，并在实验 1 中以眼动与视线锥仿真双重验证 | 本框架 |
| 车—人间隙 | 落在 1.5–7 s，主实验取 3–7 s 的决策模糊带 | 综述转引，属场景合理性辩护，不作效应量依据 |

**工程可行性的三重约束**（须在场景设定中显式声明，否则实验条件不可实现）：
- 遮挡场景的最低时间预算 **1.66 s** = 1.5 s 意图预测 + 0.16 s 制动响应（Kim 等，2022）；
- 意图预测可提供的安全缓冲仅 **0.5–2.0 s**（Social-LSTM：15 帧 ≈ 0.5 s 观测窗、动作前 0.5–1.0 s 预测时域，Precision 85.02%／Recall 84.13%／F1 84.57%），**远小于**交叉口遮挡场景由制动动力学反推的 **6.07 s（视觉）／6.28 s（语音）** 需求（Chang 等，2009）；
- 行人预警硬下界 tLTTB = 碰撞前 **1.5 s**（Char，2022）。

> 第二条构成本研究必须显式承认的一处工程—人因缺口：**若仅依赖车载意图预测，盲区预警在物理上无法达到人因所需的提前量**；本研究的 $t_{detect}$ 设定因而依赖路侧／V2X 输入，此为结论的外部效度边界。

### 5.2 实验 4：盲区情境的时间参数与系统可靠性

**研究问题**：预警相对行人自然显露时刻应提前多少？预告区段是否具有独立价值？系统可靠性如何调节这一价值？

**设计**：4（$\Delta t'$：−0.5／0／+1.0／+2.5 s）× 2（可靠性：100%／80%）被试内，另加"无预警基线"对照。区块 B 比较分层语义分化与单层。

**水平依据**：
- **$\Delta t' = -0.5$ s**：预警发出于行人已显露之后 0.5 s，即**完全放弃预告区段**。此水平检验 P1′，是研究二独有的关键对照。
- **$\Delta t' = 0$**：预警与显露同时，仅省去 Scanning 的搜索成本，不提供预测窗口。
- **+1.0 s／+2.5 s**：与研究一的 $\Delta t$ 水平取值对齐，使跨情境比较（P2′）在同一刻度上进行。
- 上界校验：所有水平须满足 $t_{warn} \ge t_{detect}$；在 60 km/h、$t_{detect}$ 对应 6 s 的设定下，$\Delta t' = +2.5$ s 仍在可行域内。
- 虚警**只施加在第一级／预告级**，依据是"低行动要求级别上的虚警代价更小"这一可否证预测：Schall 等（2013）的 15%／15% 零效应取自"提示提前 11–13 s、警示级语义、不要求立即动作"的条件；而 Abe 与 Richardson（2006）的强效应取自"要求立即制动"的条件。

**区块 B：分层语义分化。** 这是盲区情境独有的分层设计。非盲区情境的 L1 与 L2 指向同一可见目标，仅强度不同；盲区情境的两级承担**本质不同的信息**：

| 级 | 时刻 | 语义 | 驾驶员可完成的加工 |
|---|---|---|---|
| **L1 预告级** | $t_{detect}$ 之后、$t_{reveal}$ 之前 | 「遮挡体后方存在一个你看不见的行人」 | Predicting、预置 Deciding |
| **L2 确认级** | $t_{reveal}$ 附近 | 「它现在出现了，在这里」 | Scanning、Identification、Deciding、Executing |

故**级间间隔在盲区情境下不是自由参数**，而由 $t_{reveal} - t_{detect}$ 即场景几何与传感架构共同决定——这与主线框架把级间间隔作为自变量（0.7／1.0／1.5 s）形成对照，是零点几何化带来的第三项后果。区块 B 因此比较"分层语义分化"与"单层（仅 L2）"，并设**状态条件化升级仲裁**：若 L2 之前已检测到有效减速（阈值取 −0.075 g），取消升级，并记录取消升级率、错误升级率与错误取消率。仲裁的必要性依据：Winkler 等（2018）报告 **50% 被试在预警呈现前已开始制动**。

**主要机制指标**：
- 预告区段内的**预期性注视**（向遮挡体边缘的注视比例与首次注视时间）——Predicting 的代理量，是 P1′ 与 P3′ 的直接证据；
- 显露区段内的行人 TTFF、I → E 链条时长；
- 信任量表、预告级依从率；
- 安全约束：最小 TTMD、碰撞率。

### 5.3 实验 5：盲区情境的空间锚定策略

**研究问题**：目标锁定（BW）在物理上不可实现时，预警应锚定于何处？最优锚定是否随遮挡几何变化？

**设计**：5（Baseline／BO／BR-p／DR／BD-dir）× 2（遮挡几何：近距侧方／远距前方）被试内；BO+BR-p 复合作为探索水平另设。时间参数固定为实验 4 入选组合。

| 水平 | 操作化 | 理论定位 | 主要风险 |
|---|---|---|---|
| **BO** 遮挡体锚定 | 高亮／描边绘制于遮挡体表面朝向行人的一侧 | 指示「危险来自这个物体后面」 | 构成 on-遮挡物构型；Chen 等（2023）报告外周视野下 on-HUD 危险漏检率最高且 RT 最长，**须检验掩蔽风险** |
| **BR-p** 推测地面锚定 | 贴地图形绘制于行人推测的地面位置（按探测轨迹外推），纵深按 $R_x = T_{tc} \cdot V_{car}$ 缩放 | 指示「风险将发生于何处」，即 BR 在遮挡条件下的自然延伸 | 外推误差直接转为空间误差；须报告配准误差 |
| **DR** 穿透显影 | 将遮挡体半透明化以显示其后行人（diminished reality） | 保持行人在原空间语境中被感知 | **深度歧义**（X-ray vision 的经典问题）；须测深度判断误差与不适 |
| **BD-dir** 屏幕方位指示器 | 屏幕固定的方向箭头，不做空间配准 | FOV 受限时的退化方案；对应主线框架"须退化为边界箭头"的工程边界 | 不携带精确位置信息 |
| BO+BR-p | 复合 | 检验互补性 | 负荷叠加；须检验注视时长是否越 2000 ms |

**遮挡几何两水平的设置依据**：Merenda 等（2018）报告 **17° 圆形 FOV 下近距侧方行人的共形图形移出视场而彻底失效**。量产显示 FOV 当前仅 10°–15°，而文献方案要求 40°–85°。故本实验按"近距侧方"与"远距前方"两种几何交叉，直接检验 P5′（最优锚定随几何反转），并据此界定哪些方案在量产 FOV 下可实现。

**图形参数固定项**（不作为自变量，按四源收敛区间取值）：
- 不透明度取 **0.6**：四源收敛于 0.6–0.75；Hou 等（2025）报告 T0.75 的无意视盲最低而 T0.5 的反应时最短且满意度最高（安全最优与体验最优分离），Li 等（2025）给出"至少 0.6"，Lopez 与 Moacdieh（2025）报告 20% 与 60% 均支持情境意识。取 0.6 同时满足两侧构念。
- 颜色取**红与黄**（日夜鲁棒色对，Zhong 等 2022 在实车上比较 42 种组合：日间黄 4.12 > 绿 3.92 > 红 3.08，夜间红 3.88 > 黄 3.80，蓝紫两种照度下均最差，白色描边多数情况下更优）。
- 闪烁状态在所有条件间**固定**。依据：Hou 等（2025）原文结论为"动效对无意视盲无显著影响，仅闪烁缩短反应时"，故条件间闪烁不一致会使反应时差异完全可归因于闪烁。
- 动画**不得与本车运动耦合**。依据：Merenda 等（2018）报告与车辆运动耦合的动画在 2 s TTC 高紧迫度下产生负的停车间隙（即理论碰撞）。

**并列主要终点**：显露后行人 TTFF、漏检率、**遮挡体误锚定率**（驾驶员将注意锁定于遮挡体而非行人的比例，BO 条件的特有风险）、深度判断误差（DR 条件）、晕动与不适评分。

### 5.4 交叉迁移区块（嵌入实验 5）

在实验 5 末尾追加区块：把**研究一入选的非盲区方案**（含其时间参数与 BW 锁定）直接施用于盲区场景。BW 在此条件下必然退化为对遮挡物的锚定，故该区块同时是 P6′ 的检验与 BD-2（BW 不可实现）的实证演示。

## 六、假设汇总

### 6.1 由理论导出的可否证预测

| 编号 | 预测 | 来源 | 否证条件 |
|---|---|---|---|
| **P1′** | $\Delta t' \le 0$（放弃预告区段）绩效显著劣于 $\Delta t' > 0$ | §2.2 SPIDER 分段 | 两者无显著差异，或 $\Delta t' \le 0$ 更优 |
| **P2′** | 盲区最优 $\Delta t'$ 显著大于非盲区最优 $\Delta t$ | §2.2 + Merenda 刺激驱动 | 两者相等或盲区更小 |
| **P3′** | 预告区段收益单调递增但存在饱和 | §2.2 | 线性无饱和，或倒 U 型 |
| **P4′** | 80% 可靠性对盲区预警的信任损伤显著大于对非盲区预警 | §2.3 不可核验性 | 损伤相当或方向相反 |
| **P5′** | 最优锚定策略随遮挡几何反转（近距侧方 BD-dir 优、远距前方共形优） | §2.4 FOV 17° 失效 | 存在跨几何一致的单一最优 |
| **P6′** | 双向迁移损失显著大于零 | §2.5 | 迁移损失不显著 → **本框架的切分不成立，应退回单情境处理** |

### 6.2 由文献归纳的假设

| 编号 | 假设 | 主要文献依据 |
|---|---|---|
| H1′ | 盲区预警使油门松开与首次制动位置显著提前，且峰值减速度下降（收益形式为制动平顺化而非仅反应时缩短） | Zhang 等（2024）：提前 36.29／39.10 m、\|a\|max 降 3.45 m/s²、最小冲突距离 +9.41 m；Chang 等（2009）：紧急减速率 3.10–3.56 → 2.77–3.18 m/s² |

## 七、统一指标体系与判定原则

### 7.1 指标层级

| 层级 | 非盲区情境指标 | 盲区情境**新增／改变**的指标 |
|---|---|---|
| 安全 | 最小 TTMD、碰撞率、最小冲突距离 | 同 |
| 行为 | 松油时刻、制动启动、峰值减速度、jerk | 同，但计时零点改为 $t_{reveal}$ |
| 眼动 | TTFF（警告）、TTFF（行人）、道路注视比例、注视时长 | **新增：预告区段内向遮挡体边缘的预期性注视比例与首次注视时间**；**新增：遮挡体误锚定率** |
| 认知 | 路径侵入预测正确率、冲突点空间误差 | **新增：DR 条件的深度判断误差** |
| 代价 | 漏检率（未增强危险）、无意视盲率、DALI 负荷 | 同，且漏检率**升格为第一约束**（H4′） |
| 主观 | 信任量表、依从率、接受度 | 同，且信任为 P4′ 的主要终点；**新增晕动与不适（DR 条件）** |

### 7.2 判定顺序

不评选单一冠军，按以下顺序逐级筛选，结果以 **Pareto 前沿**呈现：

1. **安全非劣**：最小 TTMD 的组间差下限 > −0.2 s，且碰撞率不高于基线；
2. **漏检非劣**：未增强危险漏检率不高于基线（盲区情境下此条前置至第 2 位，依据 H4′）；
3. 制动更平顺者（峰值减速度、jerk）；
4. 认知代价更低者（负荷、注视时长不越 2000 ms）；
5. 低可靠性下退化更小者；
6. 仅在上述条件相当时，才以反应时与主观偏好定选。

### 7.3 共同方法学规范

- 被试内设计 + 混合模型，被试与场景为随机效应；反应时按右偏分布处理。
- 主要结局预注册；次要结局 FDR 校正。
- 眼动采用动态 AOI、有效率不低于 80%，**并区分四类 AOI**：警告 AOI、真实行人 AOI、**遮挡体 AOI**、未增强危险 AOI。
- 报告估计差、95% 置信区间与效应量；"无显著差异"不解释为等效。
- **试次间隔取 60 秒**：SPIDER 2.0 转述的证据显示次任务结束后分心影响仍持续 30 s 以上，取 60 s 留一倍冗余；插入 filler 与 catch trials 抑制预期与习惯化。
- **盲区情境的额外规范**：遮挡场景高度可预期，被试经数试次即可学会"货车后必有行人"。故须（a）以 filler trials 稀释遮挡事件密度至不超过总事件的 1/4；（b）设置**遮挡体后无行人**的 catch trials 以测虚警条件下的行为；（c）在分析中把试次序号作为协变量以检验学习效应；（d）报告首个遮挡试次的单独分析结果作为"无预期"条件的近似。
- 样本量以最小具有实际意义的差异加混合模型模拟确定，并按预实验方差与约 10% 的眼动无效或晕动脱落重新计算。DR 条件的脱落率按 15% 估计（含晕动）。

## 八、结论边界（须在论文中声明）

1. 短期模拟驾驶、视觉 AR-HUD、城市行人横穿；不外推长期使用与最后时刻的多模态干预。
2. **盲区限于单一遮挡体的几何遮挡**；多重遮挡、动态遮挡（行进中的车辆造成的间歇遮挡）、以及天气造成的能见度下降均不在范围内。
3. $t_{reveal}$ 的解析解依赖遮挡体几何与驾驶员眼点位置，**跨车型须重算**；本研究提供解析式而非固定秒数。
4. $t_{detect}$ 在模拟器中为程序设定，**非真实传感器性能**；实际系统的 $t_{detect}$ 受遮挡比例影响而退化，该退化曲线为本研究的已知缺口（见 `盲区证据台账.md` S-05）。
5. 本研究的 $t_{detect}$ 设定依赖路侧／V2X 输入；仅依赖车载意图预测时，其可提供的 0.5–2.0 s 缓冲不足以支撑所需提前量（§5.1）。
6. DR（穿透显影）条件的绩效受模拟器渲染保真度限制，其结论不可外推至真实光学 AR-HUD。
7. 遮挡场景的可预期性无法完全消除，故本研究的效应量应视为对真实"鬼探头"事件效应的**保守低估或高估方向不明**，须在讨论中并列两种可能。
