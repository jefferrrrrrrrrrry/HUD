文献综述概念界定：HUD 与 AR-HUD2.1.1

AR-HUD（增强现实抬头显示）是把图形与车外真实目标逐帧配准的抬头显示；其图形随目标在视野中的位置、大小、遮挡关系连续变化 （Yoon 等, 2014；Kim 等, 2018）。汽车 HUD 始于 1988 年通用 Oldsmobile Cutlass Supreme，相对低头显示可缩短约 0.2 s 反应时 （Yoon 等, 2014 转引 Horrey 等）。
代际显示方式信息与场景的关系典型内容
传统 HUD屏幕固定 screen-fixed图形位置与车外场景无空间对应，仅占据视野中一块固定区域车速、导航箭头、油量
AR-HUD世界锁定 world-locked／共形 contact-analog图形位置与车外目标逐帧配准行人边界框、路面虚拟阴影、车道增强、冲突区标记
必须在一开始澄清的概念混淆：「屏幕固定」与「显示位置」是两个独立维度。Lind（2007）的四方对照表明，碰撞预警平视显示（CWHUD）本身即屏幕固定式，其相对仪表显示已快约 200 ms、漏报少 16 次。因此讨论「屏幕固定的局限」时，比较对象必须是同在前视野的世界锁定图形，而非仪表显示。忽略这一点会系统性高估共形性的边际收益。
量产硬约束：显示 FOV 当前约 10°–15°，而文献提出的车速—FOV 耦合方案要求 40°–85°（Ma 等, 2021；Teng 等, 2023）——数倍落差意味着大量实验室有效方案在量产车上根本画不出来。

文献综述理论基础：SPIDER 五阶段2.1.5

SPIDER = Scanning · Predicting · Identifying · Deciding · Executing Responses。由 Strayer 与 Fisher（2016）提出，Strayer 与 McDonnell（2025）更新为 SPIDER 2.0 （*Human Factors*，JCR Q1，IF 3.6；*Annual Review of Vision Science*）。选它而非 PIEV 的两个理由：PIEV 的 Emotion 阶段无法操作化；SPIDER 本身围绕分心构建，能同时容纳「AR 帮助注意」与「AR 造成注意隧道」两种效应。

文献综述预警出现时机的证据谱2.2.1

读图要点：① 落在无效区的全部是分层体系中的提示级（Lubbe 的 2.5 s、Phan 的 2.0 s），它们并非独立生效——单层与分层的阈值不可互相迁移；② 收益递减区的两项（Kim 5.0 s Far、Wang ≤ 5 s）分别表现为过度反应与无增益，方向不同但都指向同一结论；③ 4.0 s 的绿色虚线是人类意图判别力的峰值——即使换成一位熟练驾驶员，在 5 s 时也有 55% 虚警率。

三类持续时长范式（报告率 < 15%）

  • 至危险解除型：最普遍但最缺量化。Kim 等（2018）虚拟阴影持续更新至危险解除；Ma 等（2024）风险解除后面积与饱和度逐渐减小直至消失

  • 动态强度调制型：Huo 与 Alla（2025）闪烁持续；Wu 等（2024）动态跟随把「持续显示」转化为「动态行为」

分层必要性的最强单条证据

Zhang 等（2015）：TTC 2.5 s 单层预警与无预警无显著差异（29.4% vs 44.1%），有效下限 3.0 s。

升级仲裁：一个被普遍忽视的规则。Winkler 等（2018）报告左转侵入场景中 50% 被试在预警呈现前就已开始制动。若不设仲裁，则近半数试次中 L2 会对一个已在制动的驾驶员喊「立即制动」。本研究据此设「状态条件化升级仲裁」：若 L2 前已检测到有效减速（aego < -0.075 g，阈值取自 Phan, 2016）则取消升级，并记录取消升级率／错误升级率／错误取消率。

文献综述三个时间窗的张力：需求 > 人类 > 算法2.2.6

本领域一个根本性的张力：需求（6.07–6.28 s，Chang 与 Chang, 2009）远大于人类判别上界（TTA 4 s 峰值，Chen 等, 2019）；后者又远大于算法预测上界（动作前 0.5–1.0 s，Cangut 与 Alver, 2026）。本领域实证研究几乎全部把预警设在 2–5 s——这个区间不是任何一侧的最优值，而是「算法勉强能判、人还来得及反应、虚警率尚可接受」三者的交集。
对本研究的含义：「把预警设得更早」在工程上并非可自由选择的方向。实验 1 的 Δt = +2.5 s 水平（相对 t0 ≈ 3.2 s 即绝对约 5.7 s）已接近甚至超出人类判别的可靠上界，因此 H2（收益递减 + 代价递增）有很强的先验支持。

冲突三：级间间隔 0.7 s 是最优还是偏小？

  • 0.7 s 是孤证而非最优值：Lubbe（2017）的 0.7 s 从未与其他间隔对照——它是该研究采用的唯一一个级间间隔。「0.7 s 有效」只能读作「不至于失效」，不能读作「最优」。既有综述把它当最优值引用，属于把单点证据外推为最优点。
  • 本研究的工作假设指向 1.0 s：L1 需承担 Scanning + Identifying，S + I ≈ 0.9–1.2 s；短于此则两级警告可能在知觉上融合为单一刺激，分层的语义结构失效。
  • ⚠ 必须声明的降级：该推导不是 SPIDER 原文参数。1.0 s 的主要依据应是工程证据——Daimler 级联第二级间隔恰为 1.0 s、Suzuki 等档距恰为 1.0 s，两个独立来源在同一数值上汇合；SPIDER 推导只作事后的机制解释。
  • 新提炼的规律：级间间隔随紧迫度单调缩短（Daimler 1.4 → 1.0 → 0.5 s）；与 Takada 等（2014）2 : 1 滞环「避免极短促报警」从两个方向界定同一约束。
转化：三水平取值保留（0.7 / 1.0 / 1.5 s），但论证方式从「取自 Lubbe + 两侧插值」改为「四源夹逼区间 0.5–2.0 s 的中段 + 双源支持的 1.0 s 中心值 + 单调缩短规律」。理论定位：0.7 s 短于加工窗口（检验融合下界）· 1.0 s 恰好覆盖（理论中心）· 1.5 s 长于窗口（检验收益递减）。

来源结论驾驶模式信息关系
Wang 等（2024）DSID信息越完整越好：三元素俱全者最好；同时提升 SA 与避险能力、降低负荷手动驾驶互补功能（预警 + 空间 + 速度，各回答不同问题）

冲突五：图形应指向危险侧还是逃逸侧？（本轮新识别的维度）

Kang 等（2016）：听觉行人预警中刺激—反应不兼容（提示回避方向而非危险方向）优于兼容；配合 TTC 4.0 s 时「更可靠、更有用」（仅摘要）

Straughn、Gray 与 Tan（2009，IEEE Trans. Haptics）：长 TTC 用危险侧方向、短 TTC 用逃逸方向——经核验该文本身即行人碰撞预警的 S-R 兼容性研究，属一手来源（本课题此前误标为「经 Gray 等 2014 转引」）

外部效度边界：两项证据均为听觉／触觉预警。视觉 AR-HUD 的图形若指向「逃逸方向」而非行人所在，可能与共形配准的基本逻辑冲突——AR 的价值正在于把图形贴到危险对象上。
→ 本研究定位为探索性区块（实验 3 区块 D），不作主设计。
预注册的条件化推断规则（不预设方向）：若「映射方向 × 提前量」交互显著 → 支持 Straughn 的时间依赖假设；若仅主效应显著 → 支持 Kang 的单向假设。必须在数据采集前写入预注册文件，以避免事后解释。

冲突六、七：两组 B 类（记法／口径）冲突

冲突六　不透明度 3 倍（本轮已裁定）：① 记法已定——Ye 与 Yin（2025）把 Hou 等的 T 标尺当作「提升可见性的 0.75」使用，故 T 功能上是 alpha，最优换算为 0.5–0.75；② 剩余差异是构念而非矛盾——Lopez 原文为「20% 与 60% 均支持情境意识」，未推荐 20%，与 Li 等在 0.6 上一致。四源收敛 0.6–0.75。
处理更新：主条件仍取 0.6（交集的保守下界），0.2 档的检验目的从「消解记法不确定」改为「检验遮挡收益是否超过可读性代价」。

冲突七　频率 8 倍 vs 占空比接近：4 Hz/60% 与 0.5 Hz/50%。
机制假设：占空比决定单位时间总光通量与亮灭时长比，频率只决定重复速率。Shen 等「无闪烁最差」说明至少需有 onset 事件，「50% 优于 75%」说明并非 onset 越多越好。
处理：全条件统一动效参数（周期 2 s、占空比 50%）或全不闪烁，不得让锁定策略与闪烁状态共变。

方法学意义（两层）：① 记法不统一而无法取得全文时，应把不确定性显式转化为敏感性检验，而不是挑一个数值当定论。
② 本轮新得：B 类冲突有时可由「引用者如何使用该参数」间接裁定——原文不可得时，一篇引用并复现其设置的开放获取文献，往往在方法节保留了记法方向的判据。代价是证据等级降为间接。
须记录的漏检：Hussain 与 Park（2023, IJHCI）专题研究「透明度水平 × 真实背景」，与本参数直接相关却不在本库 102 篇内。

H2Δt = +2.5 s 相比 +1.0 s 反应时无显著增益，但主观负荷与侵入性更差（收益递减 + 代价递增）。
→ 被推翻意味着「越早越好」成立，上界线需重估
H3BTN 归一化触发的跨车速效应一致性显著优于固定时间阈值（即「准则 × 车速」交互显著）。
→ 被推翻意味着固定 TTC 阈值已足够，无需引入 BTN
H4级间间隔存在倒 U 型峰值且峰值位于 1.0 s；分层增益主要位于 Identifying 与 Deciding 而非 Scanning。
→ 被推翻时 1.0 s 的工程依据仍成立，只是失去理论解释

H5–H14：由文献归纳的方向性假设（摘要）

  • H5　折中窗口存在，其位置由 Δt 而非绝对 TTC 决定
  • H6　状态维持或适中时长降低漏检，过长增加注视吸附
  • H7　风险耦合衰减在漏检率与视觉占用上同时优于固定时长与纯状态维持
  • H8　分层相较最佳单层方案降低急刹与负荷，同时保持安全余量
  • H9　80% 可靠性下分层优势显著衰减、L1 依从率下降；低可靠性时 1.5 s 级间反而更稳健
  • H10　级间间隔存在最优区间，过短来不及理解，过长造成重复
  • H11　BW 定位效率优于 BD/BR；BW+BR 改善情境理解但增加负荷
  • H12　风险量级动态促进紧迫度判断，轨迹动态促进路径预测
  • H13　组合动态只在未显著增加负荷时优于单一动态
  • H14　时间分层与空间动态共同通过缩短目标验证时间（SPIDER 的 I 阶段）改善绩效
全部为待检验假设。H14 属跨实验整合推断，只有在实验 2 与实验 4 的中介阶段指标均提供一致证据时，才可作为机制性结论。

研究问题研究框架2.5.4

五个实验的递进逻辑（这也是本研究不是「五个并列小实验」的理由）：实验 0 提供零点与下界（t0 分布 → 实验 1 自变量换算基准；PRTp95 → 可避险区校验；t0 时刻 BTN → 触发阈值校准；acomf 实测 → 全部实验的归一化分母；方差成分 → 样本量估计）→ 实验 1 建立单层时间基线 → 实验 2 升级为分层规则并检验低可靠性稳健性 → 实验 3 固定全部时间参数只比较「锁定在哪里」 → 实验 4 固定时间与空间载体只比较「如何随风险变化」。

文献综述「最优设计」的判定原则2.5.4

本研究不评选单一「冠军条件」，而采用约束优先的多指标判定顺序。报告形式为在（安全收益，虚警代价）与（安全收益，认知代价）两个平面上给出各条件的 Pareto 前沿位置。
顺序判定理由
1首先满足安全约束碰撞率不升高、最小 TTMD 不劣于对照（预注册非劣界：组间差值下限 > −0.2 s）
2在安全条件中选制动更平顺者峰值减速度与 jerk 较低——避免把「更快但更急刹」误读为更安全
3再选认知代价更低者注视熵、道路离视比例、主观负荷——避免把「注视更久」误读为「更关注」
4再选在 80% 可靠性下退化更小者避免选出一个只在完美系统下成立的方案
5仅在上述条件相当时，以反应时与主观偏好作最终依据并列时选择更简单、侵入性更低的方案
这一顺序的必要性由本章的辨析直接支持：若只看反应时，则 Kim 等（2018）的 BRAKE 文本在 Far 条件下会被判为「有效」（驾驶员确实更早制动），而其 +34.46% 的峰值减速度上升会被忽略。同理，若只看主观偏好，则 Wang 等（2025）的红地毯（16/21 偏好）会胜过虚拟墙，而后者的让行成功率才是显著更优的。
五条由方法学质量导出的设计约束：① 不得沿用文献典型样本量，须由实验 0 的方差成分反推；② 不得把零结果读作无效应，须报告效应量置信区间；③ 必须实测并报告系统渲染延迟；④ 必须完整报告六项视觉参数；⑤ 必须预注册反应时清洗规则（0.2–2.9 s）与注视定义（最小 80 ms、最大离散 100 像素）。
