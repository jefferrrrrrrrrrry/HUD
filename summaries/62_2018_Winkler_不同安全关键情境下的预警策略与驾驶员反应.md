## 一、研究背景与问题

### 1.1 领域现状
- 城市环境是当前 ADAS 的短板：德国自 1991 年起约 **3/4** 的警方记录事故发生在城区，2011–2013 年人身伤害事故的约 **69%** 也在城区（Statistisches Bundesamt, 2014）；2013 年德国城市道路三类最常见事故为「转入或横穿道路」**26%**、「同向行驶」**21%**、「转出道路」**16%**，合计近 2/3；而**死亡最多的是横穿道路的弱势道路使用者，占 27%**。
- **多级预警（multi-stage warning）**是共识方向：从不显眼的信息/早期预警，随危急度升级为更紧迫的预警，最终可能自动介入（引 Campbell et al., 2007；Diederichs et al., 2010；Naujoks & Neukum, 2014；Werneke et al., 2014；Winkler et al., 2016, 2018a, 2018b；Zarife, 2014）。
- **HUD 的优势与风险**：HUD 把符号投在发动机盖上方、与道路现实在视野中重叠，使视线保持在路面（Hanowski et al., 1999；Horrey et al., 2003；Lee et al., 1999；Luoma & Rämä, 2002）；只需眼调焦而无需眼动/头动，可显著缩短响应时间（Ablaßmeier et al., 2007；Azuma, 1997；Watanabe et al., 1999）。但若设计不当会抬升负荷，造成**认知/视觉/知觉隧道效应（tunneling）**，视野收窄、外周检测受损（Dirkin, 1983；Gish & Staplin, 1995；Mackworth, 1965；Williams, 1985）；也可能因视觉杂乱或对比干扰发生认知俘获与视觉掩蔽（Green et al., 2008；Ward & Parkes, 1994）。

### 1.2 研究缺口
1. 多数 ADAS 只在**单一用例**中验证（如 Ben-Yaacov et al., 2002；Benmimoun et al., 2007；Lee et al., 2002b；Werneke & Vollrath, 2013），难以外推与形成通用设计建议。
2. 既有的「预警特异性（specificity）」研究（Naujoks & Neukum, 2014；Thoma et al., 2009；Brown et al., 2017）都**附加了听觉信号**，可能掩蔽视觉设计的效应；且大多只考察**注意导向型**的早期预警，未延伸到**反应导向型**的紧迫阶段。
3. Thoma et al. (2009) 让被试仅观看视频而非真实驾驶，注意力条件与真实驾驶不同。

### 1.3 核心研究问题
- 一个统一的视觉预警提示能否覆盖城市环境中多样的安全关键情境？
- 预警的**策略**（注意导向 attention-oriented vs 反应导向 reaction-oriented）与**特异性**（通用 generic vs 具体 specific）如何影响碰撞率、制动反应时、最大制动力，以及主观的可理解性与有用性？
- 假设：有预警优于无预警；预警类型影响行为与主观评价，且其适宜性随场景变化。

## 二、研究方法

### 2.1 被试与样本
- 招募 66 人，**6 人因模拟器晕动症被排除**，最终 **60 名驾驶员**（女 27、男 33），M = 23.7 岁（SD = 3.7），驾龄 M = 5.7 年（SD = 3.6）；年行驶里程多数 **< 3000 km**（多为无车大学生）；视力或矫正视力正常；报酬 12 € 或课程学分。

### 2.2 实验设计（混合设计）
- **被试间因素：预警类型（5 水平）**
  1. **C**（control）无预警；
  2. **RG**（reaction generic，反应通用）= 所有场景均显示**停止标志（stop symbol）**；
  3. **RS**（reaction specific，反应具体）= 在可规避场景显示「转向符号（steer symbol）」（红白条纹交通锥 + 侧向箭头），其余场景显示停止标志；
  4. **AG**（attention generic，注意通用）= 红色警告三角形内含**感叹号（caution sign）**；
  5. **AS**（attention specific，注意具体）= 警告三角形内**绘出具体危险对象**（行人 / 骑车人 / 前车 / 交通锥）。
  - 符号选型依据前测与文献：（红色）警告三角**能吸引注意但更偏信息性**，故用于注意导向策略；**停止标志更具激活性**，故用于反应导向策略。红色与特定形状本身也起警示作用（Bhatia, 2003；Campbell et al., 2004；Young, 1991）。
- **被试内因素：场景（8）× 试次（2）**，故每人共遭遇 **16 次**关键事件；8 个场景顺序随机化以控制时间效应。
  - 8 场景代号与内容（据正文散见描述复原）：**PS** 行人在直路横穿、**PI** 行人在左转处横穿、**BI** 骑车人在左转处横穿、**BT** 骑车人在右转/T 字路口后横穿、**LI** 前车在交叉口停车、**LS** 前车在直路制动、**OH** 坡后障碍物（干草捆/交通锥）、**OC** 弯道后障碍物阻路。
  - RS 组的符号分配：**PI、BI、BT、OH → 停止标志**；**PS、LI、LS、OC → 转向符号**（因这些场景规避机动更合适）。
  - AS 组：PI/PS = 行人图标；BI/BT = 骑车人；LI/LS = 汽车；OC/OH = 交通锥。
- **统计**：
  - 主观危急度、预警可理解性、有用性：2×8×5 混合设计 ANOVA + Bonferroni 事后两两比较；违反球形假设时用 Greenhouse-Geisser 校正；
  - 碰撞频次：GEE 框架下的二元 logistic 回归（被试为随机效应，可交换协方差结构；**因未收敛而未纳入交互项**）；
  - 制动反应时与最大制动力：线性混合模型（REML 估计，被试为随机效应，复合对称协方差），纳入 3 主效应与全部二/三阶交互；
  - 显著性水平 *p* ≤ .05；效应量报告 η² 或 *r*；均值均以 **95% CI** 为误差界。软件 IBM SPSS 23。

### 2.3 实验材料与设备
- **模拟器**：TU Braunschweig 静态中等保真模拟器；含真实车内件（座椅、力反馈方向盘、油门与刹车踏板）、三块 LCD 作后视镜；三块投影屏距驾驶座**约 2.1 m**（正前 1.85 m × 2.10 m，左右各 1.85 m × 2.20 m），三台投影机分辨率 **1400 × 1050 px**；驾驶仿真软件 **SILAB**（WIVW）；**180° 视场**；含风噪与发动机声。被试拥有完整横纵向控制权。
- **HUD 参数（本课题关键）**：预警以**多彩 HUD** 呈现，位置为**驾驶员中心正前、发动机盖正上方**；**尺寸最大 21 cm × 21 cm，对应 6° 视角**。**仅视觉模态，无附加听觉或触觉信号**（为避免掩蔽视觉设计效应）。
- **道路**：城区，**限速 50 km/h**；主体为大致直路以降低晕动症风险；左右转由语音提示 + 仪表盘转向箭头指示；场景之间为普通城市交通、无额外关键事件。
- **数据记录**：SILAB 以 **60 Hz** 记录全部驾驶行为（位置、速度、踏板与方向盘活动）；用 Dikablis 眼动眼镜 + Ergoneers D-Lab 记录注视行为——**但因 HUD 常在视野中与安全关键对象重叠，人工判读也近乎猜测，本文最终放弃注视行为分析**（PS 场景的部分结果见 Winkler et al., 2015）。

### 2.4 任务与流程
- 书面知情同意 + 人口学问卷；**15 min 训练驾驶**熟悉模拟器；两条指导语：(1) 提示可能出现危急情境；(2) 介绍主观评分流程。有预警组仅被告知「有 HUD 碰撞预警辅助」，**不解释符号含义**，以检验直觉可理解性。
- 正式驾驶 = **2 个 trial，每个约 15 min，各含 8 个场景**，中间短暂休息。每个场景结束后车辆短暂停车（由前屏横幅提示），被试在中控触摸屏（车载收音机高度）上完成 3 项主观评分。
- **主观量表**：Heller (1982) 两级评分——先在 5 个有标签类别（very low / rather low / moderate / rather high / very high）中选一，再在 3 个子级（−, 0, +）中细化，转换为 **1–15 分**。3 个条目：情境危急度、预警可理解性、预警有用性。
- 实验以简短访谈收尾以核验被试对符号含义的真实理解；全程约 1.5 h。

## 三、关键指标与测量（时间类指标重点标注）

| 指标 | 单位 | 操作化定义 |
|---|---|---|
| 碰撞频次 | %（原始为次数） | 遭遇安全关键对象时自车撞上的次数 |
| **制动反应时（brake reaction time）** | s | **从预警起始（warning onset；对照组为名义起始时刻）到刹车踏板被踩下的时间**；纳入条件 **≥ 0.2 s**，含碰撞事件 |
| 最大制动力（brake maximum） | % | 预警起始后到车速为零或释放刹车前，刹车踏板的最大踩踏量（占样本最大值的百分比） |
| 情境危急度 / 预警可理解性 / 预警有用性 | 1–15 | Heller (1982) 两级量表 |

**关于「预警时机」的关键说明（对本课题极重要）**：
- 作者明确写道：本研究**通过把预警起始时刻适配到不同安全关键情境，从而「排除了时机（timing）这一问题」**（§1，与 Naujoks & Neukum 2014 的对比处）。
- 触发方式：安全关键对象与预警的触发**基于自车穿过指定路标（landmarks）**，触发点由前测确定。
- **「由于技术约束以及场景的复杂性与多样性，本研究无法使用 time-to-collision 阈值（作者期望未来研究可以）」**（§2.2 末）。因此本文**不提供 TTC 阈值数据**。
- 各场景的具体预警触发点写在 Table 2 中，但该表在 PDF 中为图片形式，**本地文本抽取未取到其单元格内容**——如需逐场景触发点，须回看 PDF 第 4 页 Table 2。

### 数据剔除规则（时间参数相关）
- 约 **16%** 的安全关键对象遭遇中，被试仅松油门减速或制动过晚，被作为离群值剔除（**制动反应时截断值 2.9 s，g 水平 3.0**）；此类情况在 **PI、LI 与两个骑车人场景**尤为常见。
- 另有被试在**预警起始之前**就制动，或反应时 **< 0.2 s**（被认为是响应预警的最短可能时间），亦被剔除；**LI 场景有一半数据点因此丢失**。
- 最终两个制动参数各纳入 **77%** 的数据点。所有含交叉口的场景都是问题场景（被试可能因预判复杂路况而提前减速）。

## 四、主要结果与发现

### 4.1 情境危急度（操纵检验）
2×8×5 混合 ANOVA：**场景主效应** F(5.4, 295.6) = 75.58, *p* < .0001, η² = 0.58；**场景 × 试次交互** F(5.4, 295.6) = 2.97, *p* = .01, η² = 0.05；试次主效应边缘显著 F(1,55) = 3.46, *p* = .068；**预警类型无主效应** F(4,55) = 1.09, *p* = .371。
危急度排序（1–15 分）：
- **PS（行人直路横穿）= 最危急，M ≈ 13（very high）**；
- 其次 BI（骑车人左转处横穿）与 PI 第一试次（rather high）；
- 中等：PI 第二试次、BT、LI、OH，以及 LS 第二试次；
- 较低：LS 第一试次与 OC 两试次；**OC ≈ 6（rather low）为最低**。
- 危急度随重复变化约 **1 个量表点**，方向随场景而异（多数场景第二次更不危急，但 **BI、BT、LS 反向**）。

### 4.2 碰撞
- GEE：**场景主效应** χ²(7) = 118.76, *p* < .001, *r* = 0.35；**试次主效应** χ²(1) = 5.14, *p* = .023, *r* = 0.07；**预警类型无主效应** χ²(4) = 5.92, *p* = .205（交互因统计约束未能分析）。
- 总体碰撞率约 **13%**：**960 次**安全关键对象遭遇中记录 **120 次碰撞**；第二试次比第一试次少 **5%**。
- 分场景：**PS 约 48%**（几乎一半遭遇撞上横穿直路的行人）、**BI 27%**、**PI 12%**、**LI 12%**、**LS 3%**、**BT / OH / OC 均为 0%**。
- 描述性上：**对照组 C 碰撞最多（17%），RG 组最少（8%）**。

### 4.3 制动反应时与最大制动力
- 线性混合模型：**制动反应时**——scenario F(7,616) = 17.8, *p* < .0001；warning type F(4,64) = 4.97；trial F(1,630) = 23.96；**scenario × warning type 交互显著**（原文表 7 的 p 值排版有错位，正文明确称该交互与三主效应均显著）。
- **学习效应**：第二试次比第一试次快 **0.16 s**（T1: M = 1.20 s ± 0.05 s, n = 374；T2: M = 1.04 s ± 0.04 s, n = 366）；该学习效应**不与场景或预警类型交互**。
- **最快制动出现在 PS（行人横穿直路）**，因其留给驾驶员的反应时间最短；PS 与除 LI 外的所有场景差异显著（*p* ≤ .001）。
- **有预警 vs 无预警（核心结论）**：4 个预警组的制动反应时**均显著快于对照组**：C–RG *p* = .001；C–RS *p* = .014；C–AG *p* = .019；C–AS *p* = .007。**4 个预警组之间无显著差异**。
- **均值（总体，M ± 95% CI）**：
  - 对照 **C：制动反应时 1.4 s ± 0.1 s；最大制动力 45% ± 6%**
  - **RG：1.03 s ± 0.06 s；68% ± 4%**
  - **AS：1.05 s ± 0.08 s；60% ± 5%**
  - **RS：最大制动力 46% ± 5%**（与 C 相近；反应时正文未单列均值）
  - **即 RG 相对 C 快约 0.37 s，AS 相对 C 快约 0.35 s。**
- **场景 × 预警类型的方向性差异（描述性）**：**AS 在很危急/较危急场景（BI、PI）更有利**；**RG 在中等到较低危急场景（OH、LS、OC）更有利**；在最危急的 PS 场景，各预警概念的制动反应时**相当接近**。
- **最大制动力**：scenario F(7,611) = 84.71, *p* < .0001；warning type F(4,60) = 4.70；**trial 无主效应**；scenario × warning type 交互显著。事后仅 **RG** 与他组差异显著：**RG–C *p* = .007；RG–RS *p* = .001**。RG 在几乎所有场景取得最高制动力（除 LI 与 BI，后者由 AS 最高）。

### 4.4 主观评价
- **可理解性**：warning type F(3,44) = 5.32, *p* = .003, *r* = 0.27；scenario F(5.0,222.0) = 6.67, *p* < .0001；trial F(1,44) = 14.91, *p* < .0001（T1 M = 9.8 ± 0.4 → T2 M = 10.5 ± 0.3）；**scenario × warning type 交互** F(15.1,222.0) = 5.84, *p* < .0001, *r* = 0.29。
  - **RG 与 AS 理解最好（均 M = 11 ± 0.4，rather high）**；AS 显著优于 RS（M = 9，moderate）与 AG（M = 10）：**AS–RS 与 AS–AG 均 *p* = .016**；RG 与二者差异不显著（*p* = .142）。
  - **LI 场景可理解性最低**，与半数被试在预警前即已制动、因而不理解为何触发预警有关。
- **有用性**：仅 scenario 主效应显著 F(4.5,197.5) = 5.35, *p* < .0001；trial × scenario 边缘显著 F(5.0,219.7) = 2.17, *p* = .058；**预警类型无主效应** F(3,44) = 1.04, *p* = .384——即**四种预警都被接受**，评分从 moderate(8) 到 rather high(10)；**LI 最低（6–7）**（LI–PI/BT/OH 均 *p* < .001；LI–OC *p* = .001；LI–BI *p* = .027；LI–PS *p* = .054）。
- **转向符号的失败**：**RS 组 42% 的被试在事后访谈中无法确定或错误理解「转向符号」的含义**；且**整个实验中仅 1 名被试**（且不在 RS 组）真正做出了规避机动，尽管规避在部分场景是可行选项。故本文**无法分析转向行为**。

## 五、对 AR-HUD 行人预警时空设计的启示

### 5.1 时间参数（本课题核心）
- **预警时机 / TTC 阈值**：**论文未使用 TTC 阈值**（明确写「因技术约束、场景复杂性与多样性，本研究无法使用 time-to-collision 阈值」）。触发依据为**自车穿过指定路标**，触发点由前测确定并**针对每个场景单独适配**，从而把「时机」作为受控常量而非自变量。各场景的具体触发点在 Table 2（图片表，本地文本未抽取到）。
- **预警提前期（lead time）**：**论文未直接报告数值**。但可从两条侧证间接约束：
  1. **OC（弯道后障碍）的预警起始被作者自评为「偏早（early warning onset）」**，作者认为过早的预警反而促使被试选择更熟悉/可靠的制动而非规避（§4）；
  2. **LI 场景有 50% 的被试在预警起始之前就已制动**，说明该场景预警偏晚或情境线索先于预警到达。
  → 设计含义：**「同一触发逻辑在不同场景可能同时偏早和偏晚」**，这本身就是支持自适应时机的实证依据。
- **预警时长（duration）**：**论文未明确报告**预警符号的持续显示时长或闪烁参数。**本文无闪烁频率/占空比数据。**
- **驾驶员反应时基线**：
  - 无预警（C）**1.4 s ± 0.1 s**；
  - 反应通用停止标志（RG）**1.03 s ± 0.06 s**；
  - 注意具体危险图标（AS）**1.05 s ± 0.08 s**；
  - **预警带来的缩短量约 0.35–0.37 s（350–370 ms）**；
  - **重复暴露（学习）另带来 0.16 s 缩短**（T1 1.20 s → T2 1.04 s）；
  - **有效反应时的纳入窗口：≥ 0.2 s（下界，被认为是响应预警的最小可能时间）到 ≤ 2.9 s（上界截断，g = 3.0）**——这两个数字可直接作为反应时数据清洗规范。
- **时序结构（单级 vs 分级）**：本文为**单级**视觉预警；但结论**明确指向分级**：作者建议把结果实现为多级系统——**很危急情境/晚期阶段用「停止标志」（反应通用 RG）**，**较不危急情境/早期阶段用「感叹号警告三角」（注意通用 AG）**，因为后者在低危急场景与其具体版本效果相当却更灵活、更能容忍目标检测错误、降低误报风险；并建议在更危急阶段**叠加听觉信号**以帮助驾驶员区分预警级别并唤醒分心驾驶员。**论文未给出升级间隔的秒数。**
- **场景危急度到反应需求的映射（时间预算意义）**：**PS（行人横穿直路，危急度 ≈13/15，碰撞率 48%）需要紧急制动**；**OC（弯道后障碍，危急度 ≈6/15，碰撞率 0%）只需松油门或适度制动**——同一预警在两者中的适当性完全不同。

### 5.2 空间参数
- **呈现位置 / 空间参照系**：**HUD、驾驶员中心、发动机盖正上方**；符号与道路现实在视野中**重叠**但**不做接触类比配准**（非 world-fixed 贴合目标），属**符号固定 / 屏幕坐标**类。
- **视场角 / 尺寸**：**最大 21 cm × 21 cm，对应 6° 视角**（这是本文最可直接引用的空间参数）。
- **偏心度 / 与目标的相对位置**：**论文未明确报告**符号相对危险目标的偏心度；但报告了一个重要副作用——**HUD 在驾驶员视野中经常遮挡（overlay）安全关键对象**，以致眼动数据无法可靠归属（尤其面积较大的危险物），最终放弃注视分析。**这是「屏幕固定符号 + 6° 尺寸」的直接空间代价证据。**
- **颜色**：**红色**（红色警告三角、红色停止标志、红白条纹交通锥）；采用**彩色交通标志（colored traffic signs）**以借用既有语义（Alves et al., 2013；Payre & Diels, 2018；Plavsic et al., 2009）。
- **透明度**：**论文未明确报告**。
- **图形形态（4 类，本文核心自变量）**：
  1. 停止标志（八角、红底）— 反应通用；
  2. 停止标志/转向符号（交通锥 + 侧向箭头）交替 — 反应具体；
  3. 红色警告三角 + 感叹号 — 注意通用；
  4. 红色警告三角 + 危险对象图标（行人/骑车人/汽车/交通锥）— 注意具体。
- **动效（含闪烁频率与占空比）**：**论文未报告任何动效或闪烁参数**（本研究为静态符号，纯视觉、无声）。
- **视觉拥挤密度定义**：**论文未定义视觉拥挤密度**；场景多样性由对象类型（行人/骑车人/前车/干草捆）、行为动态（横穿方向与距离）与遭遇地点（交叉口/直路/弯道/坡道）三个维度构成。

### 5.3 可直接写入设计规范的条目
1. **若**在 HUD 中呈现碰撞预警符号，**则**符号尺寸不宜超过 **21 cm × 21 cm / 6° 视角**（§2.1）；并须核验该尺寸下符号是否遮挡危险目标——本研究中该配置导致 HUD 频繁覆盖安全关键对象，眼动归属失效（§2.3）。
2. **若**只需「有 vs 无」预警的收益，**则**任一视觉预警概念都可带来约 **0.35–0.37 s** 的制动反应时缩短（C 1.4 s → RG 1.03 s / AS 1.05 s，§3.5），且四种概念之间**无显著差异**（§3.3）。
3. **若**目标是**最强最快**的制动反应且对象类型可能尚未可靠识别，**则**采用**反应通用的停止标志（RG）**：制动反应时 1.03 s ± 0.06 s，最大制动力 68% ± 4%（全场景最高），碰撞率描述性最低（8%），且**通用性可容忍目标检测失败**（§3.5、§4）。
4. **若**场景**高度危急且危险对象已可靠分类（如行人横穿）**，**则**「注意具体」型（警告三角 + 行人图标，AS）在 BI/PI 等高危急场景描述性上更优，并与 RG 并列理解最好（M = 11/15）（§3.3、§3.4）。
5. **若**场景**危急度中等或偏低**（相当于本文 OH / LS / OC，危急度 6–9/15），**则**用**注意通用**（感叹号三角）而非强反应型：强反应型会招致过度制动、可能惊扰后车（无转向灯等可预期线索），并使驾驶员感到被过度干预（§4）。
6. **若**要在 HUD 中提示「请规避/转向」，**则不要**使用「交通锥 + 侧向箭头」式符号：**42% 的被试无法正确理解**，且全实验仅 1 人真正规避；建议改用 Maag et al. (2015) 的「车道 + 方向盘 + 箭头」式设计，或改用触觉/多模态/自动介入（§4）。
7. **若**要清洗制动反应时数据，**则**采用 **下界 0.2 s / 上界 2.9 s（g = 3.0）** 的窗口，并预期在含交叉口场景丢失可观数据（LI 达 50%）（§2.6）。
8. **若**评估预警系统，**则**必须在**多种安全关键场景**中测试：同一预警类型在不同场景导致完全不同的驾驶行为与危急度评分（scenario × warning type 交互在制动反应时、最大制动力、可理解性上均显著，§4）。

## 六、本文局限性与未来工作
1. **无 TTC 阈值触发**，时机作为受控常量被「排除」，因此本文不能回答「多早预警最好」；作者明确希望未来研究引入 TTC。
2. **无误报（false alarm）**：驾驶员始终能在情境中找到真实危险，生态效度受限；作者列为下一步。
3. **无多模态**：只用视觉；作者建议在更危急阶段叠加听觉。
4. **场景内变异未受控**：驾驶员自身行为（跟车距离、车速）使同一场景的实际危急度在被试间差异很大，**LI 场景尤为严重**，作者建议在后续评估中修正 LI，其余 7 个场景可推荐复用。
5. **样本单一**：M = 23.7 岁、年里程 < 3000 km 的学生为主；未覆盖老年、经验丰富或受损驾驶员（作者明确列为未来方向）。
6. **模拟器与碰撞率的外部效度**：模拟器对车辆动力学表征不足，碰撞率外推有限；但**制动行为被认为可较好泛化到真实驾驶**（引 Boda et al., 2018）。
7. **8 个场景不是城市事故场景的代表性抽样**，不能用于估计真实道路安全收益。
8. **眼动分析被放弃**（HUD 遮挡目标），故本文无注视行为证据。
9. 危急事件出现频率远高于日常交通，被试可能更警觉或更紧张。

## 七、与本课题的关联与引用建议
- **可用于章节**：
  - 「预警符号形态与特异性」设计章——本文是**符号策略 × 特异性**二维正交操纵、且**纯视觉无声**的少见证据（大部分同类研究都混入听觉）；
  - 「时间参数」章——用于给出**制动反应时基线 1.4 s（无预警）→ 1.03 s（RG）**这一可引用锚点，以及**0.2 s / 2.9 s 数据清洗窗口**、**0.16 s 学习效应**；
  - 「场景危急度分层」章——PS/BI/PI 的危急度与碰撞率（48%/27%/12%）可作为**行人场景优先级排序**的依据；
  - 「多级预警时序结构」章——本文给出明确的分级建议（晚期 = 停止标志，早期 = 感叹号三角）。
- **与已收录文献的一致处**：
  - 与 `15_2015_Winkler`、`16_2015_Kazazi`（同一实验室、同一 UR:BAN 项目、同一模拟器平台）高度同源——**必须在汇报时声明可能的样本/平台重叠**（本文 60 人，青年样本，M = 23.7 岁）；
  - 与 `60_2021_Wang` 一致：都发现**有 AR/HUD 预警比无预警反应更快**；
  - 与 `62`自身及 `06_2024_Ma`、`08_2024_Wu` 一致：**红色 + 熟悉交通标志形状**是被反复采用的警示编码。
- **必须显式指出的冲突**：
  1. **「更具体的预警更好」vs 本文**：Naujoks & Neukum (2014) 认为特异性主要影响预警**有用性**而非驾驶行为；Thoma et al. (2009) 与 Brown et al. (2017) 未发现特异性对反应时的影响。本文**部分支持**（4 个预警组制动反应时无显著差异）**但也部分反驳**（特异性显著影响可理解性：AS > RS/AG，*p* = .016；且 scenario × warning type 在制动参数上显著）。边界条件：**特异性的收益是场景依赖的**——高危急场景具体化有利，低危急场景通用化有利。
  2. **「更强的反应导向预警更安全」vs 本文的反证**：RG 带来最高制动力（68%），但作者明确警告这种**极端制动可能惊扰后车**（缺乏转向灯等可预期线索），并可能在低危急情境引起被试的压力与反感——即**「越强越好」不成立**，与已收录的「过度急刹/习惯化/依赖」风险条目一致（见 `HUD_AR-HUD预警文献证据整理.md` 结论 5）。
  3. **本文（62）无 TTC vs 本课题「约 3 s TTC 作为工程起点」**：本文**不能**为 3 s 提供支持或反驳，因为它刻意把时机作为受控常量。引用时**不得**把本文列为 TTC 证据；它只能支持「预警时机应随场景自适应」这一定性主张（依据：OC 偏早、LI 偏晚，同一路标触发逻辑无法同时适配）。
  4. **屏幕固定符号 vs 接触类比（contact-analog）**：本文的 6° 屏幕固定符号造成**遮挡危险目标**；这与 `09_2025_叶明慧`「行人预警不宜用单纯近地水平投影、混合面更优」以及 `60_2021_Wang`「边界框过于突出、应改用更柔和提示」形成互补的三方证据链：**符号既不能太抢眼（60），也不能遮挡目标（62），也不能只贴地（09）**。

> **Takeaway**：纯视觉 HUD 预警（≤21 cm、6° 视角）可把制动反应时从无预警的 1.4 s ± 0.1 s 缩短到 1.03 s ± 0.06 s（反应通用停止标志），但最优符号随场景危急度反转——高危急用具体化、低危急用通用化，且强反应型带来的 68% 最大制动力本身也是风险。
