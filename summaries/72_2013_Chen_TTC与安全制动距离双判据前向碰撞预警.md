## 一、研究背景与问题

### 1.1 领域现状
统计显示**约 21% 的碰撞事故为前向碰撞（forward collision）**。汽车安全从被动安全（passive safety）转向主动安全，即 ADAS。既有 FCW 研究路线包括：基于路面摩擦系数与驾驶员特性的预警算法（Nakaoka 等，引 [3]）、车道偏离 + 前向碰撞融合的视觉 ADAS（Liu 等，引 [4]）、多预警（视觉 + 听觉）接受度研究（Sato & Akamatsu，65 名被试，引 [7]）、以及跟车决策规划（Gehrig & Stein，引 [13]）。

### 1.2 研究缺口
既有 FCW 多**只用 TTC 或只用安全距离单一判据**，且**不把驾驶员反应时、制动系统压力建立时间、车重、坡度、路面状况、驾驶员年龄等实时条件纳入同一模型**。

### 1.3 核心研究问题
提出一种**同时考虑 TTC 与安全制动距离（safety braking distance）**的 FCW 算法，能够：
1. 实时计算最小/最大安全制动距离 *D*<sub>s,min</sub> / *D*<sub>s,max</sub> 与 TTC；
2. 依据 D 与 *D*<sub>s</sub>、TTC 与临界 TTC 的比较，输出**分级预警信号**；
3. 把驾驶员反应时与制动压力建立时间显式纳入。

## 二、研究方法

### 2.1 被试与样本
**无人类被试**。本文为算法 + 仿真研究。仿真所用的实车数据为**一段 767 s 的高速公路行驶记录（2010 年 2 月 5 日上午 10:21:34 起）**。

### 2.2 设计（算法结构而非实验设计）
- 系统结构（Fig. 1）：**红外线（ultrared ray）收发器**测量本车与前车（障碍物）距离 D → 计算单元（安全距离计算与分析、TTC、D、*D*<sub>s,min</sub>、*D*<sub>s,max</sub>）→ 报警器。输入量包括：车速 V、道路坡度 θ<sub>s</sub>、驾驶员年龄、车重 W、路面材质、天气状况。
- 判定流程（Fig. 2–4）：
  - 输入是否装 ABS、f<sub>r</sub>、A<sub>f</sub>、C<sub>d</sub>、ρ、γ 等参数；
  - 用 ANN 计算 ① 安全制动距离 *D*<sub>s,min</sub>/*D*<sub>s,max</sub>，② **安全 TTC：T*<sub>s,min</sub>* 与 T*<sub>s,max</sub>*，③ TTC；
  - **若 D < *D*<sub>s,min</sub> → 进入 Rule 1；否则若 D < *D*<sub>s,max</sub> → 进入 Rule 2；否则判为安全驾驶**；
  - **Rule 1（D < D<sub>s,min</sub>）**：若 **TTC < T<sub>c</sub>（临界 TTC）** → **Level 3 Dangerous**；否则若 dD/dt > 0（间距在扩大）→ **Level 1**；否则 → **Level 2 Warning**；
  - **Rule 2** 同样产生三级预警信号；
  - 全系统对外呈现 **Level 0 至 Level 4 共 5 类预警信号**：Level 4 = 最危险、需立刻减速；Level 0 = 仅提示注意车距。
- 统计方法：不适用（无统计检验）。

### 2.4 关键公式（原样转录）

**（1）制动距离（速度 V → 0）**

> *D*<sub>b</sub>(x) = [γW / (2gC<sub>ae</sub>η<sub>b</sub>)] · ln[1 + C<sub>ae</sub>V² / (μW cos θ<sub>s</sub> + f<sub>r</sub>W cos θ<sub>s</sub> ± W sin θ<sub>s</sub>)]

其中 *C*<sub>ae</sub> = (ρ · A<sub>f</sub> · C<sub>d</sub>) / 2；「±」上坡取正、下坡取负。
（说明：该式在 PDF 抽取过程中排版严重错乱，此处按原文符号定义与文献 [17,18] 的标准形式重构；引用时请核对原 PDF 第 1 页公式 (1) 的精确排版。）

**（2）车轮滑移率**

> *s*<sub>r</sub> = (V − Rw) / V

R 为轮胎半径，w 为轮胎角速度。ABS 的主要目的即防止 s<sub>r</sub> = 1（w = 0，轮胎锁死；锁死后失去方向控制与稳定性，制动距离与制动时间都长于装 ABS 的情形）。

**（3)(4）反应距离**

> *D*<sub>r,min</sub> = t<sub>r,min</sub> · V
> *D*<sub>r,max</sub> = t<sub>r,max</sub> · V

**（5)(6)(7）制动压力建立距离**

> *D*<sub>p</sub> = t<sub>p</sub>V<sub>0</sub> − (a<sub>p</sub>t<sub>p</sub>²)/2
> *D*<sub>p,min</sub> = t<sub>p,min</sub> · V<sub>0</sub>
> *D*<sub>p,max</sub> = t<sub>p,max</sub> · V<sub>0</sub>

（原文说明：由于压力建立期间车速近似不变，平均减速度 a<sub>p</sub> 项可忽略。）

**（8)(9)(10）安全制动距离**

> *D*<sub>s</sub> = *D*<sub>b</sub> + *D*<sub>r</sub> + *D*<sub>p</sub>
> *D*<sub>s,max</sub> = *D*<sub>b</sub>(μ<sub>min</sub>, η<sub>min</sub>) + *D*<sub>r,max</sub> + *D*<sub>p,max</sub>
> *D*<sub>s,min</sub> = *D*<sub>b</sub>(μ<sub>max</sub>, η<sub>max</sub>) + *D*<sub>r,min</sub> + *D*<sub>p,min</sub>

**（11）TTC 定义**

> **TTC = D(t) / (dD(t)/dt)**

其中 D(t) 为本车与前车的距离。

## 三、关键指标与测量

- **TTC（s）**：按式 (11) 实时计算。
- **临界 TTC，*T*<sub>c</sub>（s）**：本文**设定为 1.5 s**（依据 van der Horst 的 TTC 研究，引 [15,16]）。
- **安全 TTC 上下界 *T*<sub>s,min</sub> / *T*<sub>s,max</sub>**：由 ANN 计算单元输出（Fig. 2）；**论文未给出其数值或计算公式**。
- **反应时 t<sub>r</sub>（s）**：三段分解 + 分龄取值（见 5.1）。
- **制动压力建立时间 t<sub>p</sub>（s）**：0.3–0.75 s。
- **安全制动距离 *D*<sub>s,min</sub> / *D*<sub>s,max</sub>（m）**。
- **预警等级**：Level 0–4（5 类）。

## 四、主要结果与发现

仿真基于 767 s 实车高速公路数据：
- **速度剖面（Fig. 6）**：起初 **96 s 为加速段**，从低速加速到高速；随后**约 600 s 维持高速**；最后**约 50 s 减速直至停车**。速度轴范围 0–120 km/h。
- **车距（Fig. 7）**：超过 200 m 的部分不在图中显示。
- **安全制动距离对比（Fig. 8）**：与实际车距对照可见，**在大约第 140 s 至第 165 s 期间，本车未保持安全制动距离**。
- **TTC 与临界 TTC（Fig. 9）**：整段行驶中**共出现 5 次 TTC 小于临界 TTC（1.5 s）的情形**。
- **预警输出（Fig. 10）**：系统输出 5 类预警等级（0–4）；Level 4 表示最危险、需减速，Level 0 仅提示注意车距。
- **结论**：算法适用于 FCW，能给出有用的报警信息。

> 注意：本文**没有任何人因实验、没有统计量、没有对预警有效性的验证**（无 F/p/效应量/被试反应时）。第四节结论完全建立在单段实车数据的算法自洽性演示上。

## 五、对 AR-HUD 行人预警时空设计的启示

### 5.1 时间参数（本课题核心，穷尽转录）

**A. 临界 TTC 阈值**
- **临界 TTC，T<sub>c</sub> = 1.5 s**（原文 Section 5：「The critical TTC, T<sub>c</sub>, is set to be 1.5 s [15,16]」）。这是**本批次文献中最短的 TTC 阈值**，其定位是「危险等级判定线」而非「首次提示线」。
- **TTC 计算公式**：**TTC = D(t) / (dD(t)/dt)**（式 11）。注意这是**距离/距离变化率**的定义式，等价于 D/相对速度；本文未给出加速度修正的二阶 TTC 形式。
- 安全 TTC 上下界 T<sub>s,min</sub>、T<sub>s,max</sub>：**论文未明确报告数值与公式**（仅在流程图中作为 ANN 输出出现）。

**B. 驾驶员反应时（RT）的三段分解——本文最有价值的时间参数**

原文把反应时 t<sub>r</sub> 分解为「意识 → 判断 → 动作」（Consciousness → Judgment → Action）三段：

| 分量 | 定义 | 常人取值范围 | 影响因素（原文） |
|---|---|---|---|
| **反射/经验时间 Reflection time** | 以视觉、听觉或经验察觉外部状况 | **0.44–0.52 s** | 情绪、体力；**道路条件越复杂反射时间越长** |
| **判断时间 Judgment time** | 用大脑理解并作出判断 | **0.15–0.25 s** | 受情绪影响极大（紧张或极冷静差异明显） |
| **动作时间 Action time** | 判断后在恰当情境施加动作 | **0.15–0.40 s** | — |
| **合计反应时 t<sub>r</sub>** | 三者之和 | **0.74–1.17 s**（依驾驶员年龄） | 年龄、性别、体力、情绪 |

**分龄反应时表（Table 3，原样转录）**

| 驾驶员年龄 | 反应时范围（s） | 设定值 |
|---|---|---|
| 18–33 | 0.74–1.10 | t<sub>r,min</sub> = **0.74**, t<sub>r,max</sub> = **1.10** |
| 34–47 | 0.75–1.12 | t<sub>r,min</sub> = **0.75**, t<sub>r,max</sub> = **1.12** |
| 48–57 | 0.77–1.13 | t<sub>r,min</sub> = **0.77**, t<sub>r,max</sub> = **1.13** |
| 58–70 | 0.78–1.17 | t<sub>r,min</sub> = **0.78**, t<sub>r,max</sub> = **1.17** |

- **年龄带来的反应时增量**：从 18–33 岁到 58–70 岁，t<sub>r,min</sub> 仅增加 **0.04 s（40 ms）**，t<sub>r,max</sub> 增加 **0.07 s（70 ms）**。**即本文所采信的年龄效应非常小**（这与人因文献中老年驾驶员反应时显著延长的结论不一致，见第七节）。
- **分心条件下的反应时增量**：**论文未明确报告**（本文完全不考虑分心，只考虑年龄、情绪、体力与道路复杂度的定性影响）。

**C. 制动系统时延（warning lag 的机械侧分量）**
- **制动压力建立时间 t<sub>p</sub>：0.3–0.75 s**（原文：「Usually the pressure buildup time, t<sub>p</sub>, varies in the range between 0.3 and 0.75 second」）；设定 **t<sub>p,min</sub> = 0.3 s，t<sub>p,max</sub> = 0.75 s**。
- **因此「从危险出现到车辆真正开始有效减速」的总时延 = t<sub>r</sub> + t<sub>p</sub> = 0.74 + 0.30 = 1.04 s（最优）到 1.17 + 0.75 = 1.92 s（最差）**。这是一条**可直接用于 AR-HUD 时间预算的关键推算**（推算由本摘要作者据 Table 3 与 t<sub>p</sub> 范围得出，原文未显式给出该合计值）。

**D. 减速度 / 制动能力阈值**
- 未直接给出减速度阈值 a（m/s²），而是通过 **μ（0.07–0.9，见 Table 1）、η<sub>b</sub>（0.85–0.95）、f<sub>r</sub>（0.015）、γ（1.04）** 等参数经式 (1) 隐含决定。
- 由 μ 表可推：**冰面（μ = 0.07–0.1）的可用减速度不足干沥青（μ = 0.8–0.9）的 1/8**，因此同一 TTC 阈值在冰雪路面完全不成立。

**E. 时序结构（分级预警）**
- **5 级结构：Level 0 / 1 / 2 / 3 / 4**。
- 触发逻辑（时序结构的核心）：
  - **空间判据优先于时间判据**：先比较 D 与 *D*<sub>s,min</sub>、*D*<sub>s,max</sub>（选择 Rule 1 或 Rule 2），再在规则内用 **TTC < T<sub>c</sub> = 1.5 s** 判定最高危级别；
  - **趋势判据（dD/dt > 0，间距扩大）用于降级**：即使车距不足，只要间距在扩大就降为 Level 1。
- **升级间隔（level-to-level 的时间间隔）：论文未明确报告**（等级由实时判据切换，无固定时间间隔设计）。
- **预警持续时长：论文未明确报告**。
- **报警延迟（warning lag）：论文未明确报告**（未建模传感与计算时延）。

### 5.3 可直接写入设计规范的条目
1. **若** AR-HUD 需要一个「最高危险级」的时间判据，**则**可采用 **TTC < 1.5 s**（出处：Section 5「critical TTC set to be 1.5 s」，依据 van der Horst 引 [15,16]）。
2. **若**要计算 AR-HUD 预警的最早触发时刻，**则**必须在几何 TTC 之外**再加上驾驶员反应时 0.74–1.17 s 与制动压力建立时间 0.3–0.75 s**，即总计 **1.04–1.92 s** 的「不可压缩时延」（出处：Section 3 反应距离与压力建立距离两小节、Table 3）。
3. **若**目标用户覆盖老年驾驶员（58–70 岁），**则**按本文取值反应时上限从 1.10 s 增至 1.17 s（+70 ms）；但此增量偏小，建议以人因文献为准（出处：Table 3；见第七节冲突分析）。
4. **若**行驶于湿滑或冰雪路面，**则**TTC 阈值必须随 μ 上调：μ 从干沥青 0.8–0.9 降至冰面 0.07–0.1，制动距离按式 (1) 反比放大（出处：Table 1、式 (1)）。
5. **若**采用分级预警，**则**可借用本文的「空间判据先分流（D vs D<sub>s,min</sub>/D<sub>s,max</sub>）→ 时间判据定最高级（TTC vs T<sub>c</sub>）→ 趋势判据降级（dD/dt > 0）」三层结构（出处：Fig. 2–4）。
6. **若** AR-HUD 要标注「安全跟车带」，**则**可用 *D*<sub>s,min</sub>（乐观：μ<sub>max</sub>, η<sub>max</sub>, t<sub>r,min</sub>, t<sub>p,min</sub>）与 *D*<sub>s,max</sub>（悲观：μ<sub>min</sub>, η<sub>min</sub>, t<sub>r,max</sub>, t<sub>p,max</sub>）构成的**双阈值带**而非单一线（出处：式 (9)(10)、Fig. 8）。

## 六、本文局限性与未来工作
1. **无人因验证**：全文无被试实验，预警有效性、驾驶员是否理解 5 级信号、是否会被 Level 0/1 骚扰，均未评估。作者自己也未列出 Limitation 章节。

## 七、与本课题的关联与引用建议

- **可用于章节**：
  - 「TTC 定义与计算」方法学小节的**公式来源**（式 11）；
  - 「时间预算分解」小节的**核心引文**：把「TTC 阈值」拆成「感知时延 + 判断时延 + 动作时延 + 制动建立时延 + 纯制动距离」的五段结构，是我们做 AR-HUD 时间参数专题分析时的骨架；
  - 「环境条件对阈值的调制」小节（μ 表）。
- **与已收录文献的一致之处**：
  - **反应时量级**与 idx 74（Abe & Richardson 2006）所用的 SDA 算法参数 **RT = 1.25 s** 属同一量级（本文 0.74–1.17 s，Abe 取 1.25 s），互为佐证。
  - **TTC 1.5 s 的临界值**与 idx 76（Thammakaroon 2012）所用 **1.6 s 跟车时距阈值**几乎重合（76 因曼谷激进驾驶习惯把「两秒法则」下调至 1.6 s），说明工程界普遍把 1.5–1.6 s 视作「已进入危险」的判据线。
  - **分级思想**与 idx 76 的「五级碰撞时间线」在层级数量上一致（都是 5 级），但两者的层级语义不同：本文按「距离/TTC 判据」分级，76 按「事故演化阶段」分级。
- **与已收录文献的冲突之处（显式指出）**：
  1. **TTC 阈值严重冲突**：本文的危险判据是 **TTC = 1.5 s**，而 idx 71（Zhang 2015）明确证明**碰撞前 2.5 s 释放的预警等于无效**、须至少 3.0 s；idx 70（Kang 2016）与 idx 78（Large 2019）也都显示 **2.0 s 太晚**。边界条件分析：
     - **功能定位不同**：本文的 1.5 s 是「Level 3/4 危险级」判据，即**最后一道防线**，其后紧接的是驾驶员紧急制动或 AEB；而 71/70/78 讨论的 3–4 s 是**首次告知性预警**的时机。两者并不真正矛盾，而是**同一分级体系的不同层级**——这正好支持「AR-HUD 应采用分级时序：早级 3.0–5.0 s 提示，晚级 1.5–2.0 s 危险」的设计。
     - **场景不同**：本文是高速公路纵向跟车（有前车刹车灯等线索、制动可解），71/70/78 是交叉口或行人横向冲出（需转向或大幅减速）。
  2. **年龄效应量级冲突**：本文 Table 3 给出的年龄反应时增量仅 40–70 ms（18–33 岁 vs 58–70 岁），这与 HUD 老年驾驶员研究（如已收录的 idx 16 Kazazi 2015 关于老年/青年 HUD 预警差异）中常见的数百毫秒级差异不符。可能原因：本文的分龄表来自车辆工程手册的经验值（引 [17,18]），是**理想警觉状态下的下界**，未包含注意分配、视觉搜索与决策复杂度的年龄效应。**引用时不应把 Table 3 当作老年驾驶员反应时的实证依据。**
  3. **与 idx 76 的「实然—应然」张力**：76 实测 FCW 报警比真实驾驶员制动**晚 1.47 s**；本文的 t<sub>r</sub> + t<sub>p</sub> = 1.04–1.92 s 时延预算与该数值在量级上惊人吻合，提示 **76 观测到的 warning lag 很可能主要就是「人比机器快」而非系统故障**。这一交叉解读值得写入时间参数专题分析。
- **引用注意**：本文是**工程算法文献，非人因实证文献**。引用其反应时（0.74–1.17 s）、压力建立时间（0.3–0.75 s）、临界 TTC（1.5 s）、μ 表时，须注明这些是**手册经验值 / 工程设定值**，而非本文实测；且必须注明其场景为高速公路车—车前向碰撞。

> **Takeaway**：本文给出可直接用于 AR-HUD 时间预算的完整分解——**驾驶员反应时 0.74–1.17 s（反射 0.44–0.52 + 判断 0.15–0.25 + 动作 0.15–0.40）+ 制动压力建立 0.3–0.75 s，合计 1.04–1.92 s 不可压缩时延，临界 TTC 设为 1.5 s，TTC = D/(dD/dt)**。
