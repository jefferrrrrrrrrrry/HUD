## 一、研究背景与问题

### 1.1 领域现状
车载 AR-HUD 把虚拟图形叠加于真实道路场景，把导航、车况、预警等信息以"空间式"方式呈现于风挡，被视为减少视线转移、提升用户体验的关键交互范式。前人对 AR-HUD 导航与碰撞预警的研究侧重三方面：
1. **导航信息呈现形式**——Bauerfeind、Chauvin 等比较 AR-HUD 与 C-HUD（传统 HUD）的导航效率，认为水平地面投影对模糊/复杂场景有显著优势；Pfannmüller 比较了 boomerang/箭头四种形态；Pärsch 研究信息覆盖度对驾驶绩效的影响。
2. **碰撞预警图形隐喻**——Kim 的 Virtual Shadow（地面虚拟阴影）显著提升对横向行人危险的识别；Roh & Lee 的同心圆地面投影提升对行人/个人移动设备用户的反应；Chen 等比较 contact-analog 与 bounding box 的预警效果。
3. **AR-HUD 与无意视盲（inattentional blindness, IB）的耦合关系**——已有 Wang 等（2022）、Hou 等（2024）、Chen 等（2023）等系列研究表明，AR-HUD 图形的颜色、动效、相对位置等会显著影响 IB 频率。

### 1.2 研究缺口
论文明确指出：尽管 AR 信息本质上是"空间性"的，但既有研究**几乎全部把图形当作 2D 元素来比较**（颜色、形状、动效、是否覆盖等），而**忽视了"空间面（spatial plane）"这一最本质的 AR 属性**——即把图形投影在水平面（near-ground）、垂直面（ground-orthogonal）还是混合面上。作者把这个变量与 IB 行为直接挂钩。

### 1.3 核心研究问题
- RQ1（实验 1）：AR-HUD 导航图形的空间面位置（水平 / 垂直 / 混合）是否会显著影响驾驶员的无意视盲行为、反应时、工作负荷和用户体验？
- RQ2（实验 2）：AR-HUD 碰撞预警图形（行人 vs 前车）的空间面位置是否会显著影响上述指标？

## 二、研究方法

### 2.1 被试与样本
- 两个实验**分别**招募 45 名被试（先用 G*Power 3.1 估算样本量：α = 0.05，f = 0.25，power = 0.95，最低需 43 人）。
- 性别比 1:1；年龄 21–25 岁；持有效驾照；右利手；视力或矫正视力正常；签署知情同意书并获得报酬。
- 论文未明确报告平均驾龄，且作者在 Limitation 中承认被试为"大学生"，是研究的局限之一。

### 2.2 实验设计
- **设计类型**：单因素被试内设计（single-factor within-subjects）。
- **自变量**：AR-HUD 图形空间面位置，3 水平 = 水平面 / 垂直面 / 混合面。
- **因变量**：
  - 客观：① 无意视盲发生次数；② 反应时（仅在未发生 IB 时计）。
  - 主观：① NASA-TLX 工作负荷（6 维 0–100）；② UEQ-S 用户体验量表（pragmatic + hedonic 两维度各 4 项，7 点 Likert，并对答案进行 −3 至 +3 转换）。
- **统计**：IB 频次用 Kruskal–Wallis 非参数检验；反应时、NASA-TLX、UEQ 用广义估计方程（GEE）+ 事后两两比较；并用 Spearman 相关。

### 2.3 实验材料与设备
- **显示与座舱**：约 143.9 cm × 81.0 cm 的大屏模拟前风挡；Logitech 方向盘 + 油门 + 刹车踏板 + 座椅；方向盘按键作为反应记录工具。
- **程序**：E-Prime 3.0 控制刺激与数据采集。
- **场景制作**：Unity3D 2023.2.20f1 生成第一人称城市道路视频（晴天、匀速、随机布置建筑、树木、行人、车辆）；Adobe After Effects 2024 叠加 AR 图形。
- **图形参数**：
  - 颜色：导航图形 = 蓝色（援引 Gabbard 等的色彩匹配研究，蓝色在 AR-HUD 中稳健性最好）；碰撞预警 = 红色（援引 Friedrich & Vollrath、Chapanis 色彩警告强度）。
  - 透明度：α = 0.75（援引 Hussain & Park，兼顾可视性与搜索响应）。
  - 动效：导航图形采用**闪烁**（援引 Hou 等 2024，闪烁可缓解 IB）。
  - 单屏信息项数：限制为 6–7 个，避免信息过载。
  - 持续时长：碰撞预警图形持续 3 s（援引 Ma 等 2021 已证最适）。
- **三种空间面**：
  - 水平面（horizontal/near-ground）：图形贴近地面投影。
  - 垂直面（vertical/ground-orthogonal）：图形与地面垂直，即传统 2D HUD 平面。
  - 混合面（mixed）：水平 + 垂直双平面组合。

### 2.4 任务与流程
- **双任务范式（dual-task paradigm）**：主任务=驾驶（依据 AR 导航转向 + 按键应对突发事件）；副任务=问答（如"当前车速是多少？"），目的是逼近真实驾驶的认知负荷。
- **实验 1 三个 IB 测试点**（每个 trial 含 4 次转弯——2 左 2 右）：
  1. 闯红灯（车辆继续行驶但红灯亮起）；
  2. 前车制动（刹车灯亮）且车距过近；
  3. 行人突然冲入路面。
- **实验 2 六个 IB 测试点**：前车碰撞场景 3 次 + 行人碰撞场景 3 次，每个 trial 中事件顺序随机。
- 每名被试先做 1 个练习 trial，然后随机顺序完成 3 个 trial；每 trial 结束立即填写 NASA-TLX 与 UEQ-S。总时长 10–15 分钟。
- **关键操作化定义**：
  - 行人冲入视线后**无反应** → IB；
  - 红灯亮起后**3 s 内无反应** → IB；
  - 前车刹车灯亮→灭期间无反应 → IB；
  - 反应时 = 事件出现到按键的时间。

## 三、关键指标与测量
- 行为：IB 次数（频数）、反应时（ms）。
- 主观：NASA-TLX 总分（6 维平均）、UEQ-S 的 pragmatic quality、hedonic quality、overall UX。
- 关联性：用 Spearman 检验 IB、负荷、体验四者间的相关。

## 四、主要结果与发现

### 4.1 实验 1（导航图形）
- **IB 频次**：被试合计触发 61 次 IB；Kruskal–Wallis *p* = 0.778，三种空间面间**无显著差异**。
- **反应时**：GEE，χ²(2)= 0.356, *p* = 0.837，**无显著差异**。两两差值（M ± SE，ms）水平−垂直 = 25.10 ± 101.62 (*p* = 0.805)；水平−混合 = −35.24 ± 101.62 (*p* = 0.729)；垂直−混合 = −60.34 ± 101.62 (*p* = 0.553)。
- **NASA-TLX 负荷**：χ²(2)= 8.199, *p* = 0.017。垂直面 39.82 ± 3.46 显著高于水平面 26.17 ± 3.46（*p* = 0.005）与混合面 30.26 ± 3.46（*p* = 0.051，临界）；水平 vs 混合无差异。
- **UEQ-S**：
  - Pragmatic：χ²(2)= 37.491, *p* < 0.001。水平 1.53 > 混合 0.15 > 垂直 −0.48（水平 vs 垂直 *p* < 0.001）。
  - Hedonic：χ²(2)= 14.706, *p* = 0.001。混合 0.67 ≈ 水平 0.10 > 垂直 −0.48。
  - Overall UX：χ²(2)= 23.150, *p* < 0.001。水平 0.82 ≈ 混合 0.41 > 垂直 −0.48。
- **相关性**：IB 次数与负荷 *r* = 0.217 (*p* = 0.012) 正相关；负荷与 pragmatic *r* = −0.608 (*p* < 0.001)、hedonic *r* = −0.277 (*p* = 0.001)；pragmatic 与 hedonic *r* = 0.456 (*p* < 0.001)。

### 4.2 实验 2（碰撞预警图形）
- **IB 频次**：合计仅 3 次。Kruskal–Wallis：行人 *p* = 0.133，前车 *p* = 1.000，均**无显著差异**；但行人场景下，水平面的 IB 次数总体高于另两类，**水平面似不宜用于行人预警**。
- **反应时**：
  - 行人：χ²(2)= 1.722, *p* = 0.423，**无显著差异**。
  - 前车：χ²(2)= 13.006, *p* = 0.001。混合面 604.27 ± 24.75 ms 显著快于垂直 728.50 ± 47.82 ms（*p* = 0.001）与水平 678.96 ± 36.78 ms（*p* = 0.037）；水平 vs 垂直无差异。
- **NASA-TLX 负荷**：χ²(2)= 10.037, *p* = 0.007。**垂直面**最低 22.11 ± 3.10 < 混合 31.48 ± 3.10 ≈ 水平 35.65 ± 3.10（水平 vs 垂直 *p* = 0.002；垂直 vs 混合 *p* = 0.032）。
- **UEQ-S**：
  - Pragmatic：χ²(2)= 25.928, *p* < 0.001。垂直 1.66 ± 0.20 显著高于水平 0.37 ± 0.19 与混合 0.04 ± 0.27。
  - Hedonic：χ²(2)= 11.587, *p* = 0.003。混合 0.57 ± 0.21 ≈ 垂直 0.22 ± 0.18 > 水平 −0.37 ± 0.22。
  - Overall：χ²(2)= 16.581, *p* < 0.001。垂直 0.94 > 混合 0.31 ≈ 水平 −0.003。
- **相关性**：IB 与负荷不相关；负荷 vs pragmatic *r* = −0.499、vs hedonic *r* = −0.316（均 *p* < 0.001）；pragmatic vs hedonic *r* = 0.411 (*p* < 0.001)。

## 五、对 AR-HUD 时空设计的启示

### 5.1 时间元素
- **持续时长**：3 s 为本研究采用的预警图形持续时长（援引 Ma 2021），被验证可让被试在水平/垂直/混合三种面上均完成响应。
- **TTC 隐含信息**：前车碰撞反应时区间 604–728 ms，行人区间不显著（论文未明确报告均值），提示设计 TTC 阈值时应区分前车（纵向）与行人（横向）。
- **IB 判定窗口**：行人事件以"进入视野无反应"定义，红灯以"亮起后 3 s 无反应"定义，前车以"刹车灯亮→灭区间内无反应"定义——为 AR-HUD 预警有效性评估提供操作化标准。

### 5.2 空间元素（平面 2D）
- **颜色**：导航蓝、预警红，透明度 0.75。
- **动效**：导航采用"闪烁"动效（援引 Hou 等 2024）。
- **形状**：箭头型导航 + 行人/前车的指示型预警（贴合警告对象）。
- **信息密度**：单屏 6–7 项为上限。

### 5.3 空间元素（立体：分布面 / FOV / 相对位置）
这是本论文最核心的贡献。
- **导航图形** → 优先**水平面**，次选混合面，规避垂直面：
  - 水平面投影贴近驾驶员对地面与路径的"认知地图"，降低 cognitive transformation 成本；
  - 垂直面虽不增加 IB 也不延长反应时，但显著抬高 NASA-TLX 负荷（39.82 vs 26.17）并显著降低 pragmatic 与 overall UX。
- **行人碰撞预警**：避免水平面（IB 趋势更高），**优先混合面**（兼顾警告 + hedonic），垂直面亦可。
- **前车（追尾）预警**：**优先混合面**——反应时显著缩短约 75–124 ms；若以"低负荷 + 高 pragmatic"为目标，则用**垂直面**。
- 即"导航看下方（水平）、预警看上方（垂直/混合）"形成上下分工。

### 5.4 设计原则与适用边界
- 原则 1：空间面应与"任务的空间属性"对齐——导航与路径同构（水平），预警与障碍物方位同构（混合或垂直）。
- 原则 2：兼顾 pragmatic（实用）与 hedonic（愉悦）：混合面常能在 hedonic 上取得加分，可用于追求体验的车型。
- 原则 3：在低/中等驾驶负荷下，空间面对 IB 的影响有限；**在更高复杂度场景下，垂直面可能反而帮助降低 IB**——这是论文外推但未直接验证的边界条件。
- 原则 4：相同图形要素的颜色（蓝/红）、透明度（0.75）、动效（闪烁）、3 s 持续时长可作为基线规范。

## 六、本文局限性与未来工作
1. **生态效度有限**：使用预录视频而非交互式驾驶模拟器，沉浸感与注意需求降低；
2. **响应方式**：被试用方向盘按键替代真实刹车踏板，作者也明确为局限；
3. **被试同质**：21–25 岁大学生，未覆盖老年驾驶员与新手/老手差异；
4. **场景单一**：晴天、城市道路、匀速，未涉及夜间、雨雾、高速、隧道；
5. **样本与重复次数**：每个被试每场景仅 3 次 trial，行人场景的水平面"劣势"未达显著，需要更多 trial 验证；
6. **未来方向**：采用 HIL/真实 AR-HUD 实车进行验证；研究老/新驾驶员差异；探索更高密度交通与极端天气；研究水平+垂直之间的最佳"几何组合比"。

## 七、与本研究主题（HUD/AR-HUD 行人标注的时间空间设计规范）的关联

这是研究综述链中**关于"立体空间面"维度的唯一直接证据论文**，与其他偏重 2D 形状/颜色/动效的论文形成互补：
- **空间维度规范**：明确把 AR-HUD 输出投影面三分为"水平 / 垂直 / 混合"，给出了**对行人预警最不推荐水平面**、对追尾预警**混合面反应最快**的关键结论。这直接进入我们在做的行人 AR-HUD 设计规范的"空间立体面"分支。
- **时间维度规范**：3 s 持续时间作为参考；IB 判定窗口（行人进入视野即应响应、红灯 3 s、前车刹车灯亮灭区间）给出可复用的时序窗。
- **图形规范基线**：蓝 / 红、透明度 0.75、闪烁动效、6–7 个并发信息上限。
- **方法学借鉴**：双任务范式 + 视频刺激 + 按键反应；NASA-TLX + UEQ-S + GEE 的统计组合，可直接迁移到我们的实验设计。
- **可整合到设计指南的核心条目**：
  - 行人横向冲出 → 用混合面 / 垂直面 contact-analog 标注，避免单一近地水平投影；
  - 前车追尾 → 用混合面 contact-analog 配 3 s 持续；
  - 同时显示导航 + 预警时 → 导航走下方近地水平面、预警走上方混合 / 垂直，避免空间面冲突。

> **Takeaway**：在以"行人 AR-HUD 标注"为对象的设计规范中，"图形投影在哪个空间面"是与颜色/形状/动效同等重要的独立维度——水平面利于路径型导航、垂直面利于低负荷的预警、混合面利于快速反应与愉悦体验；对横向行人危险，避免单纯近地水平投影，混合面是兼顾安全与体验的首选。
