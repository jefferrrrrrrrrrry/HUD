## 一、研究背景与问题

### 1.1 领域现状
- AR-HUD 把导航信息叠加到风挡，可缓解外部环境导致的知觉退化、恢复认知资源、提升认知可用性与可见度；但设计不良反而损害安全。
- **极端天气是 IB 的放大器**：雨雾中水滴与雾粒散射吸收光线导致照度显著下降；雨滴视觉噪声与雨刷运动扭曲注意分配；低照度雾天因视觉加工受限使注意资源紧张；雾天缺乏深度线索导致情境意识下降，亮度与对比度降低使环境中的警示信息更难被察觉，可能导致漏过路口或事故。
- **既有视觉显著性研究的落点**：调整 HUD 图形的颜色对比组合可提升可见度、缩短视觉搜索时间；**文献 [23] 确认「闪烁动效 + 透明度介于 0.5–0.75」可有效缓解 IB**（本文引用的直接参数，对应已收录文献 `09_2025_叶明慧` 采用的 α = 0.75）；文献 [26] 比较「回旋镖（boomerang）与箭头」两类导航图形及其四种变体，发现回旋镖设计带来更快反应时与更高信任与满意度；文献 [34] 报告**动画告警相对静态告警使检测时间减少 25.64%**。
- **轮廓显著性（contour saliency）**：在图形周围加色环/描边可显著提升显著性，在显示空间受限时尤为有效 [27]；加边框或色圈能在**保留原有语义**的同时提升可见性 [29]；**黑色描边**在各种背景下都能提供对比，而**彩色描边可能与图形或背景融合造成混淆** [30]。

### 1.2 研究缺口
- 现有 AR-HUD 导航研究集中在界面布局、信息密度、图形运动设计、颜色对比、显示区域，**未考察 AR-HUD 信息本身的显著性设计是否影响 IB**；
- 现有 AR-HUD 导航箭头多用**重复循环动画**，其恒定不变的视觉特征在危险条件下可能引起视觉疲劳或习惯化，反而导致 IB。

### 1.3 核心研究问题
- **RQ1**：具备轮廓显著性的 AR-HUD 导航图形能否显著减少 IB？
- **RQ2**：动态缩放的 AR-HUD 导航图形能否显著减少 IB？

## 二、研究方法

### 2.1 被试与样本
- G*Power 估算：α = 0.05，效应量 f = 0.25，power = 0.95 → **最低样本 18 人**（文中另说明 power 一般取 0.8 即可，此处取 0.95）。
- 实际招募 **30 人**，性别大致均衡；年龄 20–25 岁，M = 22.23 岁（SD = 1.73）；均持有效驾照，平均驾龄 2.21 年（SD = 3.11）；多数本科学历，对驾驶辅助技术有基本了解，部分有 HUD 使用经验；视力或矫正视力正常；右利手。

### 2.2 实验设计
- **两因素被试内设计（2 × 2）**：
  - **轮廓显著性**：CS+（有黑色描边）vs CS−（无黑色描边）；
  - **动画呈现**：APS（Animation Presentation with Static arrow，固定尺寸箭头）vs APE（Animation Presentation with Enlarged arrow，动态缩放箭头）。
  - 组合成 4 种导航图形条件：**APE/CS+、APE/CS−、APS/CS+、APS/CS−**。
- **因变量**：IB（以反应时与眼动指标操作化）、总注视时长 TDT、首次注视时间/时长 TTFF、UEQ 用户体验分。
- **统计**：两因素重复测量 ANOVA（部分处写「两因素 ANOVA」）；正态性用 Kolmogorov–Smirnov、Jarque-Bera 检验；Levene 检验提示部分方差不齐（*p* = 0.034）后转做 K-S 检验确认可接受正态；因每因素仅 2 水平，**未做 Bonferroni 事后检验**。

### 2.3 实验材料与设备
- **图形制作**：Unity（实验材料用 **Unity 2022 LTS**，C# 编程，同时用于采集驾驶行为数据）。
- **图形形态**：采用**回旋镖形（boomerang-shaped）导航概念** [41]。
- **颜色**：**橙色**，理由是该色在雨雾条件下已被证明稳健、适用 [42]。
- **轮廓**：CS+ 通过**黑色描边（black outline）**实现。
- **动态缩放（关键时间-空间参数）**：正常行驶时导航动画不变；**接近危险时箭头从 150 px 放大到 300 px**。图形尺寸基准依据标准 AR-HUD 尺寸范围 **150 × 150 px 至 300 × 300 px** [16], [37]。
- **天气素材**：因短期内无法模拟真实多样天气，从网络收集**雨天与雾天各 50 张图像**；雨天分小雨、中雨、大雨、暴雨 [43],[44]；雾天分薄雾与浓雾 [45],[46]；用 **Image Color Summarizer** 工具 [47] 计算雨雾场景的**平均照度**以确定实验亮度设置。最终设计一个**同时含雨与雾的极端天气场景**。
- **驾驶场景**：Unity 第一人称驾驶仿真，道路类型全部基于真实道路，含**主干道、集散道路、高速公路、次要道路**；自车**恒速**通过雨雾天气下的城市道路；场景含建筑、树木、交通灯、路灯、道路标志、其他车辆与行人；自车执行转弯与直行；共导出 4 个实验条件。
- **设备**：**34 英寸屏幕，16:9，约 79 cm 宽 × 34 cm 高**（用以模拟典型汽车风挡尺寸）；Logitech G29 方向盘 + 油门 + 刹车 + 驾驶座；**方向盘按键记录反应时**；被试佩戴 **Tobii Pro Glasses 3** 眼动眼镜；另提及使用 Tobii 桌面式眼动仪（文中两处设备表述并存）。

### 2.4 任务与流程
- 签署知情同意、了解背景与目标 → 坐入模拟座舱、佩戴 Tobii 眼镜并校准 → 被要求尽量减少身体移动、保持与校准时相同姿势 → 练习 session → 正式阶段：**每名被试完成 4 个 session（对应 4 个图形条件），每个 session 含 3 个 IB 测量场景**；每 session 开始时阅读指导语并踩油门启动；**4 个 session 顺序随机化以控制顺序效应**；每 session 结束后填写 UEQ。
- **注意**：方法 §B.2 处写「嵌入 **4 个** 易发 IB 的测试场景，各出现一次」，而 §D 与 §C 写「每 session 含 **3 个** IB 测量场景」并列出三类事件——**文内不一致，引用时须标注**。
- **三个 IB 测量事件（明确列出）**：① 交通灯变红；② 行人踏入路面；③ 前车跟车距离减小。反应时以**毫秒**记录，作为「非 IB」的基线参照；最终分析使用**跨所有 trial 的累积反应分数**（值越高 = 反应越慢）。

## 三、关键指标与测量

| 指标 | 定义与判定标准（本文给出的推荐区间是本课题可直接引用的量化门槛） |
|---|---|
| 反应时（ms） | 从三类事件出现到方向盘按键的时间；累积分数越低越快 |
| **总注视时长 TDT（Total Dwell Time）** | 在 AOI（AR-HUD 导航图形）上的累积注视时间。**最优区间 500–2000 ms**；**≤500 ms 表示注意不足**；**≥2000 ms 可能表示因复杂、遮挡或误导内容而分心** |
| **首次注视时间 TTFF（Time to First Fixation）** | 首次注视到 AOI 的时间。**最优区间 100–300 ms**；超出该范围反映未能吸引注意或检测延迟 |
| UEQ 用户体验问卷 | 6 维度：吸引力 attractiveness、易懂性 perspicuity、效率 efficiency、可依赖性 dependability、刺激性 stimulation、新颖性 novelty；**7 点 Likert（1 = 强烈不同意 … 7 = 强烈同意）**；用总分比较 |
| AOI | AR-HUD 导航图形本身 |

## 四、主要结果与发现

### 4.1 反应时（两因素重复测量 ANOVA）
- **动态（Dynamic）主效应显著**：F = 52.63, *p* < 0.001, ηp² = 0.31 —— 动态条件显著缩短反应时。
- **轮廓（Contour）主效应显著**：F = 14.76, *p* < 0.001, ηp² = 0.11 —— 有描边时反应时更短。
- **交互显著**：F = 8.08, ηp² = 0.05；**p 值在结果节写 0.015，在讨论节写 0.007，文内矛盾**。
- **各条件均值（M ± SD，ms）**：
  | 条件 | 反应时 |
  |---|---|
  | **APE/CS+（动态 + 黑描边）** | **1579.63 ± 271.02（最短）** |
  | APE/CS− | 1654.33 ± 250.37 |
  | APS/CS+ | 1839.70 ± 342.70 |
  | **APS/CS−（静态 + 无描边）** | **2182.30 ± 316.86（最长）** |
  - 讨论节复述为 APE/CS+ **M = 1594.67 ms**、APS/CS− **M = 2183.50 ms**，与表 3 略有出入（**文内矛盾，建议引用表 3 数值**）。
  - **最优与最差之间差约 602.67 ms（按表 3：2182.30 − 1579.63）**。

### 4.2 总注视时长 TDT
- Dynamic 主效应 F = 54.60, *p* < 0.001, ηp² = 0.32；Contour 主效应 F = 4.22, *p* = 0.042, ηp² = 0.04；**Dynamic × Contour 交互 F = 23.86, *p* < 0.001, ηp² = 0.17**。
- 各条件均值（ms）：**APE/CS+ 1836.47 ± 359.52（落在 500–2000 ms 最优区间内，被判为最有效吸引注意）**；APS/CS+ 1607.27 ± 704.83；**APE/CS− 2471.30 ± 526.22（超过 2000 ms，被判为过长）**；**APS/CS− 1348.17 ± 319.23（被判为过短）**。
- 讨论节称「动态显著**减少**总注视时长」，但表 5 中动态条件（APE/CS+ 1836、APE/CS− 2471）实际**高于**对应静态条件（1607、1348）——**方向表述与数据矛盾，引用时必须以表 5 数据为准并注明**。

### 4.3 首次注视时长 / 首次注视时间 TTFF
- Dynamic 主效应 F = 16.59, *p* < 0.001, ηp² = 0.13；**Contour 主效应更强 F = 26.58, *p* < 0.001, ηp² = 0.19**；交互 F = 11.34, *p* = 0.001, ηp² = 0.09。
- 各条件均值（ms）：**APS/CS+ 186.30 ± 72.12**、**APE/CS− 176.37 ± 48.26**（两者均落在 100–300 ms 最优区间）；**APS/CS− 108.10 ± 35.34（被判为过短，可能导致 IB）**；**APE/CS+ 的数值在表 7 中被误填为 1836.47 ± 359.52（与 TDT 表重复），显然是排版错误**——原文称 APE/CS+ 首次注视时长最长、吸引注意最强，但该数值不可用。**引用时必须标注此错误。**

### 4.4 用户体验 UEQ
- Dynamic 主效应 F = 73.946, *p* < 0.001；Contour 主效应 F = 30.765, *p* < 0.001；**交互不显著 F = 0.012, *p* = 0.911**（即两者对主观体验的影响是**相加而非协同**）。
- UEQ 总分：**APE/CS+ 35.57 ± 2.32（最高）** > APE/CS− 33.13 ± 2.89 > APS/CS+ 31.77 ± 2.461 > **APS/CS− 29.23 ± 2.08（最低）**。
  - 讨论节另写「APE/CS+ 在所有 UEQ 维度得分最高，M = 5.93」——这是**单维度均分**（7 点量表）与总分 35.57 的两种表述，须区分。
- 维度层面（讨论节定性表述）：**动态显著性对「新颖性」与「吸引力」影响最大**；**轮廓显著性显著改善「易懂性」与「可依赖性」**。

### 4.5 作者的机制解释
「**轮廓通过高对比度『捕获（capture）』注意，动态变化通过运动线索『保持（hold）』注意**」——引自 [25] 的视觉显著性理论。轮廓增强图形边界对比，动态通过运动线索吸引注意，两者协同提升视觉搜索效率。

## 五、对 AR-HUD 行人预警时空设计的启示

### 5.1 时间参数
- **预警时机 / TTC 阈值**：**论文未使用 TTC 阈值**。动态放大的触发条件仅定性描述为「**车辆接近障碍物或感知到潜在危险时（as the vehicle approaches an obstacle or perceives a potential hazard）**」、「**在临近危险时（in proximity to danger）**」、「**在关键时刻（during critical moments）**」。**未给出触发距离、TTC 秒数或速度条件。**
- **预警提前期与预警时长**：**论文未明确报告**动态放大动画的持续时长、放大速率或帧率。作者在未来工作中明确承认这一缺口：「建议对**动态参数**进行精细化控制：探索不同**动画速度**与**图形变换幅度**对视觉注意的影响，以建立量化设计指南」。
- **闪烁频率 / 占空比**：**本文未采用闪烁，无闪烁频率或占空比数据**。但本文引用文献 [23] 的参数值得记录：**「闪烁动效 + 透明度 0.5–0.75」可有效缓解 IB**。
- **刺激呈现时长**：**论文未报告**单个 IB 事件的刺激呈现时长。
- **反应时基线（可直接引用，雨雾极端天气 + 恒速城市道路 + 方向盘按键）**：
  - 最优（动态放大 + 黑描边）**1579.63 ± 271.02 ms**；
  - 最差（静态 + 无描边）**2182.30 ± 316.86 ms**；
  - **显著性设计带来的净收益约 600 ms**。
  - 注意：这是**累积反应分数**（跨 trial 累积后的量纲），且反应通道为方向盘按键而非刹车踏板，量级不可与制动反应时（BRT）直接比较。
- **IB 判定时间窗（本文最具规范价值的时间参数）**：
  - **TDT 最优区间 500–2000 ms**：≤500 ms → 注意不足；≥2000 ms → 分心（复杂/遮挡/误导）；
  - **TTFF 最优区间 100–300 ms**：超出即未能吸引注意或检测延迟；
  - 本研究据此判定：**APS/CS−（TTFF 108.10 ms）过短，可能导致 IB**；**APE/CS−（TDT 2471.30 ms）过长，属分心**。
- **时序结构（单级 vs 分级）**：本文实质提出了一种**两级时间结构**——「常态阶段动画不变 → 临近危险阶段图标临时放大」，即**「临界时刻临时放大图标以增强注意捕获」**作为明确的设计建议。**但未给出两级之间的切换时刻或间隔秒数。**

### 5.2 空间参数
- **呈现位置 / 空间参照系**：AR-HUD 导航图形叠加于风挡；**论文未明确说明是贴地水平面、垂直面还是屏幕坐标**，仅称第一人称驾驶仿真中的导航图形。
- **视场角 / 偏心度**：**论文未报告角度值**。仅报告显示物理尺寸：**34 英寸屏、约 79 cm × 34 cm**（用以模拟典型风挡）；**未给出观察距离**，故无法反算视角。
- **图形尺寸（本文核心空间参数）**：**基准范围 150 × 150 px 至 300 × 300 px**（依据标准 AR-HUD 尺寸 [16],[37]）；**动态条件下箭头从 150 px 渐进放大到 300 px（即线性尺度 2 倍、面积 4 倍）**。
- **图形形态**：**回旋镖形（boomerang）导航箭头**（依据 [41]，且文献 [26] 报告回旋镖优于普通箭头）。
- **颜色**：**橙色**（理由：在雨雾条件下稳健 [42]）。
- **轮廓 / 描边**：**黑色描边（black outline）**为最优；文献依据明确指出**彩色描边可能与图形或背景融合造成混淆**，故应选黑色 [30]。
- **透明度**：**本文未设置透明度变量、未报告数值**；仅引用 [23] 的 0.5–0.75 区间。
- **与目标的相对位置**：本文的显著性设计作用于**导航图形**（非行人标注），故不涉及与危险目标的相对位置。
- **视觉拥挤 / 视觉复杂度定义**：本文以**天气引起的低照度与视觉噪声**替代视觉拥挤：雨天分小雨/中雨/大雨/暴雨 4 级、雾天分薄雾/浓雾 2 级，各 50 张图像；用 Image Color Summarizer 计算平均照度以设定实验亮度。**未给出具体照度（lux）数值**。场景元素包括建筑、树木、交通灯、路灯、道路标志、其他车辆、行人；道路类型含主干道、集散道路、高速公路、次要道路。

### 5.3 可直接写入设计规范的条目
1. **若** AR-HUD 图形需在低照度/低对比环境（雨、雾）中呈现，**则**必须为图形添加**清晰的黑色轮廓**以防止与环境视觉融合（§VI 结论建议 1；文献依据 [30]：彩色描边会与背景融合）。
2. **若**处于**临界时刻（接近危险）**，**则**采用**图标临时放大**以增强注意捕获：**150 px → 300 px**（§II、§VI 结论建议 2）。
3. **若**同时采用动态放大与黑色描边，**则**可获得：反应时 **1579.63 ± 271.02 ms**（相对静态无描边的 2182.30 ms 快约 600 ms）、TDT **1836.47 ms**（落入 500–2000 ms 最优区）、UEQ 总分 **35.57**（四条件最高）（§IV，Table 3/5/9）。
4. **若**只添加动态放大而**不加描边**，**则**总注视时长会升至 **2471.30 ms（> 2000 ms）**，判为分心——**动态必须与轮廓配套使用**（§IV.B.1）。
5. **若**评估 AR-HUD 图形的注意捕获是否合格，**则**采用门槛：**TTFF ∈ [100, 300] ms** 且 **TDT ∈ [500, 2000] ms**；TTFF < 100 ms 视为注意不足并可能引发 IB（本文 APS/CS− = 108.10 ms）（§II.C）。
6. **若**在雨雾条件下选择 AR-HUD 图形颜色，**则**橙色为已验证的稳健选择（§II.B.1，依据 [42]）。
7. **若**采用循环重复的固定动画，**则**须警惕**视觉疲劳与习惯化导致的 IB**（§II 文献综述的核心论证；作者亦在局限中承认本研究只测短期反应、未考察长期适应）。

## 六、本文局限性与未来工作
1. **Unity 仿真无法完全复现雨雾天气的复杂干扰**（作者自述）。
2. **样本为 20–25 岁、驾龄有限（M = 2.21 年）的年轻人**，对老年或经验丰富驾驶员的外推性存疑。
3. **只测短期反应**，未考察长期适应，特别是**反复暴露于显著元素导致的习惯化型 IB**。
4. **数值报告存在多处内部矛盾**（本摘要已逐条标注）：交互 *p* 值 0.015 vs 0.007；反应时均值 1579.63 vs 1594.67、2182.30 vs 2183.50；表 7 中 APE/CS+ 的 TTFF 被误填为 TDT 数值 1836.47；讨论称动态「减少」TDT 而数据显示动态条件 TDT 更高；IB 测试场景数 3 个 vs 4 个；眼动设备 Tobii 桌面式 vs Tobii Pro Glasses 3 并存。**这些是引用时必须声明的可靠性风险。**
5. **未来方向**：精细化动态参数（动画速度、变换幅度）以建立量化指南；多模态融合（视觉 + 听觉 / 触觉）；实车道路验证；加入心率、皮电等生理指标；被试选择需考虑年龄与经验的个体差异。

## 七、与本课题的关联与引用建议
- **可用于章节**：
  - 「空间参数」章——**尺寸规范（150–300 px、动态 2 倍放大）与轮廓（黑色描边）**是本课题目前唯一的显式量化条目；
  - 「时间参数 / IB 评估方法」章——**TTFF 100–300 ms、TDT 500–2000 ms** 两个门槛可直接写入实验的 IB 判定规范；
  - 「极端天气 / 低对比场景」章——本文是极少数专门做雨雾条件的 AR-HUD 显著性研究；
  - 「颜色选择」章——橙色在雨雾条件下的稳健性证据。
- **与已收录文献的一致处**：
  - 与 `09_2025_叶明慧` 一致：叶文采用 α = 0.75 透明度与闪烁动效，其依据链（Hussain & Park；Hou et al. 2024）与本文引用的 [23]「闪烁 + 透明度 0.5–0.75 可缓解 IB」是同一条证据；
  - 与 `80_2026_Shen` 一致：都支持「动态编码优于静态编码」用于打破认知隧道/IB；
  - 与 `34_2022_Zhong`（颜色可见度评估）互补：本文给出雨雾条件下的橙色选择依据；
  - 与 `24_2025_Li`（雾天 AR-HUD 信息冗余）同属雾天条件研究，宜并列讨论。
- **必须显式指出的冲突**：
  1. **「动态显著性是否减少总注视时长」——本文自相矛盾**：讨论节称动态显著**减少** TDT（表示更快完成信息加工、降低认知负荷），而表 5 的数据显示动态条件 TDT 反而更**高**（APE/CS+ 1836 > APS/CS+ 1607；APE/CS− 2471 > APS/CS− 1348）。**建议在引用中只采用「APE/CS+ 落入 500–2000 ms 最优区间」这一相对判断，避免复述「动态减少 TDT」的方向性结论。**
  2. **「更长的首次注视时长 = 更好」vs 通常的 TTFF 越短越好**：本文对 TTFF 的表述在两处不一致——§II.C 定义「TTFF 越短说明图形成功捕获注意」，而 §IV.B.2 与 §V.B 又称「APE/CS+ 的首次注视时长最长，说明吸引注意最强」。这实际上是把 **Time to First Fixation（首次注视的到达时间，越短越好）**与 **First Fixation Duration（首次注视的持续时长，越长表示加工投入越多）**两个不同指标混用了。**引用时必须明确区分这两个概念，并注明本文存在术语混用。**
  3. **本文（69）vs 本文引用的 [34]**：[34] 报告动画告警使检测时间减少 **25.64%**；本文的反应时收益约为 (2182.30−1579.63)/2182.30 ≈ **27.6%**，量级一致，可互相印证。
  4. **本文（69）vs `80_2026_Shen` 的「过强动效反而有害」**：本文只测「静态 vs 放大」两级，未测过强条件，因此**不能**用本文支持「动效越强越好」；Shen 的 75% 占空比结果（客观准确率降至 59.17%）表明存在**上限**。两文合起来的边界条件是：**动效需要「有」，但不能「过」**。
  5. **本文（69）vs `60_2021_Wang`「边界框过于突出」**：Wang 批评过强的包围式增强会俘获注意导致对未增强对象的 IB；本文只在**导航图形**上做显著性增强，并未评估「导航图形变强后对突发行人的 IB 影响」。**这是本文最重要的未覆盖风险：把导航箭头放大到 300 px 是否会提升对行人的 IB，本文无数据。撰写规范时须显式标注该缺口。**

> **Takeaway**：在雨雾极端天气下，「橙色回旋镖箭头 + 黑色描边 + 临危时从 150 px 放大到 300 px」使反应时从 2182 ms 降到 1580 ms（快约 600 ms / 27.6%），并把总注视时长稳定在 500–2000 ms 最优区间；但只加动态不加描边会使注视时长冲到 2471 ms 反成分心。
