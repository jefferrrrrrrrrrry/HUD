## 一、研究背景与问题

驾驶任务要求驾驶员在时间压力下处理大量视觉信息，但视觉处理容量有限，可能引发严重碰撞。ADAS 与 PCW 系统已被广泛部署，但传统警示往往缺乏空间信息（Kim 2016, Kim & Gabbard 2019），不能精确把注意力引导到具体危险位置，可能引发"盲反应"（Merenda 2018）。AR-HUD 通过把图形直接叠加在真实环境上，能保持驾驶员视线在道路上的同时提供时空信息。

AR 图形概念上分为两类：
- **屏幕固定（screen-fixed）**：固定在挡风玻璃特定区域；
- **世界固定（world-fixed / conformal）**：直接叠加在真实物体上，与之自然融合。

世界固定图形中又有两类主流原型：
- **虚拟阴影（virtual shadow, Kim et al. 2016）**：穹顶形贴地阴影；
- **接触式类比（contact-analog graphic）**：常用于导航提示，覆盖于关键物体（如前车整体上色），但其在"危险预警"中的有效性研究极少。

当前 AR 警示主流仍是**边界框（bounding box）**——一种"技术驱动"的设计（即机器视觉直接给出的边界框），可提供精确位置且不遮挡物体。但研究表明边界框可能引发注意收窄（attention narrowing）、降低对其他环境元素的预测能力。

两类图形在感知处理上存在差异：
- 边界框 = 低层视觉处理（简单几何形状即可定位）；
- 接触式类比 = 高层视觉处理（需要识别轮廓、判断危险类型）。

可证伪命题：
1. 两类 AR 警示在不同碰撞类型（追尾 vs. 行人）下表现是否不同？
2. 两类 AR 警示在不同交通密度下表现是否一致？
3. 两类图形的感知处理层级差异是否会影响警示效果？

## 二、研究方法

### 2.1 被试与样本
- N = 48（性别均衡，浙江理工大学便利取样）；
- 年龄：19–26 岁（M = 22，SD = 2.0）；
- 全部持中国驾照；
- 平均驾龄 2.7 年、平均里程 1,526 km；
- 均为新手驾驶员（novice drivers），无 AR-HUD 经验；
- 视力：正常或矫正后正常；
- 功效分析：MorePower 6，α = 0.05，power = 0.8，effect size = 0.2 → 至少 42 人。

### 2.2 实验设计
- 设计类型：三因素混合设计；
- 自变量：
  - AR 警示类型（**组间**，3 水平）：边界框警示 / 接触式类比警示 / 无警示对照；
  - 碰撞类型（**组内**，2 水平）：追尾碰撞 / 行人碰撞；
  - 交通密度（**组内**，2 水平）：高密度（1 车 / 150 m）/ 低密度（1 车 / 1500 m）；
- 因变量：
  - 反应时（reaction time，ms）；
  - 响应率（response rate，%）；
  - 用户体验问卷（UEQ）六维度：吸引力、可懂度、效率、可依赖性、新颖性、刺激性。
- 控制：4 个 block 顺序拉丁方逆平衡；行人左右出现随机平衡。

### 2.3 实验材料与设备
- **屏幕**：180 英寸投影屏；
- **投影仪**：Epson CB-935W，3700 流明；
- **AR-HUD 设备**：DGG01（张家港启点光电），双自由曲面反射光学，DMD 864 × 480，亮度 12,000 nit，刷新率 60 Hz；
- **背景物**：在被试视线前 3 m 处放置 LED 屏播放山景图，以模拟"AR 虚拟图像 vs. 远处真实物体"的辐辏-调节冲突；
- **驾驶模拟软件**：STISIMDRIVE M100K + Logitech MOMO 方向盘；
- **视频材料**：
  - 24 个视频，每段约 1.5 分钟，按 4 个 block（密度 × 颜色）划分；
  - 每 block 6 trial，每 trial 15 个事件（2 行人碰撞 + 1 追尾 + 超速 + 切入 + 闯红灯等）；
  - 自车恒速 54 km/h；
- **AR 警示颜色**：
  - 红色 RGB [255, 0, 0]；
  - 黄色 RGB [255, 255, 0]；
  - 每被试同时呈现两种颜色（以避免 AR 投影下的色相偏移问题）；
- **警示触发时机**：碰撞前 **3.0 s**（基于 Drueke 2018、Ma 2021、Zhang 2015）；
- **图形动效**：
  - 接触式类比：随物体运动动态改变形状；
  - 边界框：形状不变。

### 2.4 任务与流程
- 被试被告知"想象自己是司机"；
- 任务：观察视频，对意外事件（超速、闯红灯、变道、前车制动、行人横穿）按方向盘按钮反应；
- 前 3 个事件用于提高被试注意；
- 流程：知情同意 → 人口学问卷 → AR-HUD 适应 → 4 block 视频 → UEQ；
- 数据分析：广义估计方程（GEE），Bonferroni 校正多重比较。

## 三、关键指标与测量
- 反应时（RT, ms）；
- 响应率（%）；
- UEQ 六维评分（1–5，含基准等级 excellent / good / above average / below average / awful）。

## 四、主要结果与发现

### 1) 反应时
- 碰撞类型主效应显著：Wald χ²(1) = 124.228，p < 0.001；行人碰撞 RT > 追尾 RT；
- AR 警示类型主效应显著：Wald χ²(2) = 67.034，p < 0.001；两种 AR 警示均显著降低 RT；
- 交通密度主效应不显著：Wald χ²(1) = 0.073，p = 0.787；

**双因素交互**：
- 碰撞类型 × 警示类型：Wald χ²(5) = 391.539，p < 0.001
  - 在行人碰撞中：边界框 < 接触式 < 无警示（边界框比接触式短，p < 0.001）；
  - 在追尾中：边界框 ≈ 接触式 < 无警示（两 AR 间无显著差异，p = 0.293）。
- 碰撞类型 × 交通密度：Wald χ²(3) = 156.085，p < 0.001
  - 追尾：低密度 RT > 高密度 RT（p = 0.011）；
  - 行人：密度间无显著差异（p = 0.055）。
- 警示类型 × 交通密度：Wald χ²(5) = 91.171，p < 0.001
  - 高密度：边界框 < 接触式（p = 0.019）；
  - 低密度：边界框 < 接触式（p = 0.015）。

**三因素交互**：Wald χ²(11) = 445.855，p < 0.001
  - 行人碰撞：两密度下边界框均短于接触式（高 p < 0.001、低 p = 0.003）；
  - 追尾：两密度下两 AR 警示均无显著差异。

### 2) 具体反应时数据（Mean ± SD，ms）
| 条件 | 高密度追尾 | 低密度追尾 | 高密度行人 | 低密度行人 |
|---|---|---|---|---|
| 接触式 CA | 686.66 (284.27) | 804.28 (350.58) | 1507.70 (435.57) | 1354.52 (433.88) |
| 边界框 BB | 835.28 (426.96) | 824.51 (285.61) | 1062.83 (392.85) | 1051.32 (347.90) |
| 无警示 | 1188.09 (456.07) | 1341.51 (501.15) | 2131.44 (296.16) | 1976.30 (370.91) |

### 3) 响应率
- 所有主效应与交互均不显著（响应率均较高，无显著差异）；
- 不显著的趋势：在追尾中接触式响应率略高于边界框；
- 接触式在追尾"高密度 96.87%、低密度 96.88%"；
- 边界框在行人"高密度 93.75%、低密度 96.87%"；
- 无警示在行人"高密度 81.25%、低密度 90.62%"。

### 4) UEQ 主观评价
- 边界框在**可懂度**（perspicuity）p = 0.003、**可依赖性**（dependability）p = 0.026 上显著高；
- 边界框在 perspicuity 与 dependability 上达到 "excellent" 评级，而接触式仅 "below average"；
- 接触式 novelty 略高（p = 0.67）但不显著；
- 其他维度（吸引力、效率、刺激性）虽边界框略高但不显著。

## 五、对AR-HUD时空设计的启示

### 时间元素
- **警示触发时机：碰撞前 3.0 s**（基于既有文献综合推荐）；
- 行人碰撞 RT 普遍约为追尾 RT 的 1.5–2 倍（说明外周视觉响应慢）；
- 警示可减少 RT 在追尾中约 40%，在行人碰撞中约 50%；
- 在多警示场景中"过早呈现"反而可能增加认知负荷。

### 空间元素（平面）
- **颜色**：红 [255, 0, 0]、黄 [255, 255, 0]；论文谨慎地同时给出两种颜色以应对 AR 色相偏移；
- **形状**：
  - 边界框：固定矩形（静态形状）；
  - 接触式类比：随物体运动**动态变形**；
- **覆盖范围**：
  - 边界框：仅勾边，不遮挡，可能含入无关物体；
  - 接触式类比：大面积上色覆盖，可能造成颜色掩蔽/重叠错觉，使物体感觉"更远"。

### 空间元素（立体）
- 空间锁定：均为 world-fixed（贴合式）；
- HUD 显示在挡风玻璃中央 + LED 屏背景 3 m 处，模拟辐辏-调节冲突；
- **中央 vs. 外周视觉的关键差异**：
  - 中央视场（追尾）：接触式表现更好（大面积色块更有视觉连接性）；
  - 外周视场（行人侧面出现）：边界框表现更好（高显著性几何形状更易抓住外周注意）。

### 设计原则与适用边界
- **设计原则**：
  - 追尾场景（中央视场）→ 推荐接触式类比；
  - 行人场景（外周视场）→ 推荐边界框；
  - 外周视觉感知能力弱，应避免使用需要高层处理的复杂图形；
- 适用：中国新手驾驶员；
- 不适用：未经验证于经验驾驶员；
- 视觉感知层级与图形复杂度的权衡是设计核心。

## 六、本文局限性与未来工作
- 仅使用预录视频，被试无法主动控制车辆，任务相对简单；
- 真实 AR 设备引入深度/焦距冲突，可能影响外部效度；
- 真实道路远比仿真复杂，生态效度有限；
- 未涉及"不可见危险"（如遮挡后的行人）；
- 组间设计导致每组样本较少；
- 全部为中国新手驾驶员，未推广至经验驾驶员或其他人群；
- 未量化 AR 图形的精确尺寸与亮度参数；
- 未涉及夜间、雨雾天气。

## 七、与本研究主题（HUD/AR-HUD行人标注的时间空间设计规范）的关联

**时间设计规范**：
- 明确推荐"碰撞前 3.0 s"作为警示触发时机；
- 量化了追尾 RT（约 700–800 ms）与行人 RT（约 1000–1500 ms）的差异，证明外周视觉响应需要更激进的提前量；
- 两 AR 警示均使行人 RT 减半（从 ~2000 ms 至 ~1000–1500 ms）。

**空间设计规范**：
- 给出 AR 警示颜色 RGB 推荐：红 [255, 0, 0]、黄 [255, 255, 0]；
- 提供"边界框 vs. 接触式类比"的具体使用场景指南：
  - 中央视场 / 追尾：接触式类比（大面积色块、动态贴合）；
  - 外周视场 / 行人：边界框（高显著性几何）；
- 强调感知处理层级在 AR 警示设计中的重要性——低层视觉处理（边界框）适合外周，高层处理（接触式类比）只适合中央；
- UEQ 显示边界框在可懂度、可依赖性上获优势，提示用户主观更接受边界框；
- 提出"驾驶员对外周复杂图形难以辨认"原则——道路标志亦应简化以适合外周视觉。

> **Takeaway**：本文以 48 名中国新手驾驶员、真实 AR-HUD 设备、三因素混合设计严谨地证明：边界框警示更适合外周视觉的行人碰撞（RT 约 1051–1063 ms vs. 接触式 1354–1508 ms），而接触式类比警示更适合中央视觉的追尾（响应率略高）；进一步从"低层 vs. 高层视觉处理"的认知视角，为 AR-HUD 警示图形设计提供了"场景-视场-图形复杂度"的匹配指南。
