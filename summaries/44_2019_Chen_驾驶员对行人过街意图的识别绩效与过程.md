## 一、研究背景与问题

### 1.1 领域现状
行人占交通事故总死亡的 22%（WHO, 2013）。作者引用 Endsley 的情境意识（situation awareness）三层理论：驾驶员必须先**探测**行人 → 再**识别**其意图 → 再**预测**其未来状态，然后才能作出行为响应。既有文献几十年来集中在第一层（行人显著性/探测），而**第二层「意图识别」的研究极其稀缺**。
- 已知行人的显式沟通线索（手势、微笑、眼神接触）会显著提高驾驶员让行率；隐式线索（快走向路缘、踏上斑马线、较小的横向距离、不看车流）同样提高让行率。
- 关于意图识别本身仅有两项先驱研究（Schmidt, Färber & Grassi, 2008；Schmidt & Färber, 2009），发现驾驶员主要用 5 类线索：头部运动、腿部运动、步态动力学、行人特征、交通环境。

### 1.2 研究缺口
Schmidt & Färber 的研究采用**第三方视角、无自车运动、无时间限制**的视频，与真实驾驶完全不同：真实场景下驾驶员必须在**极短的时间窗内**、在自车持续接近的过程中完成意图判定，且距离会决定某些线索（如头部朝向）是否可用。因此「意图能否在所有情境下被识别」「哪些因素调节识别绩效」这些基本问题仍未解答。

### 1.3 核心研究问题
1. 驾驶员判定行人过街意图的绩效（准确性、敏感性 d′、反应偏向）如何？
2. 该绩效如何随**驾驶经验**、**到达时距 TTA（time-to-arrival）**、**行人真实意图**变化？
3. 意图识别的认知过程是什么（眼动证据 + 证据累积模型）？

## 二、研究方法

### 2.1 被试与样本
- 40 名持照驾驶员（29 男 11 女），有偿。
- **新手组** n = 20：里程 < 10,000 km（范围 50–10,000 km，M = 1,031 km，SD = 2,369 km），本科生，年龄 M = 21.5（SD = 1.93），平均驾龄 1.7 年。
- **熟练组** n = 20：里程 > 100,000 km（范围 100,000–1,500,000 km，M = 431,500 km，SD 原文印为「337,99 km」，疑为排版错误），职业司机（如出租车），年龄 M = 35.7（SD = 7.4），平均驾龄 11.2 年。
- 视力或矫正视力正常；问卷显示无事故史。

### 2.2 实验设计
- **2（驾驶经验：熟练 vs 新手，被试间）× 2（行人真实意图：过街 vs 不过街，被试内）× 4（TTA：2、3、4、5 s，被试内）混合设计**。
- **TTA 定义**：视频截断处的最后一帧与「自车到达自车路径与行人路径交点」之间的时间差。即 TTA = 4 s 意味着被试在碰撞点前 4 s 处被要求做判定。
- **因变量**：判定准确性（命中率 hit rate / 虚警率 false alarm rate）、信号检测论参数（敏感性 d′、判定标准 C、反应偏向 β）、反应时 RT、眼动指标（探测率、探测潜伏期、首次注视时长、平均注视时长、注视位置分布）。
- 统计：混合 ANOVA（TTA 因素仅取 3/4/5 s，见下）、配对 t 检验、Spearman 相关。
- **重要排除**：TTA = 2 s 条件下 710 个 trial 中有 690 个（**97.1%**）行人最终没有过街，样本严重失衡，故 TTA = 2 s 未进入 ANOVA。

### 2.3 实验材料与设备
- 视频采集：GoPro Hero 6 固定于风挡，由 5 名职业司机在西安（与被试同城）多日实录，司机对研究目的不知情。原始 3840×2160 @ 60 Hz，剪裁压缩为 3840×1080 @ 30 Hz。
- 事件筛选规则：① 录制车为行人前方最前车且**未减速**（保证行人意图不是对让行的反应）；② 目标行人全程可见，场内行人 1–3 人（非人群）；③ **无信号灯**分配路权。
- 素材构成：共选 117 个交互事件，8 个练习 + 109 个正式（43 个「过街」事件、57 个「不过街」事件、9 个「噪声」事件——行人只在人行道行走，用于促使主动视觉搜索）。全部城市道路，其中 16 个有斑马线；车道数 2–8（2 车道 23 例、3 车道 9 例、4 车道 23 例、6 车道 45 例、8 车道 9 例）。
- 每个交互事件按 4 个 TTA 切出 1–4 个片段；若截断帧处行人已踏上车道或被遮挡则该片段剔除。前接一段长度可变的「正常驾驶」画面（行人尚未出现），使被试无法预期行人出现时刻。**最终合成片段时长 7–15 s（2 s 为间隔）**。
- 显示：3 台 24 英寸 Dell U2414H（各 1920×1080），相邻屏夹角 135°，中央屏正对被试，观察距离 62 cm。
- 眼动：EyeLink 1000 plus，**采样率 1000 Hz**，tower 模式。响应设备：摇杆（两键分别对应两种判定）。

### 2.4 任务与流程
- 每 trial：片段首帧静态呈现 **3 s** 作为场景预览 → 片段自动播放 → 结束帧上立即出现**黄色矩形框**标出待判定的目标行人 → 矩形框与末帧最多保持 **1 s** → 黑屏直至被试反应（黑屏最长 **4 s**）。
- 被试须在指示后**尽快**判定「会过街 / 不会过街」。**全程不给反馈**。
- 8 个练习 trial + 109 个正式 trial（分 3 个 block：36/36/37）。每个 block 开始做 5 点标定与验证。全程约 60 min。

## 三、关键指标与测量

| 类别 | 指标 | 操作化定义 |
|---|---|---|
| 时间类 | **TTA** | 判定时刻到自车到达冲突点的剩余时间（2/3/4/5 s） |
| 时间类 | **RT（判定反应时）** | 从黄色矩形指示出现到摇杆响应的时间间隔（剔除超出 ±2.5 SD 的 trial） |
| 时间类 | **探测潜伏期** | 从行人出现到首次注视落入 AOI 的时长 |
| 时间类 | 首次注视时长、平均注视时长、dwell time | 注视定义为在场景内停留 ≥ 100 ms |
| 时间窗 | 判定可用时间 | 指示出现后末帧保持 1 s + 黑屏最多 4 s |
| 绩效 | 命中率 / 虚警率 / d′ / C / β | 依信号检测论；「会过街」= Yes 反应 |
| 空间 | 注视位置比例 | 相对 AOI 的水平/垂直偏移归一化到 0–1；简化为 top/middle/bottom 三等区 |

- 探测阶段 AOI = 紧包行人矩形的约 1.5 倍；AOI 平均仅占中央屏面积约 1%（范围 0.1%–6%）。
- 8% 的 trial 因黑屏前 AOI 内无注视或采样率 < 80% 被剔除。
- **7.6% 的 trial 中被试在指示出现前未探测到行人**。

## 四、主要结果与发现

### 4.1 探测阶段（眼动）
- **探测率**：经验主效应 F < 1（不显著）。意图主效应 F(1, 38) = 66.69, *p* < 0.001, partial η² = 0.637——过街行人 M = 0.95 (SE = 0.006) 高于不过街行人 M = 0.86 (SE = 0.011)。**TTA 主效应 F(2, 76) = 19.76, *p* < 0.001, partial η² = 0.342——TTA = 3 s 时 0.95 > 4 s 0.89 > 5 s 0.88（ps < 0.001）**。意图×TTA 交互边缘显著 F(2, 76) = 3.01, *p* = 0.055, partial η² = 0.073；事后检验显示各 TTA 水平上不过街行人的探测率均更低，且**TTA 越大差距越大**（ps < 0.002）。
- **探测潜伏期**：经验 F(1, 38) = 1.81, *p* = 0.186；意图 F(1, 38) = 5.71, *p* = 0.022, partial η² = 0.131——**过街行人 M = 1345 ms (SE = 57)，不过街 M = 1445 ms (SE = 50)**（早约 100 ms）。
- **首次注视时长**：熟练 634 ms vs 新手 558 ms，F(1, 38) = 1.69, *p* = 0.202；意图 F(1, 38) = 12.17, *p* = 0.001, partial η² = 0.243——**过街 646 ± 39 ms > 不过街 545 ± 25 ms**。

### 4.2 意图判定的准确性、敏感性与偏向
- **真实基线随 TTA 剧变**（「不过街」事件占比）：TTA = 3 s 时 648/854 = **75.9%**；4 s 时 602/1210 = **49.8%**；5 s 时 340/1226 = **27.7%**。即 TTA 越大，行人最终真的会过街的比例越高。
- **总体命中率**：熟练 0.92 vs 新手 0.91，t = 0.26, *p* = 0.797（无差异）；**虚警率**：熟练 0.43 > 新手 0.30，t = 2.26, *p* = 0.029。
- **命中率 / 虚警率（Table 1，均值 (SE)）**

| 组 | Hit 3 s | Hit 4 s | Hit 5 s | FA 3 s | FA 4 s | FA 5 s |
|---|---|---|---|---|---|---|
| 熟练驾驶员 | 0.86 (0.015) | 0.92 (0.015) | 0.90 (0.026) | 0.39 (0.048) | 0.43 (0.056) | **0.55 (0.049)** |
| 新手驾驶员 | 0.89 (0.008) | 0.93 (0.011) | 0.87 (0.022) | 0.31 (0.045) | 0.28 (0.039) | 0.35 (0.050) |

- **敏感性 d′**：新手 M = 1.960 (SE = 0.118) 显著高于熟练 M = 1.535 (SE = 0.118)，F(1, 38) = 6.49, *p* = 0.015, partial η² = 0.146。**TTA 主效应 F(2, 76) = 7.36, *p* = 0.001, partial η² = 0.162；TTA = 4 s 时 d′ 显著高于其他两个 TTA（所有 ps < 0.004）**。交互不显著 F(2, 76) = 0.21, *p* = 0.809。
- **判定标准 C**：熟练 −0.625 (0.086) 边缘低于新手 −0.382 (0.086)，F(1, 38) = 4.02, *p* = 0.052, partial η² = 0.096。TTA 主效应 F(2, 76) = 10.24, *p* < 0.001, partial η² = 0.212；交互 F(2, 76) = 4.19, *p* = 0.019, partial η² = 0.099。**熟练驾驶员在 TTA = 5 s 时标准显著更低（更倾向报「会过街」，ps < 0.001），新手在所有 TTA 保持稳定（ps > 0.07）；两组差异在 TTA = 5 s 时达到显著（*p* = 0.015）**。
- **反应偏向 β**：主效应均不显著（F(1, 38) = 2.89, *p* = 0.098；F(2, 76) = 1.46, *p* = 0.239），交互边缘显著 F(2, 76) = 2.76, *p* = 0.069, η²p = 0.068；TTA = 5 s 时熟练 < 新手（*p* = 0.039）。**所有条件下 β < 1，说明驾驶员整体采用宽松（liberal）标准，偏向于说「行人会过街」**。

### 4.3 判定反应时 RT
- 经验：熟练 762 ms vs 新手 846 ms，F < 1（不显著）。
- **TTA 主效应 F(2, 76) = 33.50, *p* < 0.001, partial η² = 0.469；TTA 越大 RT 越长（所有 ps < 0.001）**——因为 TTA 大意味着可用于累积证据的时间少。
- **意图主效应 F(1, 38) = 114.42, *p* < 0.001, partial η² = 0.751——过街 M = 645 ms (SE = 40) 显著快于不过街 M = 964 ms (SE = 54)，差值达 319 ms**。
- 所有交互均不显著（ps > 0.08）。
- 按被试**自身判定**分：「会过街」判定 738 ± 42 ms 快于「不会过街」判定 915 ± 51 ms，t = −7.59, *p* < 0.001。

### 4.4 意图判定阶段的眼动分布
- 水平方向注视基本对称：48.3% 的注视落在归一化位置 < 0.5。
- **垂直方向明显偏上：66.4% 的注视落在位置 < 0.5（即上半身）**。
- 平均注视时长：熟练 676 ± 27 ms > 新手 576 ± 27 ms，F(1, 38) = 6.65, *p* = 0.014, partial η² = 0.149；但把「正常驾驶段」的注视一并计入后组间无差异（熟练 449 ms vs 新手 433 ms，t = 0.72, *p* = 0.477）——说明差异来自意图识别任务本身。
- 意图：过街 661 ± 20 ms > 不过街 592 ± 21 ms，F(1, 38) = 27.44, *p* < 0.001, partial η² = 0.419。
- 位置：F(2, 76) = 16.88, *p* < 0.001, partial η² = 0.308，上区注视时长显著长于下区（ps < 0.005）。

### 4.5 探测与识别的连续性
- 「指示前已探测」的 trial RT = 776 ± 43 ms，显著短于「指示前未探测」的 1157 ± 61 ms，t = −12.49, *p* < 0.001（**差值 381 ms**）。
- 在「指示前已探测」的 trial 中，dwell time 与 RT 呈显著负相关（Spearman *r* = −0.208, *p* < 0.001）：注视越久，判定越快。
- 作者由此提出意图识别的**两阶段模型**：① 探测后紧随的「粗筛」（对潜在危险打标签）；② 符合证据累积（evidence accumulation / dynamic signal detection）的「精判」。「会过街」的判定阈值更低，故更快、更常被采纳。

## 五、对 AR-HUD 行人预警时空设计的启示

### 5.1 时间参数（本课题核心）

#### 5.1.1 预测时间窗与「预警最早能提前到多久」的可靠性上界
本文是**人类驾驶员**在不同预测时域上的意图判定绩效曲线，可直接作为机器预警系统的对照基线：

| 预测时域 TTA | 实际「会过街」比例 | 命中率（熟练/新手） | 虚警率（熟练/新手） | 敏感性 d′ | 判定 RT 趋势 |
|---|---|---|---|---|---|
| **2 s** | 仅 2.9%（690/710 不过街）→ 样本退化，未做 ANOVA | 论文未报告 | 论文未报告 | 论文未报告 | 最短 |
| **3 s** | 24.1%（206/854） | 0.86 / 0.89 | 0.39 / 0.31 | 低于 4 s（*p* < 0.004） | 最短 |
| **4 s** | 50.2%（608/1210） | **0.92 / 0.93** | 0.43 / 0.28 | **最高（显著优于 3 s 与 5 s）** | 中 |
| **5 s** | 72.3%（886/1226） | 0.90 / 0.87 | **0.55 / 0.35** | 低于 4 s | 最长 |

- **关键结论 1：TTA = 4 s 是人类意图判别力（d′）的最优点**。更早（5 s）虚警率急升（熟练驾驶员达 0.55，即一半以上的「不过街」行人被误判为「会过街」）；更晚（3 s、2 s）虽虚警下降，但可用制动时间不足且样本本身偏向「不过街」。
- **关键结论 2：预警提前量的代价是虚警率**。熟练驾驶员从 3 s → 5 s，虚警率由 0.39 升至 0.55（+0.16）；新手由 0.31 升至 0.35（+0.04）。**若 AR-HUD 要把预警提前到 TTC ≈ 5 s，必须容忍约 35%–55% 的「行人其实不会过街」的误标注**，并据此设计低侵入的分级视觉形态。
- **关键结论 3：TTA ≤ 2 s 时行人几乎已不再过街（97.1% 不过街）**——说明「行人是否过街」的不确定性主要集中在 TTC 3–5 s 区间，这正是 AR-HUD 标注最有价值也最容易误报的窗口。

#### 5.1.2 驾驶员反应时基线
- **意图判定反应时（不含制动）**：整体 645–964 ms；熟练 762 ms、新手 846 ms（差异不显著）。
- **意图类型的时间代价**：不过街行人的判定比过街行人慢 **319 ms**（964 vs 645 ms）——即线索不充分时驾驶员会「拖延」决策。
- **判定内容的时间代价**：作出「不会过街」判定比「会过街」慢 **177 ms**（915 vs 738 ms）。
- **未提前探测的时间代价**：若行人在被提示前未被注视，判定 RT 由 776 ms 增至 **1157 ms（+381 ms）**。→ **AR-HUD 若能把行人提前引入注意，可为决策链节省约 380 ms**，这是本文对 AR-HUD 最直接的量化收益估计。
- 行人探测潜伏期：过街 1345 ms、不过街 1445 ms（自行人进入视野起算）。
- 首次注视时长 545–646 ms；意图判定期平均注视时长 576–676 ms。→ **AR-HUD 图形若要不打断这段「上半身证据累积注视」，其驻留时长应至少覆盖 600 ms 量级**。
- 论文未明确报告制动反应时（BRT）——被试仅按摇杆，无踏板操作，作者亦在局限中承认真实驾驶下熟练驾驶员可能更快。

#### 5.1.3 时序结构
- 论文未直接测试分级预警。但由「d′ 在 4 s 最优、虚警在 5 s 剧增」可推导**两级时序**：TTC ≈ 5 s 给出低侵入的「注意」级（容忍高虚警）、TTC ≈ 4 s 升级为「意图确认」级（此时人机判别力都最高）、TTC ≈ 3 s 及以下进入制动/紧急级。升级间隔约 1 s。
- 实验用的操作化时间窗可复用：预览 3 s、指示保持 1 s、响应窗最长 4 s、判定 RT 剔除阈 ±2.5 SD。

### 5.2 空间参数
- **最关键的空间发现：驾驶员把注视集中在行人的上半身**——垂直方向 66.4% 的注视落在归一化位置 < 0.5，上区注视时长显著长于下区（F(2, 76) = 16.88, *p* < 0.001, partial η² = 0.308）；作者指出上 1/3 即头部区域。水平方向对称（48.3% < 0.5）。
- **设计含义**：AR-HUD 的行人标注若采用 contact-analog 包围框/高亮，**不应遮挡行人上半身尤其头部**（头部朝向是驾驶员与算法共用的最强意图线索）；建议采用底部半包围、贴地投影或上方悬浮标记，把「证据区」留空。
- 作者明确指出：人类驾驶员依赖上半身，而部分机器意图识别算法（如 Köhler et al., 2012）依赖躯干弯曲与双腿张开——**人机线索不一致**，AR-HUD 若把算法置信度可视化，需注意与驾驶员自身的证据源保持一致，否则会造成「系统说会过街，但我看头没转」的信任冲突。
- 视场/偏心度：目标行人 AOI 仅占中央屏面积约 1%（0.1%–6%），三屏系统覆盖水平约 135° 夹角布置，观察距离 62 cm——可作为「远距离小尺寸行人」标注的可见性参考条件；论文未报告具体偏心度（度）。
- 论文未涉及颜色、透明度、闪烁频率、占空比。

### 5.3 可直接写入设计规范的条目
1. **若** AR-HUD 行人意图预警需在保证判别力的前提下尽早触发，**则**把「意图确认级」标注设在 **TTC ≈ 4 s**——该点人类 d′ 最高（显著优于 3 s 与 5 s，ps < 0.004），命中率 0.92–0.93（§3.2.1，Fig. 3）。
2. **若** 要把预警提前到 **TTC ≈ 5 s**，**则**必须按 **35%（新手基线）～55%（熟练基线）** 的虚警率设计低侵入形态（弱化亮度/尺寸/无声），避免高频误标注导致信任下降（Table 1）。
3. **若** TTC ≤ 2 s，**则**不再适用「意图型」预警——该时域下 97.1% 的行人已不再过街，应直接切换为紧急制动型预警（§2.5「TTA=2 s 排除说明」）。
4. **若** AR-HUD 能在驾驶员自主注视前先把行人引入注意，**则**可为其意图判定节省约 **381 ms**（1157 ms → 776 ms，t = −12.49, *p* < 0.001，§3.3）；这是评估 AR-HUD 收益的定量指标。
5. **若** 设计 contact-analog 行人标注的几何形态，**则**必须**保留行人上半身/头部的视线通路**——66.4% 的意图判定注视落在上半身，上区注视时长显著最长（§3.2.3，Fig. 5–6）。
6. **若** 预警图形有驻留时长参数，**则**其下限应 ≥ 意图判定 RT 上界约 **1 s**（不过街条件 964 ms；未提前探测条件 1157 ms），否则会在证据累积完成前撤销。
7. **若** 用户群含新手驾驶员，**则**注意新手的 d′ 更高（1.960 vs 1.535）但判定标准更保守稳定、且不随 TTA 调整——**新手更需要「随 TTC 自动放宽阈值」的系统辅助**，熟练驾驶员已自发在 5 s 处放宽标准（§3.2.1）。

## 六、本文局限性与未来工作
1. **生态效度**：视频 + 摇杆判定，无车辆控制任务，工作负荷低于真实驾驶；作者认为这可能高估了被试（尤其熟练操作摇杆的年轻新手）的绩效，真实驾驶中熟练驾驶员可能更快。
2. **地面真值定义**：以「行人是否在录制车通过前实际过街」作为意图真值，但真实意图还取决于驾驶员响应与整体交通状况；且录制车明确「未减速」，属单向交互。
3. **交互单向性**：真实驾驶员-行人交互是双向的；现有驾驶模拟器只有僵硬的内置行人模型，行人模拟器只有内置车辆模型，作者呼吁开发可双向联动的仿真环境（Lehsing et al., 2016）。
4. **未测制动**：无踏板响应，因此无 BRT 数据。
5. **未来方向**：区分「粗筛」与「精判」两阶段机制；比较机器视觉与人类驾驶员在同等情境下的绩效，若机器更强则可用 ADAS 辅助人类判定（Houtenbos et al., 2005），若人类更强则应把上半身线索加权入算法。

## 七、与本课题的关联与引用建议

### 7.1 可用于论文哪一章
- **「预警时机（时间参数）」章的人类基线**：本文是本批文献中唯一给出**同一实验内 TTA 2/3/4/5 s 四个时域上完整绩效曲线**的研究，可作为「预警最早能提前到多久」这一问题的**人类上界**（d′ 峰值在 4 s，5 s 虚警 0.55）。
- **「AR-HUD 收益量化」**：381 ms 的注意引导收益可直接用作实验假设的效应量估计。
- **「行人标注几何形态」章**：上半身 66.4% 注视比例是「不得遮挡头部」这一空间规范的直接证据。
- **方法学**：TTA 切片法（把同一交互事件按 2/3/4/5 s 切成多个刺激）可直接迁移为我们 AR-HUD 实验中「预警提前期」的自变量操作化方法；SDT（d′/C/β）分析框架可用于区分「预警是否让驾驶员更敏感」与「预警是否只是让驾驶员更保守」——这是纯准确率无法区分的。

### 7.2 与已收录文献的一致 / 冲突之处
- **与 87（Cangut & Alver, 2026）的时域冲突**：Cangut 把意图预测的未来时域定为 **0.5–1.0 s**、安全缓冲 0.5–2.0 s，而本文表明**TTC 2 s 时行人已基本不再过街**，即 0.5–1.0 s 的机器预测时域落在「不确定性已消解」的区间，其 84.6% 的 F1 并不能证明它能支撑 4–5 s 的早期预警。**两者不可直接比较：机器指标的高低必须绑定预测时域**。这是本课题必须在综述中显式指出的方法学冲突。
- **与 89（Wolf, 2021）一致**：Wolf 把预警门限设为「相交时间 < 4 s」，与本文 d′ 峰值 TTA = 4 s 高度吻合，两者从人（心理物理）与机（工程实现）两端独立指向同一时间点，可互相印证。
- **与 86（Chang & Chang, 2009）的量级一致**：Chang 推导的公交预警提前期 Twd = 6.07–6.28 s（含 2.1–2.3 s 感知反应时 + 50 km/h 制动距离），比本文的意图判定最优点 4 s 更早——原因是 Chang 的 Twd 是「从预警到完全停车」的**全链路**时间，而本文的 TTA 是**判定时刻**；两者相加逻辑上一致（4 s 判定 + 后续制动），不构成冲突，但在写规范时必须明确区分「意图可判定时刻」与「预警须发出时刻」。
- **与 09（叶明慧, 2025）的补充关系**：叶文给出预警图形持续 3 s 的基线，本文给出判定 RT 上界 ≈ 1 s（未提前探测时 1157 ms），说明 3 s 驻留有充分余量。
- **与「更早预警 → 信任下降」类结论（如 74_Abe 报警时机与信任）一致**：本文用虚警率给出了「为什么更早的预警会损害信任」的机制性数据——5 s 处熟练驾驶员的虚警率 0.55，即使人类自身也无法在该时域可靠判别，机器系统同样受此**行为不确定性上限**约束，而非算法能力不足。

> **Takeaway**：人类驾驶员对行人过街意图的判别力在 **TTA = 4 s** 达到峰值（命中率 0.92–0.93），提前到 5 s 则熟练驾驶员虚警率飙升至 0.55、而 TTA ≤ 2 s 时 97.1% 的行人已不再过街——因此 AR-HUD 意图型预警的可靠时间窗为 **TTC 3–5 s**，且预先引导注意可为判定节省 **381 ms**。
