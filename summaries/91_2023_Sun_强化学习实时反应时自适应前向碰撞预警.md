## 一、研究背景与问题

### 1.1 领域现状
摘要以三类 FCW 模型作为对照基线：**基于 TTC 的经典模型（TTC-based classical model）**、**自适应模型（adaptive model）**，以及本文提出的 **RL-AFCWS**。这一分层本身即表明：工程界已把「TTC 固定阈值」视作待超越的起点，而「自适应」是公认的演进方向。

摘要点出的两个核心概念：
- **DRT（driver reaction time，驾驶员反应时）**：本文把它当作**因人而异、且随时间变化的实时量**，而非常数；
- **alarm interference（报警干扰）**：即骚扰报警造成的干扰，是本文要「大幅减少（greatly reducing）」的代价项。

### 1.2 研究缺口
- 经典 TTC 模型用**统一固定阈值**，无法区分驾驶员个体；
- 既有「自适应模型」的自适应依据摘要未说明，但本文的贡献声明暗示其**未把个体 DRT 作为在线输入**；
- 结果是：**要么阈值过早（报警干扰大），要么过晚（漏掉真危险）**，且**同一阈值对不同驾驶风格（driving styles）的驾驶员意味着不同的实际紧迫度**。

### 1.3 核心研究问题
提出 **RL-AFCWS（reinforcement learning-based adaptive forward collision warning system）**，其两段式结构为：
1. 用**曲线匹配算法（curve matching algorithm）**，通过匹配**前车—后车对（preceding-following vehicle pairs）的轨迹**，**实时获取 DRT**；
2. 构建 **DQN（deep Q network）** 模型，以**轨迹数据 + DRT 为输入**，**预测碰撞预警的激活状态（activation state of the collision warning）**。

即：把「是否报警」从规则判定改写为**强化学习的策略输出**，且策略的状态空间中包含**个体实时反应时**。

## 二、研究方法（仅摘要可得）

### 2.1 被试与样本
- **无人类被试实验**。数据为 **NGSIM 真实驾驶数据集（real driving data set NGSIM）**，且明确选取了**两个不同时段（two different periods）**的样本以提升准确率。
- 具体路段（I-80 / US-101 / Lankershim 等）、时段名称、样本条数、前后车对数量、车辆类型：**摘要未报告**。
- 训练/验证/测试划分、DRT 的真值标注方式（曲线匹配的输出是否有独立校验）：**摘要未报告**。

### 2.2 实验设计
- 性质：**算法建模 + 数值实验（numerical experiments）**，非人因实验；无被试内/被试间设计，无统计检验。
- 对照条件：**TTC-based classical model** 与 **adaptive model** 两个基线。两基线的具体阈值设定：**摘要未报告**。
- DQN 的网络结构、状态/动作/奖励函数定义、折扣因子、训练回合数：**摘要未报告**。**尤其是奖励函数——它才是「何时该报警」这一价值判断的真正载体，摘要完全未披露。**

### 2.3 实验材料与设备
- 数据来源：NGSIM 公开轨迹数据（车辆轨迹采样率、路段几何）；具体规格**摘要未报告**。
- 无 HMI 硬件（不含 HUD、扬声器、触觉装置）；报警的呈现模态与形式：**摘要未报告**。

### 2.4 任务与流程
可复原链条为「NGSIM 两时段轨迹 → 曲线匹配估 DRT → 轨迹 + DRT 输入 DQN → 输出报警激活状态 → 与 TTC 经典模型/自适应模型对比准确率、真正率与报警干扰」。各步细节**摘要未报告**。

## 三、关键指标与测量

| 指标 | 类型 | 操作化定义（摘要层面） |
|---|---|---|
| **accuracy rate（准确率）** | 分类性能 | 报警判定与标签的一致率；RL-AFCWS 达 **94%** |
| **true positive rate（真正率 / 召回率）** | 分类性能 | 真实危险中被正确报警的比例；RL-AFCWS 为 **49%** |
| **alarm interference（报警干扰）** | 骚扰代价 | 骚扰报警造成的干扰；仅报告「大幅减少（greatly reducing）」，**无数值** |
| **DRT（driver reaction time）** | **时间类**（在线估计量） | 由曲线匹配算法从前后车轨迹对中实时反演；**数值、单位、分布、估计误差全部摘要未报告** |
| **activation state of collision warning** | 决策输出 | DQN 的动作输出（是否激活预警）；触发阈值不再显式存在 |
| **driving style（驾驶风格）** | 个体差异分组 | 用于验证「对不同驾驶风格实现自适应预警」；**风格类别数与划分标准摘要未报告** |

## 四、主要结果与发现（摘要原文层面）

1. **RL-AFCWS 把准确率提升至 94%（accuracy rate ... to 94%）**，把**真正率提升至 49%（true positive rate ... to 49%）**——两者均相对于 **TTC 经典模型与自适应模型**而言。
2. 同时**大幅减少报警干扰（greatly reducing the alarm interference）**。**减少幅度无数值。**
3. **实现了对不同驾驶风格驾驶员的自适应预警（adaptive early warning for drivers with different driving styles）**。
4. **曲线匹配算法可从前后车轨迹对中实时获得 DRT**——这是本文方法学上最关键的声明。

> 摘要未报告：两基线各自的准确率与真正率（因此 94% 与 49% 的**提升幅度不可计算**）、误报率（FPR）、DRT 估计值与误差、DQN 奖励函数、报警提前量、任何统计检验。

## 五、对 AR-HUD 行人预警时空设计的启示

### 5.1 时间参数（本课题核心）

#### 5.1.0 对「自适应/动态预警阈值」的贡献（本课题四篇动态阈值证据之一）

**本篇在四篇动态阈值文献（idx 73 / 91 / 95 / 101）中的角色：提供「把驾驶员反应时作为实时输入变量」的方法学范式，是四篇中唯一让阈值「被学出来」而非「被设定」的一篇。**

| 维度 | 本篇（Sun et al., 2023）的贡献 |
|---|---|
| **论点第一句：固定 TTC 阈值不足** | 本篇的对照基线之一即「**TTC-based classical model**」，且摘要明确报告 RL-AFCWS 在准确率、真正率、报警干扰三方面**同时优于**它。**这是「固定 TTC 阈值不是最优」在真实轨迹数据（NGSIM）上的直接对照证据。** 摘要把三类模型分层为「TTC 经典模型 → 自适应模型 → RL-AFCWS」，这一分层本身即表明工程界已把固定阈值视作待超越的起点。 |
| **论点第二句：须按驾驶员状态标定** | 本篇把 **DRT（driver reaction time）作为 DQN 的输入变量**，并明确声明实现了「对不同驾驶风格的自适应预警」。即：**同一运动学情境下，反应慢的驾驶员会更早收到预警，反应快的驾驶员会更晚收到预警。** 这是「按驾驶员标定阈值」最直接的功能实现。**注意其个体差异构念是「风格（跨时段稳定的特质）」而非 idx 73 的「状态（随时波动的情境量）」。** |
| **论点第三句：须按运动学标定** | DQN 的输入同时包含**轨迹数据**（纵向相对位置与速度序列），故其策略同时是运动学状态的函数。 |
| **方法学上的独特贡献（四篇中唯一）** | idx 95 与 idx 101 是「人先定阈值形式、再标定参数」，idx 73 是「监督式预测 + 规则化动态阈值」；**本篇则放弃预设阈值形式，让 DQN 从数据中学出「何时该报警」这一策略**。这在概念上把「阈值」从**参数**变成了**策略（policy）**。**理论含义：若最优预警时机本质上是一个策略而非一个常数，则本课题实验的目标就不应是「找到最优秒数」，而应是「找到最优的时机—条件映射函数」。** 这与 `优化方案` §2.3 把「TTC ≤ θ_t」改写为「BTN ≥ θ_B」是同一方向的两种实现：BTN 是人工设计的归一化量（可解释、可写入规范），DQN 策略是学习得到的隐式归一化（不可解释、难以标准化测试）。**本课题宜采用 BTN 路线，并引本篇作为「学习式路线亦可行」的旁证。** |
| **DRT 的低成本获取路径（本篇最实用的启示）** | 曲线匹配算法**仅需前后车轨迹即可估计 DRT，不需要 DMS／眼动／生理传感器**。**工程含义：AR-HUD 系统若要实现自适应时机，可先用「本车相对前车的轨迹滞后」这一免费信号估计当前驾驶员的反应速度，用个体 DRT 替代 `优化方案` §3.2 下界线公式中的群体 `PRT_p95`，无需增加硬件。** |
| **本篇留下的空隙（与本课题的互补关系）** | 本篇在**算法侧**完成个体化触发，成功判据是分类性能；但**从未在人因实验中检验主观可接受性与信任后果**（无被试、无量表、无实测反应时），也**未回答「个体化后的报警时刻相对该驾驶员自发察觉时刻 $t_0$ 落在哪里」**——DRT 描述的是「察觉之后的处理速度」，$t_0$ 描述的是「何时才会察觉」，两者是串联的不同环节。即使 DRT 估计完全准确，报警仍可能落在 $\Delta t < 0$ 的冗余区间。**本课题在人因侧解决同一问题，两者互补而非重复。** |

**四篇合读的完整论证链（与 `73_2026_Wang_...md` 中同一小节保持一致，此处从本篇视角复述其定位）**：
1. **idx 101（SAE J2400, 2003）**：确立 FCW 人因界面的**静态标准框架**——面向「典型驾驶员」的统一规格，其价值在统一性与可测试性；
2. **idx 95（Miyoshi et al., 2005, SAE）**：标题即宣示「适应驾驶员特性（adapted for driver characteristics）」——**「阈值应因人而异」的早期节点**（该篇摘要未获取，仅为标题级定位）；
3. **本篇 idx 91（Sun et al., 2023）**：用**实时 DRT 估计 + 深度 Q 网络**把设想变成可学习的策略，准确率 **94%**、真正率 **49%**，明确优于 TTC 经典模型与既有自适应模型——**方法学突破**；
4. **idx 73（A-TTC, 2026）**：用 **569 辆卡车、3,519 条视频核验的 FCW 触发事件**证明动态标定可把**事件级骚扰报警占比压到 13.74%**、总体准确率 81.42%、威胁事件召回 89.25%（正式版口径；**未报告固定阈值对照基线**，预印本的 25.16% → 12.21% 已作废）——**规模化验证与收益量化**。
> **结论句（可直接写入论文）：从静态标准（2003）、个性化设想（2005）、可学习策略（2023）到大样本收益量化（2026），四条证据共同表明——单一固定 TTC 阈值既无法覆盖驾驶员反应时的个体与状态差异，也无法覆盖运动学场景的多样性；预警阈值必须按「驾驶员状态 × 车辆运动学能力」动态标定，且这一标定可以是学习得到的策略而非人工设定的常数。**

**本篇在该论证链中的两处必须显式声明的限制**：
- **真正率仅 49%**：意味着真实危险事件中约有一半未被报警。与「准确率 94%」并置可推知数据集极度不平衡（负样本占绝对多数），高准确率主要由「正确地不报警」贡献。**这暴露了纯算法优化的目标函数偏置：为压低报警干扰，模型付出了漏掉约一半危险的代价。从人因角度看这是不可接受的权衡方向**（对照 idx 82 Schall 2013 的 15% 漏报对所有因变量无显著效应，49% 漏检的人因后果完全未知且远超既有实验覆盖范围）。**且摘要未报告基线的真正率，故 49% 的改善幅度不可评估。**
- **学习式方法的根本风险**：若 DQN 从 NGSIM 学习「驾驶员实际何时制动」，则它可能**内在地继承「与驾驶员同步」而非「早于驾驶员」的时机取向**——把「和驾驶员一样晚」当作正确。结合 idx 76（Thammakaroon 2012 实测 FCW 报警晚于真实驾驶员制动 1.47 s）可知：**从人类行为数据中学出的预警时机，其上限就是人类自身的时机，无法产生「优于人类」的提前量。** 这一批判对本课题理论章有价值。

#### 5.1.1 原文摘要明确给出的结论
- **预警时机 / TTC / TTMD / THW 阈值**：**无固定数值**。本文的核心设计恰是**用 DQN 策略替代显式阈值**——「是否报警」由学到的价值函数决定，因此**不存在可摘录的秒数**。TTC 仅作为被超越的基线出现，其基线阈值**摘要未报告**。
- **驾驶员反应时（PRT/BRT）及其分解**：**DRT 被作为一等公民纳入模型输入**，并由曲线匹配算法**实时（in real time）**估计。但 **DRT 的数值范围、均值、SD、个体间变异、是否分解为反射/判断/动作三段——全部摘要未报告**。这与 idx 72（Chen 2013）形成鲜明对照：Chen 给出完整的分龄查表（0.74–1.17 s），本文给出在线估计的方法但不给数。
- **预警提前期（lead time）、TOR lead time**：**摘要未报告**。
- **预警持续时长、闪烁频率、占空比**：**摘要未报告**（无 HMI 层）。
- **报警延迟（warning lag）、系统时延**：**摘要未报告**（曲线匹配 + DQN 推理的计算耗时未讨论，而这在「实时」声明下本应报告）。
- **TTC 计算公式与参数**：**摘要未报告**。
- **减速度阈值 / BTN / DCA**：**摘要未报告**（本文未见运动学减速度判据，与 idx 99 的 DCA 路线不同——本文走的是「学习型策略」而非「运动学归一化」）。
- **分心条件下的反应时增量**：**摘要未报告**。本文以「驾驶风格（driving styles）」而非「驾驶状态（分心/正常）」作为个体差异维度，这与 idx 73（A-TTC 检测 distracted / harsh 状态）在**个体差异的构念上不同**：风格是**跨时段稳定的特质**，状态是**随时波动的情境量**。
- **分级时序（级数、级间间隔）**：**摘要未报告**（DQN 输出为二元激活状态，未见分级）。

#### 5.1.2 基于摘要的推断（待全文核验）
- **本批 4 篇论证线在本篇的落点**：本篇是「按驾驶员个体反应时动态标定触发时机」这一替代方案的**最直接的方法学原型**——它证明了「实时估计个体 DRT 并据此改变触发决策」在**技术上可行且能改善分类性能（94%）与减少报警干扰**。固定阈值 FCW（TTC 经典模型）在本文中被明确作为**被超越的对照**。
- **算法侧 vs 人因侧的互补（本篇最关键的论证）**：本文在**算法侧**完成了「个体化触发」，其成功判据是**分类性能与报警干扰**。但——
  - **它从未在人因实验中检验过其主观可接受性与信任后果**。摘要中不存在任何被试、任何主观量表、任何反应时实测。「报警干扰大幅减少」是**算法指标推论**，不是驾驶员报告的结果；
  - **它也未回答「个体化后的报警时刻相对该驾驶员自发察觉时刻 $t_0$ 落在哪里」**。DRT 描述的是「察觉之后的处理速度」，而 $t_0$ 描述的是「何时才会察觉」。两者是**串联的不同环节**：DRT 是 $t_0$ 之后的加工耗时，$t_0$ 之前的时段则完全在 DRT 框架之外。因此即使 DRT 估计完全准确，报警仍可能落在 $\Delta t < 0$ 的冗余区间；
  - 本课题在**人因侧**解决同一问题：以 $\Delta t = t_0 - t_{warn}$ 为核心自变量，测量个体化触发的**信息增益、SPIDER 阶段覆盖与主观代价**。**这正是本篇留下的空隙，两者互补而非重复。**
- **真正率 49% 必须显式指出为局限（推断性解读）**：49% 意味着**在真实危险事件中约有一半未被报警**。若把这一数字与「准确率 94%」并置，可推知数据集**极度不平衡**（负样本占绝对多数），因此高准确率主要由「正确地不报警」贡献。**这一组合恰恰暴露了纯算法优化的目标函数偏置：为了压低报警干扰，模型付出了漏掉约一半危险的代价。** 从人因角度看，这是不可接受的权衡方向——对照 idx 82（Schall 2013）的 15% 漏报对所有因变量无显著效应，49% 漏检的人因后果完全未知且远超既有实验覆盖范围。
- **推断（非原文）**：「曲线匹配前后车轨迹以反演 DRT」的思路可迁移为本课题实验 0 的**无侵入 $t_0$ 估计法**的补充手段：在模拟器中除眼动之外，也可用「油门/制动踏板轨迹的曲线匹配」交叉验证首次反应时刻。此为方法学借用，非原文结论。

### 5.2 空间参数
- **呈现位置 / 空间参照系（屏幕固定 vs 世界锁定 vs 目标锁定）、视场角 FOV 与偏心度、图形形态、颜色、透明度、动效、尺寸、遮挡关系**：**均不适用 / 论文未明确报告**——本文止于「是否激活预警」这一布尔输出，**完全不含呈现层设计**。
- **场景限定**：**NGSIM 高速公路/城市干道的车—车纵向跟驰**；**不涉及行人、不涉及横向冲突**。因此其空间参数对本课题的行人横穿场景**无直接可迁移量**。
- 唯一间接相关的空间信息：模型输入为**前后车对的轨迹**，即依赖**纵向相对位置与速度序列**；这提示若要把同一范式移植到行人场景，需替换为**行人—车辆的二维相对轨迹**，而这正是 idx 93 所处理的问题（见该篇）。

- **可用于章节**：

  - 第 1 章「研究缺口」中「个体化触发已在算法侧实现，但人因侧从未检验」这一空隙陈述的**直接依据**；

- **与已收录文献的一致之处**：
  - **与 idx 73（A-TTC 2026）高度一致**：两者是同一命题的两个独立实现——都以「固定阈值 FCW 不足」为出发点，都把**驾驶员反应时**作为动态标定的核心输入，都声称在减少骚扰报警的同时不牺牲检出。**两篇合在一起构成本课题「固定阈值已被工程界判定为不足」这一论断的双重支撑**：idx 73 提供自然驾驶实测的骚扰报警证据（正式版：动态标定后事件级骚扰报警占比 13.74%，威胁事件召回 89.25%；**正式版未报告固定阈值对照基线**，其预印本的「25.16% → 12.21%」已作废，见 `summaries/73_*.md` §8），本篇提供个体反应时在线估计的方法学证据（94% / 49%）。二者的差别在于个体差异构念：idx 73 用**状态**（distracted / harsh），本篇用**风格**（driving styles）。
  - **与 idx 99（Takada 2014）一致**：都反对裸 TTC 固定阈值。但路线不同——Takada 走**运动学归一化（DCA：报警 4.0 m/s²、解除 2.0 m/s²，反应时假设 1.2 s / 0.2 s）**，本篇走**数据驱动学习**。值得注意的是 Takada 的反应时是**假设常数**，本篇是**在线估计**，这是十年间的方法学跃迁。
  - **与 idx 72（Chen 2013）一致**：Chen 已把反应时纳入安全制动距离计算，但用的是**按年龄查表的静态值（0.74–1.17 s）**；本篇把同一变量升级为在线估计量。可写成「反应时从手册常数 → 分龄查表 → 在线个体估计」的三阶段脉络（idx 72 → idx 91 → idx 73）。
- **与已收录文献的冲突之处（必须显式指出）**：
  1. **与 idx 74（Abe & Richardson 2006）根本冲突**：Abe 的核心发现是**报警时机的判定基准是驾驶员自己的动作时点**——只要报警晚于驾驶员自发松油门的时刻（实测均值 **0.72 s**），就被判为「晚报警」，信任从 **7.3 跌至 4.3**（F(1,115)=118.32），且 alarm time 与信任的相关达 **R = −0.46**。本篇的优化目标函数中**完全没有信任项**，也没有「相对于驾驶员自发动作」的时间基准。**因此本篇 94% 准确率所对应的报警时机，完全可能落在 Abe 所定义的「晚报警」区间而系统不自知。** 这是算法侧与人因侧目标函数错位的典型案例，须在论文中显式点出。
  2. **与 idx 82（Schall 2013）在漏报容忍度上冲突**：Schall 实验操纵的漏报率为 **15%**，并发现对所有因变量无显著效应；本篇的漏报率隐含为 **51%（1 − 49%）**，远超 Schall 覆盖的范围。**Schall 的「漏报无害」结论绝不可外推到本篇的漏报水平**，而本篇也未提供任何人因证据说明 51% 漏报可接受。
  3. **与 idx 78（Large 2019）冲突**：Large 证明主观接受度与误报率**非单调**（误报率最低的 W1/TTC 2.0 s 六项主观指标全部最差；误报率 80% 的 TTC 5.0 s 仍获正向接受度）。本篇把「减少报警干扰」当作单向的好事，**这一价值判断在 Large 的数据面前并不成立**——干扰的减少若以延后报警为代价，主观评价可能反而恶化。
  4. **与 idx 76（Thammakaroon 2012）的隐含张力**：Thammakaroon 的多功能预警准确率为 **79.54% / 79.01%**，本篇为 **94%**；但 Thammakaroon 同时实测出 FCW 报警比真实驾驶员制动**晚 1.47 s**。**准确率的提升完全无法保证报警不比驾驶员更慢**——本篇未报告任何相对时序，这一维度在其评价体系中缺失。
