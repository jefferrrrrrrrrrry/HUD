## 一、研究背景与问题

### 1.1 领域现状
摘要立论句为：**驾驶是一种复杂的多感官体验（complex multisensory experience），需整合多种感觉输入以维持有效的情境意识（situational awareness），其中视觉与视觉注意是安全驾驶的首要（paramount）因素。** 由此确立两个层次：SA 是安全的状态变量，视觉注意是维持 SA 的首要通道。

### 1.2 研究缺口
本篇为受邀综述，不设传统「缺口」段。摘要隐含的缺口是：**SPIDER 框架自 2016 年提出后，视觉分心（visual distraction）这一子类的证据大幅积累，需要一次以视觉通道为焦点的框架更新**——摘要明确本次更新「with a focus on visual distraction」。

### 1.3 核心研究问题
本篇的核心命题可概括为：**驾驶员 SA 由五个视觉注意驱动的加工阶段共同支撑，多任务通过损害其中一个或多个阶段降低 SA，最终抬高碰撞风险；且视觉分心对五阶段的损害模式各不相同。** 摘要给出本篇的三项工作：① 论述视觉注意在 SA 中的核心作用；② 考察评估驾驶中视觉注意的常用方法；③ 呈现聚焦视觉分心的 SPIDER 模型更新版综述。

## 四、主要结果与发现（摘要原文层面）

1. **视觉与视觉注意对安全驾驶是首要的（paramount）**，是维持有效 SA 的核心通道。
2. **多任务降低 SA**，使驾驶员忽略或误判环境中的重要方面——摘要明确举出三类对象：**行人（pedestrians）、道路标志、其他车辆；行人被列为第一位**。
3. **多任务损害视觉扫视危险的能力**，并损害对关键信息的加工，**降低注意到并响应道路变化的能力**。
4. **多任务可诱发无意视盲**，使驾驶员漏掉**直接位于视线之内**的重要信息（即 looked-but-failed-to-see）。
5. **除注意削弱之外，多任务还独立地减慢对「已探测」事件的反应时**，从而增加碰撞的可能性与严重程度。措辞中的限定词 **detected** 极为关键：它把「探测失败」与「探测后反应减慢」界定为两类可分离的损害。
6. **SPIDER 五阶段（摘要原文括注）**：**scanning、predicting、identification、decision-making、executing a response**。注意摘要用的是混合词形，而本课题惯用动名词形（Scanning–Predicting–Identifying–Deciding–Executing）；引用时应以原文措辞为准或显式说明统一化处理。
7. **本次更新（2.0）聚焦视觉分心。**

**逐阶段的可测时间量说明**（阶段名称来自摘要，指标选择与耗时归属为本课题的构建性阐释）：

- **Scanning**：这是唯一一个**在信息被感知之前**就可能失败的阶段，也是唯一可能以「截尾」形式结束的阶段——若发生 IB，TTFF 不存在而非「很长」。**因此 TTFF 必须与 IB 率成对报告，否则均值会被系统性低估**（只有成功试次才进入均值）。摘要第 4 条「IB 可发生于视线之内」进一步说明 Scanning 的失败包含两种：没往那儿看（普通盲视）与看了但未采样到（注意与眼动解耦）。
- **Predicting**：这是**唯一一个可以由机器代替驾驶员完成的阶段**——预警算法的 TTC/DCA 计算本身就是一次外部化的 Predicting。这解释了为何 idx 82 的提示可以提前 11–13 s 仍然有效（机器把 Predicting 的产出提前交付），而 idx 74 的报警只要晚于 0.72 s 就失去价值（此时驾驶员自己已完成 Predicting，报警变成冗余）。**同一预警的最优提前量取决于它替代的是哪个阶段。**
- **Identification**：本阶段的耗时在本课题中可用「定位转换成本 = TTFF(真实行人) − TTFF(警告图形)」操作化，其量级参照是 idx 69 的 TDT 最优区间 500–2000 ms 与 idx 72 的判断分量 0.15–0.25 s。**注意两者相差近一个数量级**：TDT 是注视停留（含语义确认），判断分量是工程学模型中的假定值，二者不可互换。
- **Decision-making**：本阶段是**信任与依从的作用位点**。idx 74 的三组数值（correct 0.51 s / late 0.77 s / 无报警自主松油门 0.72 s）实际是在刻画本阶段的时间边界：报警若落在驾驶员自身决策完成之后，就不再进入本阶段而只起事后确认作用，信任随之从 7.3 跌至 4.3。
- **Executing a Response**：本阶段的耗时受生物力学约束，**最不可能被显示设计压缩**。idx 72 的动作分量 0.15–0.40 s 与制动压力建立 t_p = 0.3–0.75 s 是硬下限。**由此可导出一条重要的否证性预测：若某个预警方案带来的改善量小于本阶段的硬下限差异，则该改善不可能来自 Executing 阶段，必然来自前四阶段。** idx 77 的 200 ms 与 idx 62 的 370 ms（1.4 → 1.03 s）都超过这个量级，说明它们压缩的主要是 Scanning。

**B. 基于摘要的推断（非原文结论）**
1. **五阶段耗时是否可加，摘要未说明。** 本课题若要用「S+I 耗时之和」推导最小有效提前量 Δt，必须先核验 SPIDER 是否主张严格串行。若阶段可并行或交叠，则加法假设失效，须改用「阶段完成的必要条件」这类更弱表述。**这是本篇最紧要的待核验项。**
2. **Predicting 置于 Identification 之前**，与「先识别目标再外推轨迹」的直觉相反。**推断存在两种解释**：（a）预期性注意——基于场景先验预测危险将出现之处（则其代理指标应为预期性注视比例）；（b）轨迹外推——对已识别目标的路径侵入判断（则代理指标为路径侵入预测正确率、冲突点误差）。**两种解释导出完全不同的指标，须全文核验。**
3. **多任务独立减慢「已探测」事件的反应时** ⇒ 推断分心条件下的预警提前量必须留出反应时冗余。冗余量本篇无法提供，须由 idx 62（1.4 → 1.03 s）、idx 72（总时延 1.04–1.92 s）等实测文献给出。
4. **AR-HUD 在本框架下具有双重身份**：既通过空间线索缩短 Scanning 与 Identification（收益），又作为额外视觉信息源占用扫视资源、诱发 IB（代价）。**净效应 = 收益 − 代价，且两者作用于同一阶段，故必须用阶段分解指标分离。** 摘要通篇把额外视觉负荷视为损害源，**未提及 HUD/AR**，该转换需本课题自行承担论证责任。
5. **推断：本篇「探测失败」与「反应减慢」的二分，为本课题「提前量与持续时长不可混淆」提供了理论落点。** 提前量（lead time）决定的是「五阶段是否有足够时间完成」，属**时间预算**问题；持续时长决定的是「信号在 Scanning 阶段的可获得窗口」，属**信息可用性**问题。两者作用于不同阶段，因此**不能用同一条「越长越好/越早越好」的单调曲线描述**。摘要未直接论述这一点，但其阶段可分性主张是该论点的必要前提。
6. **推断：五阶段可作为「预警失效归因」的诊断树。** 若某预警方案未能降低碰撞率，可依次排查：IB 率是否未降（Scanning 失败）→ 定位转换成本是否未降（Identification 失败）→ 松油门时点是否未提前（Decision-making 失败）→ 峰值减速度是否反而上升（仅压缩了 Executing）。**本课题可据此把「无显著效应」这类零结果转化为可解释的机制结论**，这是阶段分解最实用的方法学收益。

### 5.3 可直接写入设计规范的条目
1. **若**要评估 AR-HUD 行人预警的效果，**则**必须按加工阶段分解评估、不得只用单一总体反应时——本篇明确损害同时体现在「探测能力下降」与「对已探测事件的反应减慢」两个可分离方面（出处：摘要 Results 第 2–5 条）。
2. **若**预警图形已置于驾驶员视线中央，**则**仍不得假定其必被感知，须强制报告 IB／漏检率——本篇明确 IB 可发生于视线之内（出处：摘要第 4 条）。
3. **若**驾驶员处于多任务/分心状态，**则**预警提前量须预留反应时冗余；**冗余量本篇不提供**，须引 idx 62、idx 72 的实测值（出处：摘要第 5 条 + 本课题据 idx 62/72 推断）。
4. **若**需论证「行人是分心驾驶下最易被忽略的对象」，**则**可直接引用本篇：多任务导致忽略或误判环境要素，**并以行人为首例**（出处：摘要第 2 条）。
5. **若**要建立跨实验可比的指标体系，**则**按 scanning / predicting / identification / decision-making / executing a response 五阶段组织，使各实验共享同一机制坐标（出处：摘要第 6 条）。
6. **（禁止条目）**不得写入任何 SPIDER 阶段耗时数值、任何分心导致的反应时延长毫秒数、任何「本篇支持某 TTC 阈值」的表述——**摘要全部未提供**；亦不得假定五阶段严格串行、耗时可加。

- **可用于章节**：论文第二章「注意与分心的理论骨架」新增一节（SPIDER 五阶段与代理指标映射）；第三章「核心理论模型」作为「认知加工窗口」的中线；第五章统一指标体系的组织依据（五阶段 + 安全终点 + 代价终点）。**四个实验的因变量按同一五阶段组织，才使跨实验比较有意义。**
- **与已收录文献的一致之处**：
  - 与 **idx 62（Winkler 2018）** 一致且互补：本篇给机制（分心减慢已探测事件的反应），62 给数值（BRT 对照 1.4 s → 预警 1.03–1.05 s；T1→T2 学习效应 1.20 → 1.04 s）。62 的「LI 场景 50% 被试在预警前已制动」在本框架下正是「Scanning/Predicting 未失败时预警的边际价值为零」的直接例证。
  - 与 **idx 69（Zhu 2025）** 一致：69 给出 TTFF 最优 100–300 ms、TDT 最优 500–2000 ms，恰好分别落在 Scanning 与 Identification 两阶段，**为本篇的阶段划分提供了可分辨的量化门槛**，也否证了「注视越少越好」的单调假设。
  - 与 **idx 77（Lind 2007）** 一致：CWHUD 比方向盘/仪表/HHDD 快约 200 ms（F(3,45)=10.8, p<0.0001），即「把信号放进前视野」主要压缩的是 Scanning 阶段——这是本篇「视觉注意是首要通道」的量化版本。
  - 与 **idx 74（Abe & Richardson 2006）** 一致：74 的「报警必须早于驾驶员自身首次响应（实测参照 0.72 s）」在本框架下是对 Decision-making 阶段边界的经验刻度；且 74 发现「报警及时性对信任的影响大于制动绩效改善」，说明 Decision-making 阶段有独立于 Executing 阶段的评价维度。
  - 与 **idx 72（Chen 2013）** 一致：72 把驾驶员时延分解为反射 0.44–0.52 + 判断 0.15–0.25 + 动作 0.15–0.40 = 0.74–1.17 s，**这是本库中唯一与 SPIDER 后三阶段可直接对齐的耗时分解**，可作为「阶段可分」的工程学旁证。
- **与已收录文献的冲突之处（必须显式指出）**：
  1. **与 idx 82（Schall 2013）的张力**：82 报告 15% 误报 + 15% 漏报对所有因变量均无显著效应，且提示提前 11–13 s 仍有效；而本篇框架下，超长提前量意味着 Predicting 阶段的信息在 Scanning 完成时已失效（危险尚未进入视野）。**边界条件**：82 的任务是老年驾驶员的危险感知（提示的是「往哪儿看」而非「现在制动」），属 Scanning 阶段的注意引导；而 idx 74/78 的报警是 Decision-making/Executing 阶段的动作触发。**同一「提前量」在不同阶段的最优值差两个数量级（11–13 s vs 1–4 s），这正是必须做阶段分解的最强论据，而非文献间的真实矛盾。**
  2. **与 idx 76（Thammakaroon 2012）的冲突边界**：76 实测 FCW 报警晚于真实制动 +1.47 s（FCW+LW +1.32 s），即报警落在 Executing 阶段之后；本篇框架预测此时预警对前四阶段全部无效，只可能起「事后确认」作用。**76 未测 SA 或注意指标，因此无法在本框架内验证该预测**——这是一处证据缺口而非冲突。
  3. **本篇的「分心 → 损害」立场 vs 本课题的「AR-HUD → 辅助」定位**：这不是文献间冲突，而是本课题必须自行完成的理论转换（5.2B 推断 4）。它恰好解释了本库中同时存在「AR-HUD 有益」（idx 62、77）与「AR 图形诱发 IB」（idx 69 及本库 IB 组）两组看似矛盾的证据。
