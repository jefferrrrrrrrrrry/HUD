# 周报口语化讲稿（Speaker Notes）使用指南

本目录收录 W01–W10 每周汇报的口语化讲稿（speaker notes），用于配合每周 PPT 向导师做 10–12 分钟的口头汇报。

---

## 一、使用场景

本套讲稿专为以下场景设计：

1. **导师周例会**：每周一次的 10–12 分钟口头汇报（含 Q&A）
2. **答辩训练营**：开题答辩前的口语化反复练习
3. **会议预演**：投稿 CHI / AutomotiveUI / HFES 等会议前的 pitch 排演
4. **小组组会**：同门或合作组的进度分享

不适用场景：纯书面文档提交、邮件汇报、需要严格学术语体的写作。

## 三、讲稿结构总览（IMRD 范式）

每份讲稿严格遵循**心理学学术论文汇报 IMRD 范式**的口语化结构：

1. **开场白·明确议程（60 秒，约 160 字）**：**明确本次讲什么** + 4 板块议程预告 + 主打文献选择理由
2. **Part 1：证据聚合 / 检索背景**（约 2 分钟）——多篇文献的证据分布
3. **Part 2：主打文献 IMRD 完整精读**（约 7-8 分钟）——
   - **2.1 Introduction**：研究背景 + 研究缺口 + 假设
   - **2.2 Method**：被试 + 设计 + 因变量 + 设备
   - **2.3 Results**：**因变量分层解读**（救命层 / 认知层 / 力学层 或 感知/警觉/预期 三层）+ 实际意义分析
   - **2.4 Discussion**：作者自陈局限 + 对本研究的 3 个具体启示
4. **Part 3 / Part 4：跨文献综合 + 本周共识**（约 2-3 分钟）——多篇对比 + 5 条共识
5. **结束语·本周共识（60 秒，约 250 字）**——**每周 5 条核心共识**
6. **Q&A 预答（5 个）**：每个 120-200 字预答
7. **关键数字记忆卡**：10-20 个易混淆数字与人名
8. **汇报时的注意事项**：语速、重点强调位、口误风险、应急策略

## 四、推荐使用流程

### 阶段 1：预演前 24 小时

1. **通读主文档**：先快速过一遍对应的 `W0X_xxx.md` 主文档，对内容有整体印象
2. **精读讲稿**：逐句通读对应的 `W0X_speaker.md`，标注个人不熟悉的术语
3. **背诵关键数字**：用记忆卡里的表格做闪卡式记忆（建议覆盖至 80% 准确率）

### 阶段 2：预演前 2 小时

1. **对照念读 2 遍**：开第一遍熟悉发音、第二遍计时（控制在 10–12 分钟内）
2. **预演 Q&A**：让同门或室友抽问 3–5 个 Q，照预答回答
3. **检查 PPT 同步**：确认讲稿每个 Part 对应的 PPT 页码

### 阶段 3：汇报现场

1. **不要看着稿子读**：稿子放在面前但目光以 80% 时间看老师与 PPT、20% 扫稿
2. **重点强调位放慢加重音**：见每份讲稿"六、汇报时的注意事项"中的列表
3. **遇到打断按 Q&A 应答**：答完后请示"是否继续 Part X" 再继续主线

## 五、汇报技巧通用建议

### 5.1 语速控制

- **理论密度高的周**（W02、W03、W09）：建议每分钟 200 字以下
- **数据密集的周**（W05、W06）：建议每分钟 200–220 字
- **综合对比的周**（W07、W10）：建议每分钟 220 字
- **检索分布与背景化的周**（W01、W04、W08）：可达 220–240 字

每讲完一个数据停顿 1 秒，让数字落地。

### 5.2 五条"千万不要"

1. **不要看着稿子从头到尾念**——这会让老师觉得你没掌握内容
2. **不要忽略 Q&A 预答**——导师常问的问题 70% 已在预答里覆盖
3. **不要把数据全部背出来**——只背关键数字（记忆卡里的 5–10 个），其他可临时翻 PPT
4. **不要回避不确定**——遇到不会的问题坦诚说"这个我需要回去再核查"，不要硬撑
5. **不要超时**——10–12 分钟是黄金区间，超过 15 分钟老师会失去耐心

### 5.3 答疑时段策略

- **导师打断式提问**：暂停主线，听完问题后用预答里的内容回应（不要急着继续主线）
- **导师建议性提问**："你考虑过 X 吗？"——先说"老师这是一个非常好的角度"，再说明已考虑/未考虑的现状
- **导师挑战性提问**："你的推论太绝对了吧？"——立即承认表述边界，"准确的说法应该是 ……"
- **导师扩展性提问**："如果换成 Y 怎么办？"——给出 1 个备选方案 + 说明取舍

### 5.4 信任建立技巧

- **首句锁定关注点**：开场白里就告诉老师本周最关键的发现是什么
- **引用具体数字**：而不是"反应时缩短了"，要说"反应时从 1707 毫秒缩短到 1083 毫秒，缩短 36%"
- **承认局限性**：每讲完一个发现，主动指出"但有一个 confound 需要警惕"——这比老师指出来效果好得多
- **结束语的请教措辞**：用"这部分是否合适请老师判断"而不是"以上是我的工作汇报完毕"

## 七、常见问题 FAQ

**Q：讲稿可以直接用作论文的写作素材吗？**
A：不能。讲稿是口语化的，直接用作书面论文会显得不专业。但 Q&A 部分的预答内容可以转化为论文的 Discussion 段落，特别是对自己研究局限性的反思部分。

**Q：如果老师 5 分钟后让我跳过，怎么办？**
A：直接跳到对应讲稿的"结束语"部分，30 秒结束。如果还有时间，可以拣 Part 3 或最后一部分的"下周计划"快速带过。

**Q：导师可能问我没准备的问题怎么办？**
A：坦诚回答"老师这个问题我没有充分准备，下周补做"，然后立即在汇报后跟进。千万不要现场编造数据或论断。

**Q：讲稿里的中文人名（如"边扬"）我读不准怎么办？**
A：每份讲稿的"六、汇报时的注意事项"中"切勿口误"已列出主要人名读音。汇报前可对照 W0X 主文档的英文原文确认。

**Q：我能修改讲稿吗？**
A：可以，但建议保留 6 段结构。修改时注意保持口语化措辞，避免引入书面用语。
