# summaries/ 文件撰写规范（供批量补写使用）

## 0. 硬性要求

1. **语言**：正文全部中文；论文标题、术语、变量名保留英文原文。
2. **禁止编造**：凡摘要／全文未提供的信息，必须写「摘要未报告」或「论文未明确报告」。**绝不允许**凭常识填数值、样本量、统计量。
3. **仅摘要来源者必须显式标注**：表头「资料来源」写 `**仅摘要（来源：Crossref / OpenAlex / Semantic Scholar）**`，并在表格后加一行引用块说明「本篇未获得 PDF 与全文，以下各节仅依据摘要重构」。
4. **推断与原文结论必须分离**：第五节内区分「A. 原文（摘要）明确结论」与「B. 基于摘要的推断（非原文结论）」。
5. 文件名格式：`summaries/<idx>_<year>_<第一作者姓氏或中文姓名>_<中文短标题>.md`，例如 `58_2025_Strayer_SPIDER2.0驾驶分心与视觉注意.md`。
6. 元数据（作者、年份、期刊、DOI、引用数、本地 PDF/全文路径）一律从 `/home/gezhuocheng/HUD/papers_metadata.json` 中该 idx 条目读取，不要另行猜测。

## 2. 交叉引用可用的既有关键数值（用于第七节比对，不要改写这些数值）

- idx 02（Phan 2016）：无 AR 时行人觉察时刻约 TTC 3 s，AR 提示提前至约 4.5 s；触发 TTC 2.0 s + 16.6 m。

- idx 62（Winkler 2018）：无 TTC 阈值，用路标触发；BRT 对照 1.4 s → 预警 1.03–1.05 s；LI 场景 50% 被试在预警前已制动；T1→T2 学习效应 1.20 → 1.04 s；RT 清洗界 0.2–2.9 s。
- idx 69（Zhu 2025）：TDT 最优 500–2000 ms；TTFF 最优 100–300 ms。
- idx 70（Kang 2016，仅摘要）：TTC 2.0 vs 4.0 s，4.0 s 更优。
- idx 71（Zhang 2015）：7 档 2.5–5.5 s；2.5 s 无效（碰撞率 29.4%）；有效下限 3.0 s；推荐 3.0–4.0 s；无预警基线距冲突点 1.5 s 才猛制动、碰撞率 44.1%；最大减速距离 SD 40.75 → 15.97 m。
- idx 72（Chen 2013）：临界 T_c = 1.5 s；反射 0.44–0.52 + 判断 0.15–0.25 + 动作 0.15–0.40 = 0.74–1.17 s；制动压力建立 t_p = 0.3–0.75 s；总时延 1.04–1.92 s。
- idx 74（Abe & Richardson 2006）：无报警自主松油门基线 0.72 s；correct 组 0.51 s vs late 组 0.77 s；信任 7.3 → 4.3（F(1,115)=118.32）；alarm time 与信任 R = −0.46；早报警 BRT 1.20 → 0.93 s；晚报警 0.95 → 1.07 s；听觉报警 2.0 s / 4000 Hz；SDA 参数 RT=1.25 s、D_l=0.5 g、D_f=0.45 g（早）/0.60 g（晚）。
- idx 76（Thammakaroon 2012）：FCW 报警晚于真实制动 +1.47 s；FCW+LW +1.32 s；跟车判据 2.0 → 1.6 s；L3 临界为碰撞前 2–3 s。
