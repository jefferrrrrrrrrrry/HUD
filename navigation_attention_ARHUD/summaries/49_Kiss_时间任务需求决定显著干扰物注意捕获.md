## 一、背景与问题

显著但与任务无关的视觉刺激究竟是被自下而上（bottom-up）自动捕获注意，还是受自上而下（top-down）的任务设置调控？这是注意研究中长期未决的争论（Theeuwes, 2010; Folk et al., 1992）。"附加单子（additional singleton）"范式（显示持续到反应）支持自下而上捕获，而空间线索范式（显示时间极短）支持自上而下控制。Kiss 等 (2011) 提出：两类范式结论分歧的关键可能在于"时间任务需求"——当显示时间极短时，被显著干扰物捕获注意将严重影响目标加工，因此个体会启动主动抑制。

## 二、方法

采用附加单子范式 + ERP 测量。参与者搜索形状单子靶（圆 vs 菱形），报告靶内线段方向。25% 试次无靶。一半区组含红/绿色 singleton 干扰物（与任务无关），出现在 6 个位置之一。

- **实验 1**：搜索阵列持续至按键（最长 2500 ms），N = 12（剔除后）。
- **实验 2**：搜索阵列仅呈现 200 ms，N = 12。

EEG 记录 23 导，分析 PO7/PO8 在 220–300 ms（N2pc 窗）与 300–340 ms（Pd 窗）的对侧化电位。

## 三、关键指标

- 行为：反应时（RT）、错误率，按"靶/干扰物同侧/对侧"分别计算。
- ERP：N2pc（对侧负成分，注意选择标记）、Pd（对侧正成分，主动抑制标记）。

## 四、主要结果

**实验 1（长显示）**：干扰物存在使 RT 延长 81 ms（993 vs 912 ms, *t*(11) = 6.7, *p* < .001）；侧位干扰物诱发显著 N2pc（*F*(1,11) = 5.4, *p* < .05），随后在 300–340 ms 出现晚 Pd——证据指向先被捕获，再被抑制。

**实验 2（200 ms 短显示）**：RT 干扰效应减小至 49 ms，显著小于实验 1（*F*(1,22) = 4.7, *p* < .05）。关键地，**侧位干扰物不再诱发 N2pc**；相反，在 N2pc 时窗（220–300 ms）直接出现 Pd（*F*(1,11) = 11.6, *p* < .01），表明捕获被快速、主动抑制。

跨实验交互检验确认：显示时长 × 对侧化对干扰物 ERP 的影响显著（*F*(1,22) = 9.4, *p* < .01）。

## 五、对本研究的启示（AR-HUD 导航场景）

1. **三类策略归属判断**：本研究是 **C 信号抑制**机制的关键 ERP 证据，首次以神经生理学方式表明：当任务时间压力高时，显著干扰可被主动抑制（Pd 提前出现），而非必然先发生捕获。
2. **对 AR-HUD 设计的启示**：导航 HUD 图元（如箭头、POI 标）相对于驾驶任务（前方路况）而言是"显著但常常与即时驾驶子任务无关"的刺激。本研究表明，**驾驶员在高时间压力情境（如复杂路口、紧急避让）下，有能力对 HUD 元素进行抑制**——但这种抑制是消耗资源的（认知代价）。
3. **引用价值 ★★★★★**：作为驾驶情境中"HUD 元素是否会被自动捕获"的理论基础引用；论证 AR-HUD 透明度/动态效应不当时，驾驶员在低时间压力下（巡航）易发生捕获/非注意盲视（参 03、04 文献），在高时间压力下虽可抑制，但会牺牲对 HUD 信息的有效解码。

## 六、局限

1. 抽象的视觉搜索任务，生态效度有限；驾驶情境中目标-分心物关系更动态、更连续。
2. 样本量小（N = 12/组），统计效力有限。
3. 仅检验 200 ms vs 持续两种时长，未覆盖中间时长以建立连续函数。
4. 未测量个体差异（如认知控制能力、工作记忆容量）。
