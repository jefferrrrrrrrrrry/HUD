## 第二部分　诊断：为什么「从时间参数入手设核心变量」现在会卡住

以下五点是我读完现有六份文档后判断的根因，按严重程度排序。

### 2.1 症结一：自变量的水平是「别人论文里的数字」，不是「理论量」

实验 1 现在取 5.0 / 3.0 / 2.0 s，来源分别是 Kim 等 (2018) 的 5.0 s 远距对照、Wu 等 (2024) 的 3 s 触发、Lubbe (2017) 的 1.8–2.5 s 临界级。问题在于：

- Kim 等 (2018) 是 **15 mph（24 km/h）停车场实车**，5.0 s ≈ 33.5 m；
- Wu 等 (2024) 是 **60 km/h 全景视频**，3 s ≈ 50 m；
- Lubbe (2017) 是 **moving-base 模拟器 + 心算分心**。

同一个"秒数"在不同车速、不同分心状态下对应完全不同的**运动学难度**和**认知难度**。把三个数字并列成三个水平，实际上操纵的是一个混杂了车速、所需减速度、分心程度的复合量。这会导致两个后果：（a）结论无法外推到别的车速；（b）理论上无法预测效应方向，只能事后解释。

> 现有框架自己也意识到了这点：「区块 B 的 3.0 s 是工程锚点，而不是已证明的最优时机」。但把锚点当水平，问题仍在。

### 2.2 症结二：没有「零点」——预警的价值本应相对于驾驶员自发察觉时刻来度量

现有设计问的是"警告在 TTC 的哪个点出现最合适"。但驾驶员并非在警告出现前对行人一无所知。在 2.0 s 条件下，相当一部分被试可能**已经自己看见了行人**，此时 AR 预警的功能从"告知"退化为"冗余确认"；而在 5.0 s 条件下，预警确实早于自发察觉。

也就是说，5.0 s 与 2.0 s 之间既有"提前量多少"的量的差异，也可能有"是否早于自发察觉"的**质的差异**。两者混在一起，效应就无法归因。

Phan 等 (2016) 的结果恰好印证这一点：AR cues 把行人**觉察时刻**从 TTC = 3 s 推早到 4.5 s。这说明自发察觉时刻 t₀ 是一个可测量、且被 AR 显著改变的量——它应当是**测量对象与校准基准**，而不是被忽略的背景。

### 2.3 症结三：风险指标（TTC/TTMD）与触发准则（固定时间阈值）没有分开

现有文档已经细致区分了 TTC 与 TTMD 的几何适用性，这很好。但**触发准则仍是"某个时间量跨过固定阈值"**。运动学上决定"还能不能避开"的量是**所需减速度**：

$$a_{req} = \frac{v_{ego}^2}{2 d_{conflict}}\quad\text{（纵向近似）},\qquad BTN = \frac{a_{req}}{a_{max}}$$

在 40 km/h 与 60 km/h 下，同一个 TTC = 3 s 对应的 $a_{req}$ 相差 1.5 倍。因此现有设计里把车速当"平衡呈现的控制变量"，实际上是让自变量在两个车速档之间**改变了物理含义**。

Takada 等 (2014) 的 DCA 与 Coelingh 等 (2010) 的工程实现都指向同一个方向：现代 FCW/AEB 用的是减速度归一化的威胁数（BTN/STN），而不是裸 TTC。A-TTC (2025) 更进一步证明动态阈值可把误报率减半。

### 2.4 症结四：理论只作背景，没有被用来「生成可否证的定量预测」

PIEV（Hooper, 1936）、Endsley SA、Wickens 多资源理论在综述里出现了，但没有从中导出任何数值预测。结果是：实验设计给出的"预期模式"停留在方向性猜测（"3 s 预计较优"），一旦数据不符，只能补充解释。

一个从理论出发的设计应该能写出这样的语句：*若相对提前量 Δt 小于 SPIDER 五阶段耗时之和（估计 0.9–1.2 s + 制动执行时间），则分层预警不会带来额外收益，因为 L1 与 L2 落在同一个加工阶段内。* 这是可以被数据直接推翻的。

### 2.5 症结五：时间参数与「系统可靠性/驾驶员信任」被解耦

预警时刻越早，行人是否真的会横穿这件事就越不确定——意图预测模型的精度是**时间的函数**（P2CWS 的 1.5 s 未来窗；Cangut & Alver 的 85%）。越早预警 ⇒ 正预测值下降 ⇒ 虚警率上升 ⇒ 信任与依从下降（Abe & Richardson, 2006；报警可靠性与依从率的概率匹配关系见 Bliss et al., 1995，碰撞报警可靠性对驾驶行为的影响见 Bliss & Acton, 2003）。**注：此前引用的「虚警率 > 30% 时信任崩塌」未能溯源，已撤回，见研究框架 §14.9 第 4 条。**

也就是说，**预警时间参数的上界不是由人因决定的，而是由预测可靠性决定的**。现有设计完全没有这条约束线，因此"越早越好"与"太早会习惯化"之间只能靠猜。

## 第三部分　理论重构：时间参数的「三线夹逼 + 一个零点」模型

建议把论文第三章「核心理论模型」从"四阶段风险加工链"升级为下面这个可量化的框架。它的好处是：**每一条线都对应一族可测量的经验参数，且能直接生成自变量的水平**。

### 3.1 模型总览

```
                      时间轴（距冲突点的剩余时间，右侧更紧急）
   ─────────────────────────────────────────────────────────────────▶
   │            │                    │              │            │
  t_pred      t_warn              t₀（自发察觉）   t_LPB       冲突
   │            │                    │              │
   │◀── 上界线 ─▶│                    │              │
   │  可靠性—信任 │                    │              │
   │            │◀── 相对提前量 Δt ──▶│              │
   │            │                    │◀── 下界线 ──▶│
   │            │                    │   运动学必要性 │
   │            │◀───── 中线：SPIDER 加工窗口 ───────▶│
```

- **t_pred**：意图预测在给定精度门限下最早可判定的时刻（由算法性能决定）。
- **t_warn**：预警实际呈现时刻（**设计变量**）。
- **t₀**：无辅助条件下驾驶员自发察觉时刻（**实测基线**）。
- **t_LPB**：最晚制动点（last point to brake，由运动学与 PRT 决定）。

### 3.2 下界线：运动学必要性（Kinematic Necessity Bound）

预警必须早于「驾驶员完成 PRT 之后仍能以可接受减速度避开」的最晚时刻：

$$t_{warn} \;\ge\; PRT_{p95} + \frac{v_{ego}}{a_{comf}} + \delta_{brake}$$

其中 $a_{comf}$ 取舒适减速度（常用 3.5–4.0 m/s²），$\delta_{brake}$ 为制动系统响应延迟（0.1–0.3 s）。

**可用于标定的经验参数（本轮新增文献）**

| 参数 | 数值 | 来源 |
|---|---|---|
| 非分心 PRT 中位数 / p95 | 1.1 s / 1.5 s | Olson & Sivak (1986) |
| 分心 + audio-visual + 触觉脉冲 PRT | 0.8 s (SD 0.29) | Lubbe (2017) |
| 分心 + 无触觉的最长 PRT | > 2.5 s | Lubbe (2017) |
| CWHUD 相对仪表显示的 BRT 增益 | −200 ms | Lind (2007) |
| PCW 组感知反应时 | 0.29 s vs 无预警 0.36 s | Banerjee 等 (2021) |
| FCW 触发时机与紧急制动时长最优区间 | 见 idx 84 摘要节 | Char (2020) 3700 例重建 |
| DCA 触发的反应时缩短效应 | 见 idx 99 | Takada 等 (2014) |

**触发准则的改写**：把"TTC ≤ θ_t"改写为"BTN ≥ θ_B"（$BTN = a_{req}/a_{max}$）。这样 40 km/h 与 60 km/h 下触发时刻自动缩放，车速真正成为控制变量。

### 3.3 上界线：可靠性—信任（Reliability–Trust Bound）

$$t_{warn} \;\le\; t_{pred}\big(\text{PPV} \ge \pi^{*}\big)$$

即预警不得早于"意图预测的正预测值达到可接受门限 π*"的时刻。用信号检测论（Green & Swets, 1966）形式化：把预警阈值 θ 视为判据 β，虚警率 FAR(θ) 与漏报率 MR(θ) 构成 ROC；设计目标不是最大化命中率，而是在**信任约束**下最大化命中率。

**可用于标定的经验参数**

| 参数 | 数值 | 来源 |
|---|---|---|
| 行人意图预测（Social-LSTM） | 精度 85.02%，F1 84.57% | Cangut & Alver (2026) |
| P2CWS 方向识别 / 意图预测 | 89.3% / 91.28%（0.5 s 历史 + 1.5 s 未来窗） | Kim 等 (2020) |
| 动态阈值下的骚扰报警占比 | **13.74%**（事件级），召回 89.25% | A-TTC (2026) |
| 固定阈值的骚扰报警基线 | **正式版未报告**（预印本曾报 25.16%，正式版删除，不可引用） | A-TTC (2026) |
| 虚警率损害信任的临界点 | **未能溯源，不可引用**（此前记作 > 30%，归 Bliss 2003） | 撤回；可用证据为 Bliss et al. (1995) 的概率匹配关系与 Bliss & Acton (2003) |
| 报警时机 × 信任 × 期望的交互 | 见 idx 74 | Abe & Richardson (2006) |

**这条线的设计含义**：如果预警提前到意图尚不可判定的区间，则必然以虚警为代价换取提前量。因此实验中**必须把"系统可靠性"作为一个操纵变量**（如 100% vs 80% 有效预警），否则无法回答"能提前到多早"。

### 3.4 中线：SPIDER 加工窗口（Cognitive Processing Window）

采用 Strayer & McDonnell (2025) 的 SPIDER 2.0 作为主理论骨架，替代仅作背景的 PIEV：

| SPIDER 阶段 | 含义 | 本研究的可测代理指标 | 既有经验耗时 |
|---|---|---|---|
| **S**canning | 扫视、发现有异常 | TTFF(警告图形) | 617 ms（BW 动态跟随，Wu 2024）；1051 ms（分级警告，Chen 2024） |
| **P**redicting | 预测行人是否进入本车路径 | 路径侵入预测正确率、冲突点误差 | 论文未明确报告 |
| **I**dentifying | 在真实场景中确认目标 | 目标验证时间 = TTFF(行人) − TTFF(警告) | 估 300–600 ms |
| **D**eciding | 决定制动/转向 | 首次注视行人 → 松油时间 | 论文未明确报告 |
| **E**xecuting | 执行 | 松油 → 制动启动、峰值减速度、jerk | Lubbe/Banerjee 见上 |

**由此导出的定量预测（可否证）**

- P1：**Δt 的最小有效值** ≈ S + I 阶段耗时之和 ≈ **0.9–1.2 s**。若 Δt < 0.9 s，AR 预警只能压缩 E 阶段，不能改善 D 阶段，因此预期"峰值减速度上升、jerk 上升、但碰撞率不降"。
- P2：**分层预警级间间隔应等于 S + I 耗时**，即 L1 承担 Scanning + Predicting，L2 承担 Deciding + Executing。这给现有 0.7 / 1.0 / 1.5 s 一个理论解释：**1.0 s 是理论中心值（S+I 的点估计），0.7 s 与 1.5 s 分别是"少一个加工阶段"与"多一个加工阶段"的对照**，而不是三个任意枚举值。
- P3：若 Δt 已足够（≥ 2.5 s），分层预警的增益应主要出现在**主观负荷与制动平顺性**上，而非反应时上——因为反应时在长窗口下已不受限。

### 3.5 零点：自发察觉基线（Unaided Detection Baseline）

两条路径确定 t₀：

1. **理论路径（τ / looming）**：驾驶员对碰撞进程的自发察觉依赖光学膨胀率 $\dot\theta$，经典阈值约 0.003 rad/s。对宽 $w \approx 0.5\,\mathrm{m}$ 的横穿行人，可解出可察觉距离与时刻，作为 t₀ 的理论下限。
2. **实测路径（推荐，作为实验 0）**：在同一模拟器中跑无预警基线，用眼动 + 首次减速时刻测每位被试的 t₀ 分布。

**核心自变量随之重定义**：

$$\Delta t \;=\; t_0 - t_{warn}$$

Δt > 0 表示预警早于自发察觉（真正提供了信息增益），Δt ≈ 0 表示同步确认，Δt < 0 表示冗余。这样做的三个好处：

- 跨车速、跨场景可比（因为 t₀ 本身随车速与遮挡变化）；
- 直接消化个体差异（老年/新手 t₀ 更晚 → 同一绝对 TTC 对他们意味着不同 Δt）；
- 使"AR-HUD 的信息增益"成为一个可直接量化的构念，而不是"有 AR vs 无 AR"。

## 第四部分　核心变量的重新定义

### 4.1 实验 1（时间参数）的自变量

| 编号 | 自变量 | 水平 | 理论出处 |
|---|---|---|---|
| IV-A | **相对提前量 Δt** | 3 水平：Δt ≈ 0 s（同步确认）、Δt = +1.0 s（≈ S+I 窗口）、Δt = +2.5 s（充裕窗口） | §3.4 P1/P3；t₀ 由实验 0 标定 |
| IV-B | **触发准则类型** | 2 水平：固定时间阈值（TTC/TTMD）vs 减速度归一化阈值（BTN） | §3.2；Takada 2014、Coelingh 2010、A-TTC 2025 |
| IV-C（区块 B） | **持续与撤销策略** | 3 水平：固定 1.5 s、状态维持（至首次正确反应 + 300 ms 渐隐）、风险耦合衰减（强度随 BTN 单调下降） | §2.3.8 的"持续时长悖论"；Ma 2021 的 3 s、Shen 的占空比证据 |

主设计：IV-A × IV-B = 2×3 被试内（6 条件），IV-C 作为独立区块（3 条件），总 9 个危险试次块 + 填充与 catch trials。相比原来的 3 水平 + 4 水平枚举，条件数相当，但**每个水平都有理论解释与预测方向**。

### 4.2 实验 2 的自变量（含新增可靠性维度）

| 编号 | 自变量 | 水平 | 理论出处 |
|---|---|---|---|
| IV-A | **级间间隔** | 0.7 / 1.0 / 1.5 s（= S+I 点估计 ±1 阶段） | §3.4 P2 |
| IV-B | **系统可靠性** | 100% 有效 vs 80% 有效（含 20% 虚警） | §3.3；Abe & Richardson 2006、Bliss 2003、A-TTC |
| 对照 | 无预警基线、实验 1 入选单层方案 | | 原框架 |

IV-B 是本次优化中**最重要的新增**：它把"预警能提前到多早"从工程直觉变成可实验回答的问题，也让论文能给出"在可接受虚警率下的最早预警时刻"这一有实际价值的结论。

### 4.3 因变量体系（按 SPIDER 五阶段组织）

| 阶段 | 主指标 | 次指标 |
|---|---|---|
| Scanning | TTFF(警告)、TTFF(行人) | 注视次数、道路注视比例 |
| Predicting | 路径侵入预测正确率 | 冲突点空间误差 |
| Identifying | 目标验证时间 = TTFF(行人) − TTFF(警告) | 警告漏检率 |
| Deciding | 首次注视行人 → 松油时间 | 风险等级判断正确率 |
| Executing | 制动启动时间、峰值减速度、jerk | 转向幅度 |
| 安全终点 | 最小 TTMD、最小冲突距离、碰撞率 | PET |
| 代价终点 | NASA-TLX、侵入性评分、信任量表 | UEQ-S |

**关键改进**：现有框架的"主要机制指标"是逐实验列举的；改为按 SPIDER 统一组织后，四个实验共享同一套指标结构，跨实验比较才有意义。

### 4.4 控制变量与协变量

- 控制：车速（40/60 km/h，通过 BTN 归一化后成为真正的控制变量）、行人出现侧、遮挡类型、道路背景、天气。
- 协变量（必测，进入模型）：被试 t₀（实验 0 标定）、驾龄、年龄、基线 PRT、AR 系统信任量表基线、模拟器适应度。
- 随机效应：被试、场景。

### 4.5 统计策略

1. **反应时与制动启动用时间到事件模型**：加速失效时间模型（AFT）或 Cox 比例风险模型，处理"未反应/未注视"的截尾数据。先例：Banerjee 等 (2021) 用 log-logistic AFT 计算减速时间；`时间元素专题分析` §2.3.6 也已指出 TTFF 需用生存分析。
2. **主分析用 GLMM / 分层贝叶斯**，随机截距含被试与场景。
3. **预注册非劣界**：安全非劣定义为最小 TTMD 的差值下限 > −0.2 s 且碰撞率不高于基线；只有安全非劣时才比较收益。
4. **不评选单一冠军**：报告安全—舒适—负荷的 Pareto 前沿；并列时选实现更简单者（沿用原框架的决策规则，这一点原设计做得好，保留）。
5. **效应量与不确定性**：报告 $\eta_p^2$ / Cohen's d 与 95% CI；对"未发现差异"的条件明确写"未发现可支持唯一最优值的证据"。

| **实验 0（新增）**<br>标定实验 | 无预警基线 + 心理物理标定 | 车速 × 遮挡（2×2），无 AR | t₀ 分布、PRT 分布、$a_{req}$ 可行域、样本量估计 | 确定**零点**与**下界线** |

### 5.1 实验 1 的预注册预测（用于事后检验理论）

| 编号 | 预测 | 若被推翻意味着 |
|---|---|---|
| H1a | Δt = 0 条件下峰值减速度与 jerk 显著高于 Δt = +1.0 s | S+I 窗口不是限制因素，需回到绝对 TTC 框架 |

### 5.2 实验 2 的预注册预测

| 编号 | 预测 |
|---|---|
| H2a | 级间间隔 1.0 s 条件下"首次注视→正确反应"时间最短（倒 U 型峰值） |
| H2b | 在 80% 可靠性条件下，分层预警的优势显著衰减，且 L1 的依从率下降 |
